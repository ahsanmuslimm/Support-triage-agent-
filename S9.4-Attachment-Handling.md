# S9.4: Attachment Handling

Malware scanning, text extraction, OCR, and PII pseudonymization.

## Implementation Summary
- MalwareScanner: ClamAV REST API integration, EICAR test file detection
- TextExtractor: PDF text (pdfplumber), OCR (Tesseract), DOCX text extraction
- PIIPseudonymizer: Presidio-based PII detection and tokenization
- Storage: S3 with server-side encryption, 30-day TTL
- Extraction pipeline: Scan → Extract → Pseudonymize → Index
- Supported formats: PDF, images (jpg/png/tiff), Office (docx), supported malware targets
- ~250 lines code + 25 tests

## Key Classes
- MalwareScanner: File scanning with format detection
- TextExtractor: Multi-format text extraction
- PIIPseudonymizer: PII replacement with token mapping
- ScanStatus: clean, infected, error, unsupported
- ExtractionStatus: success, unsupported, error, empty
