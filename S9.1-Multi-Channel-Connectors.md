# S9.1: Multi-Channel Connectors

Protocol-based connectors for Intercom, Freshdesk, Zendesk, and WhatsApp.

## Implementation Summary
- HelpdeskConnector ABC with normalize_message(), normalize_ticket(), post_reply(), update_ticket(), fetch_thread_history()
- IntercomAdapter: conversation_id mapping, user sync, custom attributes, media handling
- FreshdeskAdapter: ticket_id mapping, custom fields, agent assignment, automation rules
- ZendeskAdapter: ticket_id mapping with sidebar + advanced routing suggestions
- WhatsAppAdapter: Meta Cloud API, 24h window tracking, template enforcement, media support
- Contract tests: same test suite across all 4 adapters with fixtures
- ~600 lines code + 40 tests

## Key Classes
- MessageNormalization: Unified message model
- TicketNormalization: Unified ticket model
- Attachment: File metadata with type classification
- ReplyResult: Post reply outcome
- TicketUpdateRequest: Ticket update payload
