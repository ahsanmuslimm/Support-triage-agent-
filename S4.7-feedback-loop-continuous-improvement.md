# S4.7 — Feedback Loop & Continuous Improvement

## Overview

This sprint implements a feedback collection and analysis system that closes the loop on triage quality. The system captures agent and human feedback per conversation, analyzes override patterns to identify model performance gaps, fires retraining signals when thresholds are crossed, and tracks customer sentiment trends to detect systemic dissatisfaction. This enables data-driven model improvement and proactive issue detection.

**Key Goals:**
- Measure triage accuracy through feedback and override patterns
- Identify top failure categories to prioritize retraining
- Detect sentiment degradation early
- Automate decision signals for when retraining is necessary

## Technical Specification

### Component 1: Feedback Collection (Agent + Human)

Conversations generate feedback from two sources:
- **Agent feedback**: supervisor or agent reviewing the auto-triage, with a quick rating (thumbs up/down) and optional reason
- **Human feedback**: customer satisfaction score (1–5 stars) collected post-interaction, optional comment

Collection is **non-blocking and async**—feedback submission does not delay any other operation. A backend worker aggregates feedback into rolling windows (7-day, 30-day).

### Component 2: Override Reason Analysis

Override reason codes (from S4.3) are aggregated daily. Analysis produces:
- **Override rate** by reason code (e.g., `INTENT_MISCLASSIFIED`, `SEVERITY_MISJUDGED`)
- **Trend**: rising or stable over 7d and 30d windows
- **Percentile**: what fraction of all overrides fall into this category

Used to identify systemic gaps in the triage model.

### Component 3: Model Retraining Trigger Signals

Retraining signals fire when any of these conditions are met:
1. **Override rate spike**: 7-day rolling override rate exceeds configurable threshold (default: 15%)
2. **Accuracy drop**: inferred from feedback scores; 30-day average customer satisfaction < target (default: 4.0 stars)
3. **New intent cluster**: override reason code emerges with >5% of overrides in a 7-day window (indicates novel intent not in training)

Each signal includes: trigger type, metric value, threshold, timestamp, and tenant context. Signals are **deduplicated** by (tenant_id, signal_type, window)—only one signal per signal type per 7-day window per tenant.

### Component 4: Sentiment Shift Tracking

Customer sentiment is aggregated using **Exponential Weighted Moving Average (EWMA)** to detect gradual degradation:

```
EWMA[t] = α × sentiment[t] + (1 - α) × EWMA[t-1]
```

Where α = 0.2 (default), giving recent scores more weight. A shift is detected when:

```
|EWMA[current] - baseline| > Z_score_threshold × σ_baseline
```

Default Z-score threshold: 2.0 (95% confidence). Alerts trigger only when shift moves below baseline (degradation).

## Data Model

### ConversationFeedback

Stores individual feedback events. Indexed by (conversation_id, tenant_id) and (submitted_at, tenant_id) for efficient aggregation.

```json
{
  "id": "fb_abc123xyz",
  "conversation_id": "conv_12345",
  "tenant_id": "org_acme",
  "source_type": "agent",
  "rating": 5,
  "rating_scale": "1-5",
  "feedback_text": "Model correctly identified billing inquiry",
  "tags": ["positive", "intent-correct"],
  "submitted_by": "agent_id_or_system",
  "submitted_at": "2024-01-15T14:32:10Z",
  "created_at": "2024-01-15T14:32:10Z"
}
```

**Fields:**
- `source_type`: enum [agent, human]
- `rating`: 1–5 stars (or thumbs: 1 for down, 5 for up)
- `feedback_text`: optional free-form (max 500 chars)
- `tags`: optional array for quick categorization (positive, negative, intent-*, severity-*, etc.)
- `submitted_by`: agent ID, system ID, or anonymous for customer feedback

# handlers/feedback.py
from django.db import transaction
from celery import shared_task

@transaction.atomic
def store_feedback(conversation_id, tenant_id, source_type, rating, text=None):
    """Store feedback without blocking request."""
    feedback = ConversationFeedback.objects.create(
        conversation_id=conversation_id,
        tenant_id=tenant_id,
        source_type=source_type,
        rating=rating,
        feedback_text=text or "",
    )
    # Emit to queue for aggregation
    aggregate_feedback_if_due.delay(tenant_id)
    return feedback.id
```

**Rate limiting:** client IP + tenant_id bucket; 100 feedback events per hour per tenant.

**Duplicate detection:** conversations can only submit one agent feedback per day. Multiple human feedbacks allowed but deduplicated at aggregation time.

# tasks/aggregation.py
from celery.beat import periodic_task
from datetime import datetime, timedelta

@periodic_task(run_every=crontab(minute=45, hour=23))
def aggregate_override_reasons():
    """Summarize override reasons for all tenants."""
    tenants = Tenant.objects.filter(is_active=True)
    for tenant in tenants:
        end_date = datetime.utcnow().date()
        start_7d = end_date - timedelta(days=7)
        start_30d = end_date - timedelta(days=30)
        
        # Query overrides from S4.3 OverrideLog
        overrides_7d = OverrideLog.objects.filter(
            tenant_id=tenant.id,
            override_date__gte=start_7d,
            override_date__lte=end_date,
        )
        overrides_30d = OverrideLog.objects.filter(
            tenant_id=tenant.id,
            override_date__gte=start_30d,
            override_date__lte=end_date,
        )
        
        total_7d = overrides_7d.count()
        total_30d = overrides_30d.count()
        
        # Group by reason_code
        for reason_code in set(overrides_7d.values_list('reason_code', flat=True)):
            count_7d = overrides_7d.filter(reason_code=reason_code).count()
            count_30d = overrides_30d.filter(reason_code=reason_code).count()
            
            trend = "rising" if (count_7d > count_30d / 4.28) else "stable"
            
            OverrideReasonSummary.objects.update_or_create(
                tenant_id=tenant.id,
                reason_code=reason_code,
                defaults={
                    'count_7d': count_7d,
                    'count_30d': count_30d,
                    'pct_of_overrides_7d': (count_7d / total_7d * 100) if total_7d > 0 else 0,
                    'pct_of_overrides_30d': (count_30d / total_30d * 100) if total_30d > 0 else 0,
                    'trend_7d': trend,
                    'trend_30d': 'stable',  # simplified
                    'last_updated': datetime.utcnow(),
                }
            )
```

### Retraining Signal Logic

**Check and fire signals (runs after aggregation):**

```python
# tasks/retraining_signals.py

def check_and_fire_retraining_signals(tenant_id):
    """Fire signals if conditions are met."""
    today = datetime.utcnow().date()
    window_start = today - timedelta(days=7)
    
    # 1. Override rate spike
    total_overrides = OverrideLog.objects.filter(
        tenant_id=tenant_id,
        override_date__gte=window_start,
    ).count()
    total_conversations = Conversation.objects.filter(
        tenant_id=tenant_id,
        created_at__gte=window_start,
    ).count()
    
    override_rate = (total_overrides / total_conversations * 100) if total_conversations > 0 else 0
    threshold = get_config(tenant_id, 'OVERRIDE_RATE_THRESHOLD', 15.0)
    
    if override_rate > threshold:
        _fire_signal_once_per_window(
            tenant_id=tenant_id,
            signal_type='override_rate_spike',
            metric='override_rate_7d',
            metric_value=override_rate,
            threshold_value=threshold,
            window_start=window_start,
            window_end=today,
        )
    
    # 2. Accuracy drop (from feedback)
    avg_rating = ConversationFeedback.objects.filter(
        tenant_id=tenant_id,
        submitted_at__gte=window_start,
        source_type='human',
    ).aggregate(avg=models.Avg('rating'))['avg']
    
    accuracy_target = get_config(tenant_id, 'CUSTOMER_SATISFACTION_TARGET', 4.0)
    if avg_rating and avg_rating < accuracy_target:
        _fire_signal_once_per_window(
            tenant_id=tenant_id,
            signal_type='accuracy_drop',
            metric='avg_customer_satisfaction_30d',
            metric_value=avg_rating,
            threshold_value=accuracy_target,
            window_start=window_start,
            window_end=today,
        )
    
    # 3. New intent cluster
    top_reason = OverrideReasonSummary.objects.filter(
        tenant_id=tenant_id,
        last_updated__gte=window_start,
    ).order_by('-count_7d').first()
    
    if top_reason and top_reason.pct_of_overrides_7d > 5.0:
        _fire_signal_once_per_window(
            tenant_id=tenant_id,
            signal_type='new_intent_cluster',
            metric='top_override_reason_pct',
            metric_value=top_reason.pct_of_overrides_7d,
            threshold_value=5.0,
            window_start=window_start,
            window_end=today,
        )

def _fire_signal_once_per_window(tenant_id, signal_type, metric, metric_value, 
                                  threshold_value, window_start, window_end):
    """Deduplicate by (tenant, signal_type, window)."""
    existing = RetrainingSignal.objects.filter(
        tenant_id=tenant_id,
        signal_type=signal_type,
        window_start=window_start,
        window_end=window_end,
    ).first()
    
    if not existing:
        signal = RetrainingSignal.objects.create(
            tenant_id=tenant_id,
            signal_type=signal_type,
            metric=metric,
            metric_value=metric_value,
            threshold_value=threshold_value,
            window_start=window_start,
            window_end=window_end,
            fired_at=datetime.utcnow(),
            status='pending',
        )
        emit_alert(signal)  # Notify ops team
```

### Sentiment Shift Tracking

**Hourly job computes EWMA and detects shift:**

```python
# tasks/sentiment.py

@periodic_task(run_every=crontab(minute=0))  # every hour
def compute_sentiment_trend():
    """Compute EWMA and detect sentiment shift."""
    tenants = Tenant.objects.filter(is_active=True)
    now = datetime.utcnow()
    
    for tenant in tenants:
        # Last 24 hours of feedback
        start_time = now - timedelta(hours=24)
        recent_feedback = ConversationFeedback.objects.filter(
            tenant_id=tenant.id,
            submitted_at__gte=start_time,
            source_type='human',
        )
        
        if recent_feedback.count() == 0:
            continue
        
        avg_sentiment = recent_feedback.aggregate(avg=models.Avg('rating'))['avg']
        sample_count = recent_feedback.count()
        
        # Get baseline (30-day average)
        baseline_start = now - timedelta(days=30)
        baseline_feedback = ConversationFeedback.objects.filter(
            tenant_id=tenant.id,
            submitted_at__gte=baseline_start,
            source_type='human',
        )
        baseline_sentiment = baseline_feedback.aggregate(avg=models.Avg('rating'))['avg']
        sigma = baseline_feedback.aggregate(std=models.StdDev('rating'))['std'] or 0.1
        
        # Get previous EWMA (or use current as initial)
        previous_trend = SentimentTrend.objects.filter(
            tenant_id=tenant.id,
        ).order_by('-computed_at').first()
        
        alpha = 0.2  # EWMA smoothing factor
        if previous_trend:
            ewma = alpha * avg_sentiment + (1 - alpha) * previous_trend.ewma_sentiment
        else:
            ewma = avg_sentiment
        
        # Compute Z-score
        z_score_threshold = get_config(tenant.id, 'SENTIMENT_SHIFT_Z_SCORE', 2.0)
        z_score = abs(ewma - baseline_sentiment) / sigma if sigma > 0 else 0
        
        shift_detected = z_score > z_score_threshold and ewma < baseline_sentiment
        
        trend = SentimentTrend.objects.create(
            tenant_id=tenant.id,
            window_hours=24,
            sample_count=sample_count,
            avg_sentiment=avg_sentiment,
            ewma_sentiment=ewma,
            baseline_sentiment=baseline_sentiment,
            sigma_baseline=sigma,
            z_score=z_score,
            shift_detected=shift_detected,
            shift_direction='degradation' if shift_detected else None,
            computed_at=now,
        )
        
        if shift_detected and not previous_trend.alert_sent:
            emit_sentiment_alert(tenant.id, ewma, baseline_sentiment)
```

    """EWMA computed correctly."""
    # Create feedback: [4.0, 4.2, 4.1, 3.9]
    scores = [4.0, 4.2, 4.1, 3.9]
    alpha = 0.2
    
    # Manual: 4.0, 0.2*4.2 + 0.8*4.0 = 4.04, ...

def test_shift_detection_triggers_below_baseline():

    sigma = 0.35

- **Raw feedback:** 90 days (then archival/deletion)
- **Aggregated summaries:** indefinite (OverrideReasonSummary, SentimentTrend history)
- **Retraining signals:** 1 year
- **Audit log:** all feedback acknowledgments retained 2 years for compliance
