### 8. `Makefile` (Common Commands)
```makefile
.PHONY: help setup lint typecheck test smoke up down db-migrate db-rollback clean

help:
	@echo "Triage Agent - Development Commands"
	@echo "===================================="
	@echo "make setup         - Install dependencies"
	@echo "make lint          - Run linter (Ruff)"
	@echo "make typecheck     - Run type checker (mypy, TypeScript)"
	@echo "make test          - Run all tests"
	@echo "make smoke         - Run smoke tests on local stack"
	@echo "make up            - Start local services (Docker Compose)"
	@echo "make down          - Stop local services"
	@echo "make db-migrate    - Run Alembic migrations"
	@echo "make db-rollback   - Rollback last migration"
	@echo "make clean         - Clean build artifacts"

setup:
	uv sync

lint:
	ruff check . --fix
	ruff format .

typecheck:
	mypy py_core/src packages/*/src --strict
	tsc --noEmit 2>/dev/null || true

test:
	pytest tests/ -n auto --cov=py_core --cov=packages

smoke:
	pytest tests/ -m smoke -v

up:
	docker-compose -f infra/docker-compose.yml up -d

down:
	docker-compose -f infra/docker-compose.yml down

db-migrate:
	alembic upgrade head

db-rollback:
	alembic downgrade -1

clean:
	find . -type d -name __pycache__ -exec rm -rf {} +
	find . -type d -name .pytest_cache -exec rm -rf {} +
	find . -type d -name dist -exec rm -rf {} +
	find . -type f -name "*.pyc" -delete
```

### 10. Root `README.md`
```markdown
# Triage Agent - AI-Powered Customer Support

A multi-tenant, omnichannel AI platform that ingests support inquiries, classifies intent, enriches context, resolves Tier-1 issues autonomously, and routes everything else with full context.

## Quick Start

### Prerequisites
- Python 3.12+
- Node.js 18+
- Docker & Docker Compose
- uv (Python package manager)

### Setup
```bash
# 1. Clone and navigate
cd Support-triage-agent-

# 2. Copy environment
cp .env.example .env.local

# 3. Install dependencies
make setup

# 4. Start services
make up

# 5. Run tests
make test
```

### Development

**Linting & Type Checking:**
```bash
make lint      # Ruff + format
make typecheck # mypy + tsc
```

**Testing:**
```bash
make test      # Full suite
make smoke     # Quick health checks
```

**Database:**
```bash
make db-migrate   # Run migrations
make db-rollback  # Rollback last
```

## Architecture

- **Database:** PostgreSQL 18 + pgvector
- **Monorepo:** uv workspaces + Turborepo
- **Backend:** Python 3.12 (FastAPI, LangGraph)
- **Frontend:** TypeScript (Next.js console, Preact widget)
- **Testing:** pytest (Tier A-E optimized TDD)

## Workspace Structure

- `py_core/` — Shared Python library (tenant context, DB, errors, logging)
- `packages/api/` — FastAPI ingestion & routing API
- `packages/triage-worker/` — LangGraph agent executor
- `packages/knowledge-worker/` — RAG & embedding pipeline
- `packages/console/` — Admin UI (Next.js)
- `packages/widget/` — Chat widget (Preact)
- `ml/` — Prompts, golden datasets, evaluations
- `infra/` — Docker, Terraform
- `tests/` — Contract & acceptance tests
