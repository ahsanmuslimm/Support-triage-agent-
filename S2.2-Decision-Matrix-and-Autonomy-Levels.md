# S2.2 — Decision Matrix & Autonomy Levels

**Sprint:** 2 (Triage & Classification Core)  
**Deliverable:** Decision matrix, autonomy policies (L0–L3), policy input document  
**Effort:** 2 days  
**Dependencies:** S0 (PostgreSQL), S1.5 (Identity), S2.1 (Intent classification)

---

## Overview

The **decision matrix** answers: "Should the triage agent handle this automatically, or escalate to a human?"

Three inputs determine autonomy:

1. **Intent confidence** (from S2.1)
2. **Identity assurance level** (from S1.5: channel-asserted, verified, device-only)
3. **Tool safety** (can execute safely? Is customer verified enough?)

Output: an **autonomy decision** (L0–L3) that gates actions and controls AI autonomy level.

---

## Technical Specification

### 1. Autonomy Levels

| Level | Name | Scope | Examples |
|---|---|---|---|
| **L0** | Read-Only | Retrieve info, answer questions | "Where is order #123?" |
| **L1** | Low-Risk Write | Single idempotent actions, low financial impact | Create support ticket, add note |
| **L2** | Medium-Risk Write | Financial or account actions, needs verification | Refund < $50, password reset |
| **L3** | High-Risk Write | Rare, high-value actions, requires approval | Refund > $500, account deletion |

### 2. Policy Input Document

The decision matrix is fed a **policy input document** containing all relevant context:

```python
@dataclass
class PolicyInput:
    """Complete context for autonomy decision."""
    
    # Intent & confidence
    intent: str  # e.g., "order_status", "refund"
    intent_confidence: float  # 0.0–1.0
    
    # Identity & verification
    customer_ial: int  # 0=unverified, 1=channel-asserted, 2=verified
    customer_id: str
    account_age_days: int
    
    # Risk signals
    message_contains_pii: bool
    message_contains_injected_sql: bool
    message_contains_xss: bool
    
    # Previous interactions
    conversation_count: int  # How many conversations?
    refund_count_30d: int  # Refunds in last 30 days
    account_warnings: list[str]  # ["fraud_flag", "chargeback", "abuse"]
    
    # Tool context
    tool_requested: str  # e.g., "refund", "password_reset"
    tool_amount: Optional[float]  # For refund tool
    tool_requires_ial: int  # Minimum IAL required
    
    # Business context
    is_business_hours: bool
    is_peak_load: bool
    
    # Tenant policy
    tenant_autonomy_settings: dict  # {"order_status": L1, "refund": L2, ...}
```

### 3. Decision Rules (Tier A — Strict TDD)

```python
class DecisionMatrix:
    """
    Pure logic: input document → autonomy level.
    No I/O, no randomness, fully deterministic and testable.
    """
    
    def decide(self, policy_input: PolicyInput) -> tuple[int, str]:
        """
        Decide autonomy level.
        
        Returns: (level, reason)
        """
        
        # Rule 1: Intent confidence must be ≥ 0.9 for any automation
        if policy_input.intent_confidence < 0.9:
            return (0, "Low confidence intent (< 0.9)")
        
        # Rule 2: Security checks (injection, XSS, etc.)
        if policy_input.message_contains_injected_sql or policy_input.message_contains_xss:
            return (0, "Security risk detected in message")
        
        # Rule 3: High-risk customer flags
        if "fraud_flag" in policy_input.account_warnings or "chargeback" in policy_input.account_warnings:
            return (0, "Account flagged for fraud/chargeback")
        
        # Rule 4: Tool IAL requirement
        if policy_input.customer_ial < policy_input.tool_requires_ial:
            return (0, f"Customer IAL ({policy_input.customer_ial}) < required ({policy_input.tool_requires_ial})")
        
        # Rule 5: Intent-specific autonomy from tenant settings
        intent_autonomy = policy_input.tenant_autonomy_settings.get(policy_input.intent, 0)
        
        # Rule 6: Financial limits
        if policy_input.tool_requested == "refund":
            if policy_input.tool_amount is None:
                return (0, "Refund amount not specified")
            
            # Refund > $500 always requires approval
            if policy_input.tool_amount > 500:
                return (3, f"High-value refund (${policy_input.tool_amount})")
            
            # Refund in last 30 days already? Escalate
            if policy_input.refund_count_30d >= 2:
                return (2, "Customer has 2+ refunds in 30 days (pattern)")
            
            # New account (< 30 days): require more verification
            if policy_input.account_age_days < 30:
                return (1, "Account age < 30 days (new customer)")
            
            # Baseline: $50–500 refund
            if policy_input.tool_amount < 50:
                return (2, f"Low-value refund (${policy_input.tool_amount})")
            else:
                return (2, f"Medium-value refund (${policy_input.tool_amount})")
        
        # Rule 7: Password reset requires IAL2 (email verified)
        if policy_input.tool_requested == "password_reset":
            if policy_input.customer_ial < 2:
                return (2, "Password reset requires verified email (IAL2)")
            return (1, "Password reset (low risk)")
        
        # Rule 8: Account deletion requires approval
        if policy_input.tool_requested == "account_delete":
            return (3, "Account deletion always requires manual approval")
        
        # Rule 9: Default to intent_autonomy from config
        return (intent_autonomy, f"Default autonomy for intent '{policy_input.intent}'")
```

### 4. Autonomy Promotion Workflow

Agents start at **L0 (read-only)** and get promoted based on quality:

```python
class AutonomyPromoter:
    """Promote/demote agents based on performance."""
    
    async def should_promote(
        self,
        tenant_id: int,
        intent: str,
        current_level: int,
    ) -> tuple[bool, str]:
        """
        Promotion criteria for moving from level N to N+1:
        - Intent accuracy ≥ 95% on shadow samples
        - Groundedness ≥ 0.95 (no hallucinations)
        - ≥ 200 shadow samples processed
        - Admin sign-off
        - No demotions in last 7 days
        """
        
        # Get intent metrics
        metrics = await self.get_intent_metrics(tenant_id, intent)
        
        checks = {
            "intent_accuracy": metrics["accuracy"] >= 0.95,
            "groundedness": metrics["groundedness"] >= 0.95,
            "sample_count": metrics["shadow_samples"] >= 200,
            "admin_signed_off": metrics["admin_approved"] is True,
            "no_recent_demotions": not await self.had_demotion_in_7_days(tenant_id, intent),
            "no_flips": not await self.had_autonomy_flip(tenant_id, intent),
        }
        
        all_checks_pass = all(checks.values())
        reason = f"Promotion checks: {checks}"
        
        return all_checks_pass, reason
    
    async def should_demote(
        self,
        tenant_id: int,
        intent: str,
        current_level: int,
    ) -> tuple[bool, str]:
        """
        Auto-demotion on degradation:
        - False-resolution rate > 5%
        - Groundedness < 0.85
        - Injection attempts > 10/day
        """
        
        metrics = await self.get_intent_metrics(tenant_id, intent)
        
        checks = {
            "false_resolutions": metrics["false_resolution_rate"] > 0.05,
            "groundedness_drop": metrics["groundedness"] < 0.85,
            "injection_attacks": metrics["injection_attempts_per_day"] > 10,
        }
        
        should_demote = any(checks.values())
        reason = f"Demotion triggers: {checks}"
        
        return should_demote, reason
```

### 5. Autonomy Gates (Enforcement)

```python
class AutonomyGate:
    """Enforce autonomy level at execution time."""
    
    async def execute_tool(
        self,
        autonomy_level: int,
        tool_name: str,
        tool_args: dict,
        policy_input: PolicyInput,
    ) -> dict:
        """
        Execute tool only if autonomy level permits.
        
        L0: No tool execution
        L1: Only safe, idempotent tools (create_ticket, send_email)
        L2: Write tools with tracking (refund < $50, password reset)
        L3: High-risk tools (always requires approval)
        """
        
        # Gate by autonomy level
        if autonomy_level == 0:
            # Read-only: cannot execute
            return {"status": "blocked_by_autonomy", "reason": "Autonomy L0 (read-only)"}
        
        if autonomy_level == 1:
            # Low-risk write
            allowed_tools = ["create_support_ticket", "add_internal_note", "send_email"]
            if tool_name not in allowed_tools:
                return {"status": "blocked_by_autonomy", f"reason": f"Tool '{tool_name}' requires L2+"}
        
        if autonomy_level == 2:
            # Medium-risk write
            allowed_tools = ["create_ticket", "add_note", "refund", "password_reset", "plan_change"]
            if tool_name not in allowed_tools:
                return {"status": "blocked_by_autonomy", "reason": f"Tool '{tool_name}' requires L3"}
            
            # Additional: financial limits
            if tool_name == "refund" and tool_args.get("amount", 0) > 500:
                return {"status": "blocked_by_autonomy", "reason": "Refund > $500 requires L3"}
        
        if autonomy_level == 3:
            # High-risk write: all tools allowed, but track execution
            pass
        
        # Execute tool
        try:
            result = await self._execute(tool_name, tool_args, policy_input)
            return {"status": "executed", "result": result}
        except Exception as e:
            return {"status": "error", "error": str(e)}
```

### 6. Database Schema

```sql
CREATE TABLE autonomy_policies (
    id BIGSERIAL PRIMARY KEY,
    tenant_id BIGINT NOT NULL REFERENCES tenants(id),
    intent VARCHAR(100) NOT NULL,
    autonomy_level INTEGER NOT NULL CHECK (autonomy_level IN (0, 1, 2, 3)),
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(tenant_id, intent)
);

CREATE TABLE autonomy_promotions (
    id BIGSERIAL PRIMARY KEY,
    tenant_id BIGINT NOT NULL REFERENCES tenants(id),
    intent VARCHAR(100) NOT NULL,
    from_level INTEGER NOT NULL,
    to_level INTEGER NOT NULL,
    accuracy NUMERIC(3, 2),
    groundedness NUMERIC(3, 2),
    sample_count INTEGER,
    admin_approved_by BIGINT REFERENCES users(id),
    promoted_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (tenant_id) REFERENCES tenants(id)
);

CREATE TABLE autonomy_demotions (
    id BIGSERIAL PRIMARY KEY,
    tenant_id BIGINT NOT NULL REFERENCES tenants(id),
    intent VARCHAR(100) NOT NULL,
    from_level INTEGER NOT NULL,
    to_level INTEGER NOT NULL,
    reason TEXT,
    metric_name VARCHAR(50),  -- 'false_resolution_rate', 'groundedness', etc.
    metric_value NUMERIC(5, 2),
    demoted_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (tenant_id) REFERENCES tenants(id)
);
```

### 7. Simulation & Transparency

```python
class AutonomySimulator:
    """Transparency: show what would happen with different autonomy levels."""
    
    async def simulate_30_days(
        self,
        tenant_id: int,
        from_autonomy_level: int,
        to_autonomy_level: int,
    ) -> dict:
        """
        Simulate: if we moved from L1→L2 for intent X,
        what would have happened to the last 30 days of messages?
        
        Returns estimated change in:
        - Auto-resolution rate
        - Cost (tools executed)
        - Manual review load
        """
        
        # Get last 30 days of messages for this tenant
        messages = await db.query("""
            SELECT id, body, created_at
            FROM messages
            WHERE tenant_id = $1 AND created_at > NOW() - INTERVAL '30 days'
            ORDER BY created_at DESC
        """, tenant_id).all()
        
        # For each message, compute policy_input and decide at both levels
        simulated_decisions = {
            "kept_l0": 0, "promoted_to_l2": 0, "promoted_to_l3": 0,
            "estimated_cost_change": 0.0,
            "estimated_manual_load_change": 0,
        }
        
        for msg in messages:
            policy_input = await self._compute_policy_input(tenant_id, msg.id)
            
            old_decision = await self.decision_matrix.decide(policy_input)
            
            # Simulate new autonomy level for same message
            policy_input.tenant_autonomy_settings[policy_input.intent] = to_autonomy_level
            new_decision = await self.decision_matrix.decide(policy_input)
            
            if old_decision[0] < new_decision[0]:
                simulated_decisions["promoted_to_l2"] += 1
            elif old_decision[0] > new_decision[0]:
                simulated_decisions["demoted"] += 1
        
        return simulated_decisions
```
