# S9.2: WhatsApp 24h Window

24-hour messaging window tracking, template library, and SMS fallback.

## Implementation Summary
- WhatsAppWindow: Tracks last_customer_message_timestamp, calculate_time_remaining()
- Template library: Pre-built HSM templates (order_status, account_alert, password_reset, callback_request)
- Window rules: Messages >24h must use approved templates (0.5 credits vs 1 credit)
- Phone normalization: E.164 format standardization
- SMS fallback: If no template fits, use SMS instead
- Window info API: get_24h_window_info() for client queries
- ~200 lines code + 20 tests

## Key Classes
- WhatsAppWindow: 24h tracking logic
- WhatsAppTemplate: HSM template metadata
- WhatsAppTemplateLibrary: Template discovery
