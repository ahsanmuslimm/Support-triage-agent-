# Sprint 0.2 - Local Development Stack

## Objective
Create a Docker Compose configuration for local development with PostgreSQL 18, pgvector, Redis, MinIO, Mailpit, Langfuse, and LiteLLM.

## Implementation

### 1. `infra/docker-compose.yml`
```yaml
version: '3.9'

services:
  # PostgreSQL 18 with pgvector
  postgres:
    image: pgvector/pgvector:pg18-latest
    container_name: triage-postgres
    environment:
      POSTGRES_USER: triage
      POSTGRES_PASSWORD: password
      POSTGRES_DB: triage_dev
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data
      - ./init-postgres.sql:/docker-entrypoint-initdb.d/init.sql
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U triage"]
      interval: 10s
      timeout: 5s
      retries: 5
    networks:
      - triage-net

  # Redis for caching, locks, debouncing
  redis:
    image: redis:7-alpine
    container_name: triage-redis
    command: redis-server --appendonly yes
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 10s
      timeout: 5s
      retries: 5
    networks:
      - triage-net

  # MinIO - S3-compatible storage for KB documents, attachments
  minio:
    image: minio/minio:latest
    container_name: triage-minio
    environment:
      MINIO_ROOT_USER: minioadmin
      MINIO_ROOT_PASSWORD: minioadmin
    ports:
      - "9000:9000"
      - "9001:9001"
    volumes:
      - minio_data:/minio_data
    command: server /minio_data --console-address ":9001"
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:9000/minio/health/live"]
      interval: 30s
      timeout: 20s
      retries: 3
    networks:
      - triage-net

  # Mailpit - Local email testing
  mailpit:
    image: axllent/mailpit:latest
    container_name: triage-mailpit
    ports:
      - "1025:1025"  # SMTP
      - "8025:8025"  # Web UI
    networks:
      - triage-net

  # Langfuse - LLM observability & tracing
  langfuse:
    image: ghcr.io/langfuse/langfuse:latest
    container_name: triage-langfuse
    environment:
      DATABASE_URL: postgresql://langfuse:password@postgres:5432/langfuse?schema=public
      NEXTAUTH_SECRET: "your-secret-change-in-production"
      NEXTAUTH_URL: "http://localhost:3000"
    ports:
      - "3000:3000"
    depends_on:
      postgres:
        condition: service_healthy
    volumes:
      - langfuse_data:/app/data
    networks:
      - triage-net

  # LiteLLM Gateway - LLM abstraction layer
  litellm:
    image: ghcr.io/berriai/litellm:main-latest
    container_name: triage-litellm
    environment:
      LITELLM_MASTER_KEY: "sk-test-key"
      LITELLM_SALT_KEY: "sk-salt-key"
      LITELLM_LOG_LEVEL: DEBUG
    ports:
      - "8000:8000"
    volumes:
      - ./litellm-config.yaml:/app/config.yaml
    command: python -m litellm.proxy.proxy --config /app/config.yaml --port 8000
    networks:
      - triage-net

volumes:
  postgres_data:
  redis_data:
  minio_data:
  langfuse_data:

networks:
  triage-net:
    driver: bridge
```

### 4. `Makefile` Additions (Docker Commands)
```makefile
# Add to existing Makefile

.PHONY: up down restart logs db-shell redis-shell ps

up:
	@echo "Starting local development stack..."
	docker-compose -f infra/docker-compose.yml up -d
	@echo "Waiting for services to be healthy..."
	@sleep 5
	@docker-compose -f infra/docker-compose.yml ps
	@echo ""
	@echo "Services are running:"
	@echo "  PostgreSQL:   localhost:5432 (user: triage, password: password)"
	@echo "  Redis:        localhost:6379"
	@echo "  MinIO:        localhost:9000 (console: 9001)"
	@echo "  Mailpit:      localhost:8025 (SMTP: 1025)"
	@echo "  Langfuse:     http://localhost:3000"
	@echo "  LiteLLM:      http://localhost:8000"

down:
	@echo "Stopping local services..."
	docker-compose -f infra/docker-compose.yml down

restart:
	@echo "Restarting services..."
	docker-compose -f infra/docker-compose.yml restart

logs:
	docker-compose -f infra/docker-compose.yml logs -f

ps:
	docker-compose -f infra/docker-compose.yml ps

db-shell:
	docker-compose -f infra/docker-compose.yml exec postgres psql -U triage -d triage_dev

redis-shell:
	docker-compose -f infra/docker-compose.yml exec redis redis-cli

smoke:
	@echo "Running smoke tests on local stack..."
	pytest tests/ -m smoke -v --tb=short
	@echo ""
	@echo "Checking service health:"
	@echo "PostgreSQL:"
	@docker-compose -f infra/docker-compose.yml exec postgres pg_isready -U triage && echo "✓ OK" || echo "✗ FAILED"
	@echo "Redis:"
	@docker-compose -f infra/docker-compose.yml exec redis redis-cli ping && echo "✓ OK" || echo "✗ FAILED"
	@echo "MinIO:"
	@curl -s http://localhost:9000/minio/health/live > /dev/null && echo "MinIO: ✓ OK" || echo "MinIO: ✗ FAILED"
	@echo "LiteLLM:"
	@curl -s http://localhost:8000/health > /dev/null && echo "LiteLLM: ✓ OK" || echo "LiteLLM: ✗ FAILED"
```

## Usage

### Start All Services
```bash
make up
```

This will:
1. Start all 7 services
2. Wait for health checks to pass
3. Display connection info
4. Volume data persists across restarts

### View Logs
```bash
make logs
make logs | grep postgres  # Filter by service
```

### Access Services

| Service | URL/Port | Credentials |
|---------|----------|-------------|
| **PostgreSQL** | localhost:5432 | user: `triage`, password: `password` |
| **Redis CLI** | `make redis-shell` | — |
| **MinIO Web** | http://localhost:9001 | user: `minioadmin`, password: `minioadmin` |
| **Mailpit Web** | http://localhost:8025 | — |
| **Langfuse** | http://localhost:3000 | — |
| **LiteLLM API** | http://localhost:8000 | key: `sk-test-key` |

### Stop Services
```bash
make down
```

Data is preserved in Docker volumes. `make up` will resume.

### Run Smoke Tests
```bash
make smoke
```

This verifies all services are healthy and connectable.

### Database Shell Access
```bash
make db-shell
# Then run SQL commands
# \dt  # List tables
# \q  # Quit
```

## Environment Setup

1. Copy `.env.example` to `.env.local`
2. Update any credentials (defaults are development-only)
3. No secrets should be committed to git

## Cleanup

To completely remove all local data and start fresh:
```bash
docker-compose -f infra/docker-compose.yml down -v
```

The `-v` flag removes all volumes (persisted data).
