# S8.5: MLflow Registry & Promotion

## Overview
Model versioning and safe promotion workflow: shadow → canary → production.

## Promotion Gates
- Accuracy ≥95%
- ECE ≤0.05
- Groundedness ≥95%
- ≥200 shadow samples

## Promotion Stages
1. **Development**: Initial training
2. **Shadow**: Run in parallel with old model for 7 days
3. **Canary**: 10% traffic, monitor error vs baseline
4. **Production**: Full traffic (manual approval)
5. **RolledBack**: If canary error > baseline+1σ for 10 min

## Components
- **PromotionGateEvaluator**: Check all gates
- **ShadowDualPredictor**: Dual-predict, measure divergence
- **CanaryDeployment**: Traffic split, error monitoring, auto-rollback
- **PromotionWorkflow**: Full promotion workflow
