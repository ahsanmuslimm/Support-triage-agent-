# S8.7: Nightly Eval Suite

## Overview
Continuous quality monitoring with regression detection.

## Evaluators
- **Ragas**: Context precision, recall, faithfulness, answer relevance
- **Promptfoo**: Intent accuracy, entity F1, composition score

## Regression Detection
- Threshold: >5% metric drop triggers alert
- Diff table: baseline vs current vs % change
- Slack alerts on regression

## Prompt Versioning
- Register prompt versions with hash
- Link eval results to versions
- Track prompt changes in MLflow

## Outputs
- Nightly eval report with all metrics
- Regression report with diff table
- Prompt version history

## Files
- `ml/pipeline/nightly_eval_suite.py` (~400 lines)
- `tests/unit/ml/pipeline/test_nightly_eval_suite.py` (~350 lines)

## Tests
- Ragas metrics, Promptfoo evals, regression detection
- 30+ tests for evaluation suite
