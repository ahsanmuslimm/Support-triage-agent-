# S4.8 — Conversation Continuity & Context Handoff

## Overview

When an AI triage agent escalates to a human agent, the receiving agent must have complete visibility into the triage process and customer state. This specification defines the **Handoff Package**—a structured bundle of triage summaries, customer history, previous resolution attempts, and quality metrics—ensuring seamless escalation and enabling feedback loops to improve AI triage accuracy.

Handoff packages are created asynchronously at escalation time, assembled from triage output, customer profile service, and ticket history. Quality scores from receiving agents inform S4.7 model retraining and triage confidence calibration.

---

## Technical Specification

### Four Core Components

#### 1. Escalation Summary
Structured triage context extracted deterministically from triage agent output. No LLM call required.

- **intent**: detected customer intent (e.g., "billing_dispute", "technical_issue", "account_access")
- **confidence**: triage agent's confidence in intent (0–1 scale)
- **entities**: extracted entities (account ID, product SKU, error code, etc.)
- **recommended_resolution**: AI triage agent's proposed next step or resolution path
- **triage_agent_id**: identifier of triage agent that performed analysis
- **triage_duration_ms**: time spent in triage pipeline
- **rejection_reason**: if escalated, reason triage agent rejected autonomous resolution

#### 2. Customer Context Pass-Through
Account history and customer tier enabling human agent to prioritize and personalize response.

- **customer_id**: unique customer identifier
- **tier**: support tier (bronze, silver, gold, platinum)
- **lifetime_value**: LTV in USD
- **sentiment_score**: aggregated sentiment from last 10 tickets (-1 to +1)
- **open_tickets**: count of unresolved tickets
- **last_contact_at**: ISO 8601 timestamp of most recent interaction
- **account_status**: active, suspended, at_risk, churned
- **preferred_channel**: sms, email, chat, phone

#### 3. History & Previous Attempts
Last N conversations with outcome labels and attempted resolutions, enabling human agent to avoid redundant work.

- **conversation_id**: ticket/conversation identifier
- **created_at**: timestamp
- **duration_seconds**: how long ticket remained open
- **summary**: 1–2 sentence description of customer issue
- **attempted_resolutions**: list of actions taken with outcome (success, failed, partial)
- **resolution_outcome**: resolved, unresolved, reopened, escalated_to_engineering

#### 4. Handoff Quality Scoring
Post-escalation feedback from human agents used to measure and improve handoff completeness and AI triage accuracy.

- **completeness_score**: 0–100 rule-based score reflecting presence and quality of handoff fields
- **agent_rating**: 1–5 Likert scale: "How useful was the context provided?"
- **agent_notes**: free-form feedback about missing information or clarity issues
- **scored_at**: timestamp when human agent submitted score
- **resolution_achieved**: boolean indicating if human agent successfully resolved the issue

## Implementation

### Handoff Builder Service

```python
class HandoffBuilder:
    """Assembles complete handoff package at escalation time."""
    
    def __init__(self, customer_service, ticket_service, cache_client):
        self.customer_svc = customer_service
        self.ticket_svc = ticket_service
        self.cache = cache_client
    
    async def build_handoff(self, escalation_id: str, triage_output: dict, 
                           customer_id: str, tenant_id: str) -> dict:
        """Build handoff package asynchronously."""
        start_time = time.time()
        
        # Execute components in parallel
        tasks = [
            self._extract_summary(triage_output),
            self._fetch_customer_context(customer_id, tenant_id),
            self._fetch_conversation_history(customer_id, tenant_id)
        ]
        
        summary, customer_ctx, history = await asyncio.gather(*tasks)
        
        handoff = {
            "escalation_id": escalation_id,
            "tenant_id": tenant_id,
            "summary": summary,
            "customer_context": customer_ctx,
            "history_context": history,
            "created_at": datetime.utcnow().isoformat()
        }
        
        duration_ms = (time.time() - start_time) * 1000
        assert duration_ms < 500, f"Handoff build exceeded latency SLA: {duration_ms}ms"
        
        return handoff
    
    def _extract_summary(self, triage_output: dict) -> dict:
        """Extract structured triage context (deterministic, no LLM)."""
        return {
            "intent": triage_output.get("intent"),
            "confidence": triage_output.get("confidence_score"),
            "entities": triage_output.get("extracted_entities", []),
            "recommended_resolution": triage_output.get("proposed_resolution"),
            "triage_agent_id": triage_output.get("agent_id"),
            "triage_duration_ms": triage_output.get("duration_ms"),
            "rejection_reason": triage_output.get("escalation_reason")
        }
    
    async def _fetch_customer_context(self, customer_id: str, tenant_id: str) -> dict:
        """Fetch and cache customer profile (60s TTL)."""
        cache_key = f"customer_ctx:{tenant_id}:{customer_id}"
        cached = self.cache.get(cache_key)
        if cached:
            return cached
        
        profile = await self.customer_svc.get_profile(customer_id, tenant_id)
        context = {
            "customer_id": customer_id,
            "tier": profile.get("tier"),
            "lifetime_value_usd": profile.get("ltv"),
            "sentiment_score": await self._compute_sentiment(customer_id, tenant_id),
            "open_tickets": profile.get("open_ticket_count"),
            "last_contact_at": profile.get("last_contact_iso"),
            "account_status": profile.get("status"),
            "preferred_channel": profile.get("preferred_channel")
        }
        
        self.cache.set(cache_key, context, ttl=60)
        return context
    
    async def _fetch_conversation_history(self, customer_id: str, tenant_id: str) -> dict:
        """Fetch last N conversations, truncated to token limit."""
        convo_count = int(os.getenv("HANDOFF_HISTORY_CONVERSATION_COUNT", "5"))
        max_tokens = int(os.getenv("HANDOFF_MAX_TOKENS", "2000"))
        
        conversations = await self.ticket_svc.get_recent_conversations(
            customer_id, tenant_id, limit=convo_count
        )
        
        history_json = json.dumps(conversations)
        token_count = len(history_json.split())
        
        if token_count > max_tokens:
            # Truncate oldest conversations
            conversations = conversations[:convo_count - 1]
            history_json = json.dumps(conversations)
        
        return {
            "conversation_count": len(conversations),
            "conversations": conversations,
            "history_summary": self._summarize_history(conversations),
            "tokens_used": len(history_json.split()),
            "tokens_limit": max_tokens
        }
    
    def _summarize_history(self, conversations: list) -> str:
        """Generate brief narrative summary of conversation patterns."""
        if not conversations:
            return "No previous conversations."
        
        open_count = sum(1 for c in conversations if c["resolution_outcome"] == "unresolved")
        intents = [c.get("intent") for c in conversations if "intent" in c]
        
        return (
            f"Customer has {open_count} unresolved tickets. "
            f"Primary issues: {', '.join(set(intents[:3]))}. "
            f"Pattern indicates possible {self._detect_pattern(conversations)}."
        )
```

### Completeness Score Calculation

```python
class CompletenessScorer:
    """Rule-based scoring of handoff package completeness."""
    
    WEIGHTS = {
        "summary_intent": 10,
        "summary_confidence": 8,
        "summary_entities": 12,
        "summary_recommended_resolution": 15,
        "customer_tier": 8,
        "customer_ltv": 6,
        "customer_sentiment": 8,
        "customer_open_tickets": 7,
        "history_conversation_count": 10,
        "history_attempted_resolutions": 15,
        "history_outcomes": 10
    }
    
    def score(self, handoff: dict) -> int:
        """Calculate completeness score 0–100."""
        total_weight = sum(self.WEIGHTS.values())
        earned_points = 0
        
        summary = handoff.get("summary", {})
        customer_ctx = handoff.get("customer_context", {})
        history = handoff.get("history_context", {})
        
        # Summary scoring
        if summary.get("intent"):
            earned_points += self.WEIGHTS["summary_intent"]
        if summary.get("confidence") and summary.get("confidence") > 0.7:
            earned_points += self.WEIGHTS["summary_confidence"]
        if summary.get("entities") and len(summary["entities"]) > 0:
            earned_points += self.WEIGHTS["summary_entities"]
        if summary.get("recommended_resolution") and len(summary["recommended_resolution"]) > 20:
            earned_points += self.WEIGHTS["summary_recommended_resolution"]
        
        # Customer context scoring
        if customer_ctx.get("tier"):
            earned_points += self.WEIGHTS["customer_tier"]
        if customer_ctx.get("lifetime_value_usd") is not None:
            earned_points += self.WEIGHTS["customer_ltv"]
        if customer_ctx.get("sentiment_score") is not None:
            earned_points += self.WEIGHTS["customer_sentiment"]
        if customer_ctx.get("open_tickets") is not None:
            earned_points += self.WEIGHTS["customer_open_tickets"]
        
        # History scoring
        if history.get("conversation_count", 0) > 0:
            earned_points += self.WEIGHTS["history_conversation_count"]
        
        conversations = history.get("conversations", [])
        resolution_attempts = sum(
            len(c.get("attempted_resolutions", [])) for c in conversations
        )
        if resolution_attempts > 0:
            earned_points += self.WEIGHTS["history_attempted_resolutions"]
        
        if any(c.get("resolution_outcome") for c in conversations):
            earned_points += self.WEIGHTS["history_outcomes"]
        
        # Normalize to 0–100
        score = int((earned_points / total_weight) * 100)
        return min(100, max(0, score))
```

### Quality Feedback Loop

```python
async def dispatch_quality_feedback_to_s4_7(score_record: dict):
    """Send quality scores to S4.7 model retraining pipeline."""
    feedback = {
        "handoff_id": score_record["handoff_id"],
        "agent_rating": score_record["agent_rating"],
        "resolution_achieved": score_record["resolution_achieved"],
        "completeness_score": score_record["completeness_score"],
        "agent_notes": score_record["agent_notes"],
        "timestamp": score_record["scored_at"]
    }
    
    # Publish to retraining event stream
    await event_bus.publish(
        topic="s4.7.triage_feedback",
        event=feedback,
        partition_key=score_record["handoff_id"]
    )
```

```python
async def test_escalation_handoff_quality_flow():
```

## Deployment

### Environment Variables

```bash
HANDOFF_HISTORY_CONVERSATION_COUNT=5         # Last N conversations to include
HANDOFF_MAX_TOKENS=2000                       # Max tokens for history truncation
CUSTOMER_CONTEXT_CACHE_TTL=60                 # Cache validity in seconds
ENABLE_HANDOFF_QUALITY_SCORING=true           # Feature flag for scoring UI
HANDOFF_BUILD_TIMEOUT_MS=500                  # Latency SLA for handoff assembly
```

### Storage

Handoff packages stored in PostgreSQL JSONB columns for fast retrieval and querying.

```sql
-- Index for common queries
CREATE INDEX idx_handoff_tenant_created ON escalation_handoff(tenant_id, created_at DESC)
  WHERE created_at > NOW() - INTERVAL '30 days';

-- Partial index for unscored handoffs
CREATE INDEX idx_unscored_handoffs ON escalation_handoff(id)
  WHERE id NOT IN (SELECT handoff_id FROM handoff_quality_score);
```

### Observability

Prometheus metrics:

- `handoff_created_total` (counter): handoff packages created per minute
- `handoff_build_duration_ms` (histogram): builder latency (p50, p95, p99)
- `handoff_completeness_score` (histogram): distribution of completeness scores
- `handoff_agent_rating` (histogram): 1–5 rating distribution
- `handoff_resolution_rate` (gauge): % of escalations achieving resolution

CloudWatch dashboards track handoff build latency SLA compliance and quality trend over 7 days.

### Rollout Strategy

1. Deploy handoff builder service with `ENABLE_HANDOFF_QUALITY_SCORING=false`
2. Monitor handoff build latency and error rates for 24 hours
3. Enable quality scoring endpoint for internal pilot agents
4. Gather feedback on handoff completeness and missing fields
5. Adjust weights and history fetch depth based on feedback
6. Gradual rollout: 10% → 50% → 100% of escalations
