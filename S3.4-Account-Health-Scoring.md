**Dependencies:** S3.1 (Customer & Account Enrichment), S2.2 (Decision matrix), S3.8 (Continuous learning)

---

## Overview

**Account Health Scoring** computes a churn/retention risk score for each customer using a LightGBM binary classifier. The score drives routing decisions (escalate high-risk customers), tone injection (empathetic tone for at-risk accounts), and escalation priority. SHAP explainability provides an audit trail and transparency for every prediction—enabling support teams to understand *why* a customer is flagged at risk.

The health score becomes a key feature in the decision matrix (S2.2) and influences agent behavior in the triage graph (S2.7).

```python
from dataclasses import dataclass
from typing import Optional

@dataclass
class HealthFeatures:
    """
    15-feature vector for churn prediction.
    All fields are numeric (int or float) to feed LightGBM directly.
    """
    
    # Recency / Frequency (30-day and 90-day)
    order_frequency_30d: int
    """Number of orders in last 30 days. Range: [0, 100]. Decreasing trend → churn risk."""
    
    order_frequency_90d: int
    """Number of orders in last 90 days. Range: [0, 300]. Historical velocity signal."""
    
    # RFM (Recency, Frequency, Monetary)
    rfm_recency_days: int
    """Days since most recent order. Range: [0, 3650+]. High values indicate disengagement."""
    
    rfm_frequency: int
    """Total orders (all time). Range: [1, 5000]. Loyal customers order more."""
    
    rfm_monetary: float
    """Total lifetime revenue. Range: [0.0, 1e6]. High-value customers less likely to churn."""
    
    # Order metrics
    avg_order_value: float
    """Mean order value. Range: [0.0, 10000]. Spending level."""
    
    days_since_last_order: int
    """Days since last purchase. Range: [0, 3650+]. Inactive customers churn faster."""
    
    # Account tenure
    subscription_age_days: int
    """Days since account creation. Range: [1, 7300+]. Older accounts more stable."""
    
    # Payment health
    failed_payments_90d: int
    """Failed payment attempts in last 90 days. Range: [0, 50]. Payment friction → churn."""
    
    dunning_stage_ordinal: int
    """
    Dunning escalation stage (payment retry).
    Mapping: none=0, warning=1, final=2, suspended=3.
    Range: [0, 3]. High stage strongly predicts churn.
    """
    
    # Sentiment & NPS
    sentiment_score: float
    """
    Aggregated sentiment from support tickets (−1 to 1).
    Range: [−1.0, 1.0]. Negative sentiment correlates with churn.
    From S3.1 enrichment or NLP on recent tickets.
    """
    
    nps_score: Optional[float]
    """
    Net Promoter Score (most recent). Range: [−100, 100] or None.
    If None, impute with 0 during preprocessing.
    Promoters (>50) are retention signals.
    """
    
    # Support engagement
    support_tickets_90d: int
    """Number of support tickets opened in 90 days. Range: [0, 200]. High = engagement or churn risk."""
    
    escalation_rate: float
    """
    Fraction of tickets escalated to human. Range: [0.0, 1.0].
    High escalation rate may indicate problem resolution issues.
    """
    
    # Plan / tier
    plan_tier_ordinal: int
    """
    Subscription plan tier (ordinal encoding).
    Mapping: starter=0, pro=1, enterprise=2.
    Range: [0, 2]. Enterprise tiers have higher LTV, lower churn.
    """

        """Convert to feature array for model.predict()."""

            float(self.order_frequency_30d),
            float(self.order_frequency_90d),
            float(self.rfm_recency_days),
            float(self.rfm_frequency),
            self.rfm_monetary,
            self.avg_order_value,
            float(self.days_since_last_order),
            float(self.subscription_age_days),
            float(self.failed_payments_90d),
            float(self.dunning_stage_ordinal),
            self.sentiment_score,
            nps,
            float(self.support_tickets_90d),
            self.escalation_rate,
            float(self.plan_tier_ordinal),
        ]
    
    @staticmethod
    def feature_names() -> list[str]:
        """Feature names in order (for SHAP and model inspection)."""
```

### 2. LightGBM Model

```python
import lightgbm as lgb
import numpy as np
from pathlib import Path

class AccountHealthModel:
    """
    LightGBM binary classifier for churn prediction.
    
    Model artifact: models/account_health_v1.lgb (stored via DVC or S3)
    Versioning: metadata in model_versions DB table
    """
    
    # Model hyperparameters
    TRAIN_PARAMS = {
        "objective": "binary",
        "metric": "auc",
        "num_leaves": 31,
        "learning_rate": 0.05,
        "feature_fraction": 0.9,
        "bagging_fraction": 0.85,
        "min_child_samples": 20,
        "n_estimators": 200,
        "verbose": -1,
    }
    
    def __init__(self, artifact_path: str = "models/account_health_v1.lgb"):
        """
        Load model from artifact.
        
        Args:
            artifact_path: Path to .lgb file (or S3 URI)
        
        Raises:
            FileNotFoundError: if artifact not found
        """
        self.artifact_path = artifact_path
        self.model = None
        self.version = None
        self._load()
    
    def _load(self):
        """Load LightGBM booster from disk."""
        if not Path(self.artifact_path).exists():
            raise FileNotFoundError(f"Model artifact not found: {self.artifact_path}")
        
        self.model = lgb.Booster(model_file=self.artifact_path)
    
    def predict(self, features: HealthFeatures) -> float:
        """
        Predict churn probability for a customer.
        
        Args:
            features: HealthFeatures dataclass
        
        Returns:
            float in [0, 1]: P(churn). 0.65 threshold → 'at_risk', else 'healthy'.
        """
        X = np.array([features.to_array()], dtype=np.float32)
        pred_proba = self.model.predict(X)[0]
        return float(pred_proba)
    
    def predict_batch(self, features_list: list[HealthFeatures]) -> np.ndarray:
        """
        Batch predict for efficiency.
        
        Args:
            features_list: List of HealthFeatures
        
        Returns:
            numpy array of shape (len(features_list),), dtype float32
        """
        X = np.array([f.to_array() for f in features_list], dtype=np.float32)
        return self.model.predict(X)
    
    def get_feature_importance(self, importance_type: str = "gain") -> dict:
        """
        Get feature importance scores.
        
        Args:
            importance_type: 'gain' or 'split'
        
        Returns:
            Dict mapping feature names to importance scores
        """
        importances = self.model.feature_importance(importance_type=importance_type)
        names = HealthFeatures.feature_names()
        return dict(zip(names, importances))
```

### 3. SHAP Explainability

```python
import shap
from dataclasses import dataclass

@dataclass
class SHAPDriver:
    """Single SHAP feature attribution."""
    feature: str
    shap_value: float
    direction: str  # 'increases_risk' or 'decreases_risk'

@dataclass
class SHAPExplanation:
    """SHAP explanation for a prediction."""
    base_value: float
    """Model's average prediction (background dataset mean)."""
    
    prediction: float
    """Actual prediction for this customer."""
    
    top_drivers: list[SHAPDriver]
    """Top 5 features by |SHAP value|, sorted descending."""

def explain_prediction(
    model: AccountHealthModel,
    features: HealthFeatures,
) -> SHAPExplanation:
    """
    Explain churn prediction using SHAP TreeExplainer.
    
    Args:
        model: AccountHealthModel instance
        features: HealthFeatures to explain
    
    Returns:
        SHAPExplanation with base value, prediction, and top drivers
    
    Performance: <5ms per prediction (TreeExplainer is deterministic + fast)
    """
    
    # Convert to model-expected format
    X_explain = np.array([features.to_array()], dtype=np.float32)
    
    # Create explainer (cached per model to avoid recomputation)
    explainer = shap.TreeExplainer(model.model)
    
    # Compute SHAP values
    shap_values = explainer.shap_values(X_explain)
    
    # For binary classification, shap_values is list [shap_values_class_0, shap_values_class_1]
    # We care about class 1 (churn)
    shap_values_churn = shap_values[1][0]  # Shape: (15,)
    
    # Get base value (average model output)
    base_value = float(explainer.expected_value[1])
    
    # Compute prediction
    pred = model.predict(features)
    
    # Build top 5 drivers
    feature_names = HealthFeatures.feature_names()
    drivers = []
    
    for i, (fname, shap_val) in enumerate(zip(feature_names, shap_values_churn)):
        direction = "increases_risk" if shap_val > 0 else "decreases_risk"
        drivers.append(SHAPDriver(
            feature=fname,
            shap_value=float(shap_val),
            direction=direction,
        ))
    
    # Sort by absolute value, take top 5
    drivers.sort(key=lambda d: abs(d.shap_value), reverse=True)
    drivers = drivers[:5]
    
    return SHAPExplanation(
        base_value=base_value,
        prediction=pred,
        top_drivers=drivers,
    )
```

### 4. Scoring Pipeline

```python
from datetime import datetime
from dataclasses import dataclass

@dataclass
class HealthScore:
    """Result of health scoring."""
    customer_id: int
    tenant_id: int
    score: float  # P(churn) in [0, 1]
    label: str  # 'at_risk' or 'healthy'
    shap_explanation: SHAPExplanation
    scored_at: datetime

class HealthScoringPipeline:
    """Orchestrates health scoring: feature engineering → predict → explain → log."""
    
    def __init__(
        self,
        model: AccountHealthModel,
        db_session,
        audit_logger,
        threshold: float = 0.65,
    ):
        """
        Args:
            model: AccountHealthModel instance
            db_session: Database session (for audit logging)
            audit_logger: Audit logger (from py_core S1.8)
            threshold: Score threshold for 'at_risk' label (default 0.65)
        """
        self.model = model
        self.db = db_session
        self.audit = audit_logger
        self.threshold = threshold
    
    async def score(
        self,
        customer_id: int,
        tenant_id: int,
        customer_ctx,  # CustomerContext from S3.1
        billing_ctx,   # Billing context (failed payments, dunning)
        order_ctx,     # Order context (RFM, last order)
    ) -> HealthScore:
        """
        Score customer account health.
        
        Args:
            customer_id: Customer ID
            tenant_id: Tenant ID
            customer_ctx: CustomerContext (from S3.1 enrichment)
            billing_ctx: Billing info (failed payments, dunning stage)
            order_ctx: Order RFM data
        
        Returns:
            HealthScore with prediction, explanation, and audit entry
        """
        
        # Step 1: Build feature vector from enrichment contexts
        features = await self._build_features(
            customer_id, tenant_id, customer_ctx, billing_ctx, order_ctx
        )
        
        # Step 2: Predict with model
        score = self.model.predict(features)
        
        # Step 3: Explain with SHAP
        explanation = explain_prediction(self.model, features)
        
        # Step 4: Apply threshold
        label = "at_risk" if score >= self.threshold else "healthy"
        
        # Step 5: Log to audit table
        await self._log_to_audit(
            customer_id, tenant_id, score, label, explanation
        )
        
        return HealthScore(
            customer_id=customer_id,
            tenant_id=tenant_id,
            score=score,
            label=label,
            shap_explanation=explanation,
            scored_at=datetime.utcnow(),
        )
    
    async def _build_features(
        self, customer_id, tenant_id, customer_ctx, billing_ctx, order_ctx
    ) -> HealthFeatures:
        """
        Construct HealthFeatures from enrichment contexts.
        
        Feature engineering step: map domain objects to numeric features.
        """
        
        # Dunning stage: map string to ordinal
        dunning_map = {"none": 0, "warning": 1, "final": 2, "suspended": 3}
        dunning_ordinal = dunning_map.get(billing_ctx.get("dunning_stage", "none"), 0)
        
        # Plan tier: map string to ordinal
        plan_map = {"starter": 0, "pro": 1, "enterprise": 2}
        plan_ordinal = plan_map.get(customer_ctx.subscription_plan, 0)
        
        # NPS: use None if not available
        nps = customer_ctx.get("nps_score")  # May be None
        
        # Support escalation rate
        total_tickets = customer_ctx.get("support_tickets_90d", 0)
        escalated_tickets = customer_ctx.get("escalated_tickets_90d", 0)
        escalation_rate = escalated_tickets / total_tickets if total_tickets > 0 else 0.0
        
        return HealthFeatures(
            order_frequency_30d=order_ctx.get("order_frequency_30d", 0),
            order_frequency_90d=order_ctx.get("order_frequency_90d", 0),
            rfm_recency_days=order_ctx.get("rfm_recency_days", 0),
            rfm_frequency=order_ctx.get("rfm_frequency", 0),
            rfm_monetary=float(order_ctx.get("rfm_monetary", 0.0)),
            avg_order_value=float(order_ctx.get("avg_order_value", 0.0)),
            days_since_last_order=order_ctx.get("days_since_last_order", 0),
            subscription_age_days=customer_ctx.account_age_days,
            failed_payments_90d=billing_ctx.get("failed_payments_90d", 0),
            dunning_stage_ordinal=dunning_ordinal,
            sentiment_score=float(customer_ctx.get("sentiment_score", 0.0)),
            nps_score=nps,
            support_tickets_90d=total_tickets,
            escalation_rate=escalation_rate,
            plan_tier_ordinal=plan_ordinal,
        )
    
    async def _log_to_audit(
        self, customer_id, tenant_id, score, label, explanation
    ):
        """Log scoring decision to audit_entries table (from py_core S1.8)."""
        
        shap_json = {
            "base_value": explanation.base_value,
            "prediction": explanation.prediction,
            "top_drivers": [
                {
                    "feature": d.feature,
                    "shap_value": d.shap_value,
                    "direction": d.direction,
                }
                for d in explanation.top_drivers
            ],
        }
        
        await self.audit.log(
            tenant_id=tenant_id,
            resource_type="customer",
            resource_id=customer_id,
            action="health_score",
            changes={
                "score": score,
                "label": label,
                "shap_explanation": shap_json,
            },
            metadata={"model_version": "account_health_v1"},
        )
```

### 5. Threshold Tuning

```python
from sklearn.metrics import precision_recall_curve, f_beta_score
import matplotlib.pyplot as plt

def tune_threshold(
    y_true: np.ndarray,
    y_pred_proba: np.ndarray,
    beta: float = 2,
) -> tuple[float, dict]:
    """
    Tune decision threshold using F-beta score.
    
    Beta=2 weights recall 2x higher than precision, prioritizing churn detection
    (missing a churner is costlier than a false alarm).
    
    Args:
        y_true: Ground truth labels (0=healthy, 1=churned)
        y_pred_proba: Model predictions [0, 1]
        beta: Beta parameter for F-beta (default 2)
    
    Returns:
        (optimal_threshold, metrics_dict)
    
    Metrics dict includes:
        - threshold: selected threshold
        - f_beta: F-beta score at threshold
        - precision: precision@threshold
        - recall: recall@threshold
        - auc: ROC AUC (threshold-independent)
    """
    
    from sklearn.metrics import auc, roc_auc_score
    
    # Compute precision-recall curve
    precision, recall, thresholds = precision_recall_curve(y_true, y_pred_proba)
    
    # Compute F-beta for each threshold
    fbeta_scores = [
        f_beta_score(y_true, (y_pred_proba >= t).astype(int), beta=beta)
        for t in thresholds
    ]
    
    # Find threshold maximizing F-beta
    best_idx = np.argmax(fbeta_scores)
    optimal_threshold = thresholds[best_idx]
    optimal_fbeta = fbeta_scores[best_idx]
    
    # Metrics at optimal threshold
    y_pred_binary = (y_pred_proba >= optimal_threshold).astype(int)
    optimal_precision = precision[best_idx]
    optimal_recall = recall[best_idx]
    
    # Compute AUC (threshold-independent)
    roc_auc = roc_auc_score(y_true, y_pred_proba)
    
    metrics = {
        "threshold": float(optimal_threshold),
        "f_beta": float(optimal_fbeta),
        "precision": float(optimal_precision),
        "recall": float(optimal_recall),
        "auc": float(roc_auc),
    }
    
    # Plot precision-recall curve (optional, for model card)
    plt.figure(figsize=(10, 6))
    plt.plot(recall, precision, marker='.')
    plt.axvline(optimal_recall, color='r', linestyle='--', label=f'Optimal threshold={optimal_threshold:.3f}')
    plt.xlabel('Recall')
    plt.ylabel('Precision')
    plt.title(f'Precision-Recall Curve (F-beta={optimal_fbeta:.3f})')
    plt.legend()
    plt.grid()
    plt.savefig("models/precision_recall_curve.png")
    plt.close()
    
    return optimal_threshold, metrics
```

```yaml
- **Data bias:** Training data skewed toward high-engagement segments. Performance may degrade for dormant accounts.
- **Concept drift:** Customer behavior changes over time. Model requires retraining monthly (S3.8).
- **Payment-centric:** Dunning stage is strong predictor; model may overweight payment friction vs. product satisfaction.
- **No causal claims:** Correlations in SHAP values do not imply causation.

## Refresh Cadence

- **Training:** Weekly (S3.8 continuous learning loop)
- **Retraining trigger:** AUC drop >5% on validation set, or quarterly scheduled retraining
- **Monitoring:** Prediction distribution tracked via MLOps dashboard

- **Tone:** Inject empathetic tone in interactions with high-risk accounts
- **Escalation:** Prioritize at-risk customers for proactive outreach
- **Monitoring:** Alert CS teams to customers at churn risk

## Ethical Considerations

- **Fairness:** Threshold set to maximize recall (reduce false negatives), avoiding discrimination against small accounts.
- **Transparency:** SHAP explanations provided for every prediction, enabling accountability.
- **Human oversight:** Support teams can override scores in special cases.
```

### Feature Engineering

- **Dunning stage:** String enum ('none', 'warning', 'final', 'suspended') → ordinal (0, 1, 2, 3)
- **Plan tier:** String ('starter', 'pro', 'enterprise') → ordinal (0, 1, 2)
- **NPS:** If None, impute with 0 (median) during preprocessing
- **Sentiment:** Aggregated from support tickets or S3.1 enrichment

### Model Loading & Reloading

```python
import signal

    _health_model = get_health_model()
```

### SHAP Performance

- **TreeExplainer:** Deterministic, <5ms per prediction (vs. KernelExplainer ~500ms)
- **Caching:** Explainer instance cached per model to avoid recomputation
- **Batch explain:** Call `model.predict_batch()` then loop `explain_prediction()` for efficiency

### Model Artifact Storage

- **Local development:** `models/account_health_v1.lgb` (committed to git via DVC)
- **Production:** S3 URI (e.g., `s3://ml-models-bucket/account_health_v1.lgb`)
- **Fallback:** Fallback to previous model version if loading fails
