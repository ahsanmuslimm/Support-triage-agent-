# Sprint 0.3 - CI/CD Pipeline

## Objective
Create a GitHub Actions CI/CD workflow with layered testing gates: lint/type check → unit tests → integration tests → security scans → eval smoke tests.

## Implementation

### 1. `.github/workflows/ci.yml` (Main Pipeline)
```yaml
name: CI - Triage Agent

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main, develop]

env:
  REGISTRY: ghcr.io
  PYTHON_VERSION: "3.12"
  NODE_VERSION: "20"

jobs:
  # Stage 1: Lint & Type Check (< 1 min)
  lint-and-type:
    name: Lint & Type Check
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: ${{ env.PYTHON_VERSION }}
          cache: "pip"

      - name: Install uv
        run: pip install uv

      - name: Sync dependencies
        run: uv sync --all-extras

      - name: Run Ruff lint
        run: ruff check py_core/ packages/ --output-format github

      - name: Run Ruff format check
        run: ruff format --check py_core/ packages/

      - name: Set up Node
        uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: "npm"

      - name: Run mypy (Python type check)
        run: |
          uv run mypy py_core/src packages/*/src --strict \
            --no-incremental --show-error-codes

      - name: Run TypeScript type check
        run: |
          npm install -g typescript
          tsc --noEmit 2>&1 || true

  # Stage 2: Unit Tests (< 3 min)
  unit-tests:
    name: Unit Tests
    runs-on: ubuntu-latest
    needs: lint-and-type
    steps:
      - uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: ${{ env.PYTHON_VERSION }}
          cache: "pip"

      - name: Install uv
        run: pip install uv

      - name: Sync dependencies
        run: uv sync --all-extras --group dev

      - name: Run unit tests
        run: |
          uv run pytest tests/unit/ -v \
            --cov=py_core --cov=packages \
            --cov-report=xml --cov-report=term-missing \
            -n auto

      - name: Upload coverage to Codecov
        uses: codecov/codecov-action@v3
        with:
          files: ./coverage.xml
          flags: unittests
          fail_ci_if_error: false

  # Stage 3: Integration Tests (< 10 min)
  integration-tests:
    name: Integration Tests
    runs-on: ubuntu-latest
    needs: unit-tests
    services:
      postgres:
        image: pgvector/pgvector:pg18-latest
        env:
          POSTGRES_USER: triage
          POSTGRES_PASSWORD: password
          POSTGRES_DB: triage_dev
        options: >-
          --health-cmd pg_isready
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5
        ports:
          - 5432:5432

      redis:
        image: redis:7-alpine
        options: >-
          --health-cmd "redis-cli ping"
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5
        ports:
          - 6379:6379

    steps:
      - uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: ${{ env.PYTHON_VERSION }}
          cache: "pip"

      - name: Install uv
        run: pip install uv

      - name: Sync dependencies
        run: uv sync --all-extras --group dev

      - name: Run database migrations
        env:
          DATABASE_URL: postgresql://triage:password@localhost:5432/triage_dev
        run: |
          uv run alembic upgrade head

      - name: Run integration tests
        env:
          DATABASE_URL: postgresql://triage:password@localhost:5432/triage_dev
          REDIS_URL: redis://localhost:6379/0
          DATABASE_ASYNC_URL: postgresql+asyncpg://triage:password@localhost:5432/triage_dev
        run: |
          uv run pytest tests/integration/ tests/contracts/ -v \
            --cov=py_core --cov=packages \
            --cov-report=term-missing -n auto

  # Stage 4: Security Scans
  security:
    name: Security Scans
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Run Gitleaks (Secret Detection)
        uses: gitleaks/gitleaks-action@v2
        with:
          config-path: .gitleaks.toml
          fail: true

      - name: Run Semgrep (SAST)
        uses: returntocorp/semgrep-action@v1
        with:
          config: >-
            p/security-audit
            p/python
            p/typescript

      - name: Run Trivy (Dependency Scan)
        uses: aquasecurity/trivy-action@master
        with:
          scan-type: "fs"
          scan-ref: "."
          format: "sarif"
          output: "trivy-results.sarif"

      - name: Upload Trivy results to GitHub Security tab
        uses: github/codeql-action/upload-sarif@v2
        if: always()
        with:
          sarif_file: "trivy-results.sarif"

  # Stage 5: Eval Smoke Tests (PR only)
  eval-smoke:
    name: Eval Smoke Tests
    runs-on: ubuntu-latest
    needs: unit-tests
    if: github.event_name == 'pull_request'
    steps:
      - uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: ${{ env.PYTHON_VERSION }}
          cache: "pip"

      - name: Install uv
        run: pip install uv

      - name: Sync dependencies
        run: uv sync --all-extras --group dev

      - name: Run eval smoke tests (cached golden sets)
        env:
          EVAL_MODE: smoke
          GOLDEN_SET_SIZE: 50
        run: |
          uv run pytest tests/evals/ -v -m smoke --tb=short

  # Stage 6: Build Docker Images (On merge to main)
  build-images:
    name: Build Docker Images
    runs-on: ubuntu-latest
    needs: [lint-and-type, unit-tests, integration-tests, security]
    if: github.ref == 'refs/heads/main' && github.event_name == 'push'
    permissions:
      contents: read
      packages: write
    steps:
      - uses: actions/checkout@v4

      - name: Set up Docker Buildx
        uses: docker/setup-buildx-action@v2

      - name: Log in to Container Registry
        uses: docker/login-action@v2
        with:
          registry: ${{ env.REGISTRY }}
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}

      - name: Build and push API image
        uses: docker/build-push-action@v4
        with:
          context: .
          file: ./infra/Dockerfile.api
          push: true
          tags: |
            ${{ env.REGISTRY }}/${{ github.repository }}/api:latest
            ${{ env.REGISTRY }}/${{ github.repository }}/api:${{ github.sha }}

      - name: Build and push triage-worker image
        uses: docker/build-push-action@v4
        with:
          context: .
          file: ./infra/Dockerfile.triage-worker
          push: true
          tags: |
            ${{ env.REGISTRY }}/${{ github.repository }}/triage-worker:latest
            ${{ env.REGISTRY }}/${{ github.repository }}/triage-worker:${{ github.sha }}

  # Final Status
  ci-status:
    name: CI Status
    runs-on: ubuntu-latest
    needs: [lint-and-type, unit-tests, integration-tests, security]
    if: always()
    steps:
      - name: Check CI Status
        run: |
          if [[ "${{ needs.lint-and-type.result }}" == "failure" || \
                "${{ needs.unit-tests.result }}" == "failure" || \
                "${{ needs.integration-tests.result }}" == "failure" || \
                "${{ needs.security.result }}" == "failure" ]]; then
            echo "❌ CI Pipeline Failed"
            exit 1
          else
            echo "✅ CI Pipeline Passed"
          fi
```

### 2. `.gitleaks.toml` (Secret Detection Config)
```toml
title = "Triage Agent - Gitleaks Config"

# Scan for secrets
[[rules]]
description = "AWS Access Key"
regex = '''(?i)aws_access_key_id\s*=\s*[A-Za-z0-9/+=]{40}'''
keywords = ["aws_access_key_id"]
secretGroup = 1

[[rules]]
description = "Private API Key"
regex = '''(?i)(private_key|secret_key|api_key)\s*[=:]\s*[A-Za-z0-9_\-]{32,}'''
keywords = ["private_key", "secret_key", "api_key"]
secretGroup = 1

# Allowlist patterns
[allowlist]
commits = []
repos = []
paths = [
  "(?i)(.*)?test(.*)?",
  "(?i)(.*)?fake(.*)?",
  "(?i)example(.*)",
]
```

### 3. `.semgrep.yml` (SAST Rules)
```yaml
rules:
  - id: no-hardcoded-secrets
    pattern-either:
      - pattern: |
          $KEY = "sk-..."
      - pattern: |
          password = "..."
    message: "Hardcoded secret detected"
    severity: ERROR
    languages: [python]

  - id: sql-injection-risk
    pattern-either:
      - pattern: |
          execute($QUERY + $VAR)
      - pattern: |
          f"SELECT * FROM {$TABLE}"
    message: "Potential SQL injection"
    severity: ERROR
    languages: [python]

  - id: missing-type-hints
    pattern: |
      def $FUNC(...):
    message: "Function missing type hints"
    severity: WARNING
    languages: [python]
```

```yaml
name: Nightly - Full Evaluations

on:
  schedule:
    # Every night at 2 AM UTC
    - cron: "0 2 * * *"
  workflow_dispatch:

jobs:
  full-evals:
    name: Full Eval Suite
    runs-on: ubuntu-latest
    env:
      ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
      LITELLM_API_KEY: ${{ secrets.LITELLM_API_KEY }}
    steps:
      - uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: "3.12"
          cache: "pip"

      - name: Install uv
        run: pip install uv

      - name: Sync dependencies
        run: uv sync --all-extras --group dev

      - name: Run full eval suite with real LLM
        env:
          EVAL_MODE: full
          GOLDEN_SET_SIZE: 300
        run: |
          uv run pytest tests/evals/ -v --tb=short \
            --junitxml=eval-results.xml

      - name: Mutation Testing
        run: |
          uv run mutmut run --tests-dir tests/unit/ \
            --paths-to-mutate py_core/src,packages/ \
            --min-covered-mutants 70

      - name: Upload eval results
        uses: actions/upload-artifact@v3
        if: always()
        with:
          name: eval-results
          path: |
            eval-results.xml
            .mutmut-results.json

      - name: Report to Slack
        if: failure()
        uses: slackapi/slack-github-action@v1.24.0
        with:
          webhook-url: ${{ secrets.SLACK_WEBHOOK }}
          payload: |
            {
              "text": "❌ Nightly evals failed for ${{ github.repository }}",
              "blocks": [
                {
                  "type": "section",
                  "text": {
                    "type": "mrkdwn",
                    "text": "*Nightly Evaluation Failed*\n${{ github.server_url }}/${{ github.repository }}/actions/runs/${{ github.run_id }}"
                  }
                }
              ]
            }
```

### 6. `tests/conftest.py` (Pytest Configuration)
```python
import os
import pytest
from pathlib import Path

# Set test environment
os.environ.setdefault("ENVIRONMENT", "test")

# Add markers
def pytest_configure(config):
    config.addinivalue_line("markers", "smoke: mark test as a smoke test")
    config.addinivalue_line("markers", "unit: mark test as a unit test")
    config.addinivalue_line("markers", "integration: mark test as an integration test")
    config.addinivalue_line("markers", "eval: mark test as an evaluation test")
    config.addinivalue_line("markers", "slow: mark test as slow")
    config.addinivalue_line("markers", "benchmark: mark test as a benchmark")

# Plugin configuration
def pytest_collection_modifyitems(config, items):
    for item in items:
        # Auto-mark based on file location
        if "unit" in str(item.fspath):
            item.add_marker(pytest.mark.unit)
        elif "integration" in str(item.fspath):
            item.add_marker(pytest.mark.integration)
        elif "acceptance" in str(item.fspath):
            item.add_marker(pytest.mark.acceptance)
        elif "eval" in str(item.fspath):
            item.add_marker(pytest.mark.eval)
```

## CI/CD Pipeline Stages

### 1. **Lint & Type Check** (< 1 min)
- Ruff: Python linting
- mypy: Python strict type checking
- TypeScript: Frontend type checking
- **Fails PR if:** Any lint errors or type mismatches

### 2. **Unit Tests** (< 3 min)
- Run with pytest + xdist (parallel)
- Target 70% code coverage
- **Fails PR if:** Coverage drops or tests fail

### 3. **Integration Tests** (< 10 min)
- Real PostgreSQL + Redis services
- Database migrations verified
- Contract tests for all adapters
- **Fails PR if:** Any integration test fails

### 4. **Security Scans**
- Gitleaks: Detect hardcoded secrets
- Semgrep: SAST for Python/TypeScript
- Trivy: Dependency vulnerability scanning
- **Fails PR if:** High/critical findings

### 5. **Eval Smoke Tests** (PR only)
- Run 50-row golden sets (cached)
- LLM calls use recorded cassettes
- **Fails PR if:** Metric regressions detected

### 6. **Docker Build** (main branch only)
- Build API, triage-worker, knowledge-worker images
- Push to ghcr.io
- Tag with git SHA

## Local Testing Before Commit

```bash
# Run same checks as CI locally
make lint          # Ruff + format
make typecheck     # mypy + tsc
make test          # Unit + integration
make smoke         # Health checks
```

## Skipping CI Checks

To skip CI on a commit:
```bash
git commit --no-verify  # Skip pre-commit hooks
```

**Note:** CI will still run on push. Use sparingly.
