---

## Overview

Identity resolution merges customer identities across channels and systems into a canonical identity:

- **Email-based:** `customer@example.com` (primary identity anchor)
- **Phone-based:** `+1-555-0123` (secondary, merged with email if both present)
- **External IDs:** Zendesk user_id, Shopify customer_id, Stripe customer_id (channel-specific, linked to email/phone)

**Result:** Every conversation is linked to a canonical customer identity, enabling cross-channel context (order history, account status, previous issues).

## Technical Specification

### 1. Identity Types & Resolution Priority

| Identity Type | Format | Example | Confidence | Merge Rule |
|---|---|---|---|---|
| **Email** | RFC 5321 | `customer@example.com` | IAL1 (channel-asserted) | Primary anchor |
| **Phone** | E.164 | `+1-555-0123` | IAL1 (channel-asserted) | Secondary; merge to email if known |
| **Zendesk User ID** | Integer | `12345` | IAL2 (Zendesk verified) | External ID, link to email |
| **Shopify Customer ID** | UUID | `gid://shopify/Customer/123` | IAL2 (Shopify verified) | External ID, link to email |
| **Stripe Customer ID** | String | `cus_abc123def456` | IAL2 (Stripe verified) | External ID, link to email |
| **Anonymous** | Device fingerprint | `device-abc123` | IAL0 (unverified) | Temporary; upgrade when email known |

### 2. Data Model

#### 2.1 Customers Table

```sql
CREATE TABLE customers (
    id BIGSERIAL PRIMARY KEY,
    tenant_id BIGINT NOT NULL REFERENCES tenants(id),
    canonical_email VARCHAR(255),           -- Primary identity anchor
    canonical_phone VARCHAR(20),            -- Secondary anchor (E.164)
    name VARCHAR(255),                      -- Display name
    ial INTEGER DEFAULT 0,                  -- Identity Assurance Level (0-2)
    ial_email INTEGER DEFAULT 0,            -- IAL per channel
    ial_phone INTEGER DEFAULT 0,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(tenant_id, canonical_email),     -- Unique per tenant
    UNIQUE(tenant_id, canonical_phone),
    CHECK (canonical_email IS NOT NULL OR canonical_phone IS NOT NULL)
);

CREATE INDEX idx_customers_tenant_email ON customers(tenant_id, canonical_email);
CREATE INDEX idx_customers_tenant_phone ON customers(tenant_id, canonical_phone);
```

#### 2.2 Customer Identities Table (Aliases)

```sql
CREATE TABLE customer_identities (
    id BIGSERIAL PRIMARY KEY,
    tenant_id BIGINT NOT NULL REFERENCES tenants(id),
    customer_id BIGINT NOT NULL REFERENCES customers(id),
    identity_type VARCHAR(50) NOT NULL,    -- 'email', 'phone', 'zendesk_user_id', 'shopify_customer_id', etc.
    identity_value VARCHAR(255) NOT NULL,
    channel VARCHAR(50),                   -- 'zendesk', 'shopify', 'stripe', 'web_chat', etc.
    ial INTEGER DEFAULT 1,                 -- Assurance level for this identity
    verified_at TIMESTAMP,                 -- When identity was verified
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(tenant_id, identity_type, identity_value),  -- Prevent duplicate identities per tenant
    FOREIGN KEY (tenant_id) REFERENCES tenants(id),
    FOREIGN KEY (customer_id) REFERENCES customers(id)
);

CREATE INDEX idx_customer_identities_type_value ON customer_identities(tenant_id, identity_type, identity_value);
```

### 3. Identity Resolution Flow

#### 3.1 Inbound Message: Extract Identities

```python
def extract_identities(message: CanonicalMessage, channel: str) -> dict:
    """Extract identity hints from normalized message."""
    identities = {
        "email": message.from_address if channel in ["email", "web"] else None,
        "phone": message.phone_number if channel in ["sms", "whatsapp"] else None,
        "external_id": message.metadata.get("customer_id"),  # Channel-specific
        "name": message.from_name,
    }
    return {k: v for k, v in identities.items() if v}
```

#### 3.2 Resolve or Create Customer

```python
async def resolve_customer(
    tenant_id: int,
    identities: dict,
    channel: str
) -> tuple[Customer, bool]:  # (customer, was_created)
    """
    Resolve customer identity.
    
    Rules:
    1. If email exists → use canonical_email as anchor
    2. If phone exists (no email) → use canonical_phone as anchor
    3. If external_id exists → link to existing customer by email/phone
    4. If no match → create new customer (anonymous initially)
    """
    
    email = identities.get("email")
    phone = identities.get("phone")
    external_id = identities.get("external_id")
    
    # Rule 1: Email lookup
    if email:
        customer = await db.customers.get(tenant_id, email)
        if customer:
            return customer, False
    
    # Rule 2: Phone lookup (if no email)
    if phone and not email:
        customer = await db.customers.get(tenant_id, phone=phone)
        if customer:
            return customer, False
    
    # Rule 3: External ID lookup
    if external_id:
        identity = await db.customer_identities.get(
            tenant_id,
            identity_type=f"{channel}_id",
            identity_value=external_id
        )
        if identity:
            return identity.customer, False
    
    # Rule 4: Create new customer
    customer = await db.customers.create(
        tenant_id=tenant_id,
        canonical_email=email,
        canonical_phone=phone,
        name=identities.get("name"),
        ial=0,  # Unverified until verified
    )
    
    # Link external ID
    if external_id:
        await db.customer_identities.create(
            tenant_id=tenant_id,
            customer_id=customer.id,
            identity_type=f"{channel}_id",
            identity_value=external_id,
            channel=channel,
            ial=1,  # Channel-verified
        )
    
    return customer, True
```

### 4. Merge Strategy

When multiple identities arrive for same customer:

```python
async def merge_identities(
    customer_id: int,
    new_email: Optional[str] = None,
    new_phone: Optional[str] = None,
) -> Customer:
    """
    Merge new identities into existing customer.
    
    Rules:
    - If canonical_email is None → set it to new_email (upgrade from anonymous)
    - If new_email differs from canonical_email → store as alias, don't merge
    - If new_phone differs from canonical_phone → link via customer_identities
    """
    
    customer = await db.customers.get(customer_id)
    
    if new_email and not customer.canonical_email:
        # Upgrade from anonymous to email-based
        customer.canonical_email = new_email
        customer.ial = max(customer.ial, 1)
    
    if new_email and customer.canonical_email != new_email:
        # Store as alias (don't overwrite primary)
        await db.customer_identities.create(
            customer_id=customer_id,
            identity_type="email_alias",
            identity_value=new_email,
            ial=1,
        )
    
    if new_phone and not customer.canonical_phone:
        # Add phone as secondary
        customer.canonical_phone = new_phone
        customer.ial = max(customer.ial, 1)
    
    await db.customers.update(customer)
    return customer
```

### 5. Cross-Tenant Isolation

**Critical:** Prevent identity leakage across tenants.

```python
async def get_customer_identity(tenant_id: int, identity_key: str):
    """
    Lookup customer by identity.
    
    Uses RLS to ensure tenant isolation.
    """
    
    # Query includes WHERE tenant_id = $1
    customer = await db.customers.get(
        tenant_id=tenant_id,
        identity_key=identity_key
    )
    
    if customer.tenant_id != tenant_id:
        raise PermissionError("Tenant mismatch")
    
    return customer
```

### 6. Identity Assurance Levels (IAL)

| IAL | Meaning | Example |
|---|---|---|
| **0** | Unverified, anonymous | Device fingerprint, no email |
| **1** | Channel-asserted, not verified | Email from web form, self-signed |
| **2** | Verified by identity provider | Email + verification code, Zendesk user |
| **3** | Verified + out-of-band proof | Email + phone SMS code (future) |

**Update IAL on verification:**

```python
async def verify_customer_email(customer_id: int, token: str):
    """Verify customer email via OTP/link."""
    
    customer = await db.customers.get(customer_id)
    
    if verify_otp_token(customer.canonical_email, token):
        customer.ial = max(customer.ial, 2)
        customer.ial_email = 2
        await db.customers.update(customer)
        
        return customer
    
    raise ValueError("Invalid token")
```

### 8. Privacy & Pseudonymization (Preview)

For customers who opt into anonymization, replace identity with pseudonym:

```python
async def pseudonymize_customer(customer_id: int):
    """Replace identity with pseudonym (reversible via vault)."""
    
    customer = await db.customers.get(customer_id)
    
    # Generate pseudonym
    pseudonym = f"cust_{uuid.uuid4().hex[:12]}"
    
    # Store mapping in vault (encrypted, access-controlled)
    await vault.store_pseudonym(customer_id, pseudonym)
    
    # Clear PII from customer record
    customer.canonical_email = None
    customer.canonical_phone = None
    customer.name = pseudonym
    
    await db.customers.update(customer)
```

### Example: Identity Resolver

```python
# packages/api/src/triage/identity/resolver.py
from typing import Optional, Tuple
from datetime import datetime
import uuid

class IdentityResolver:
    def __init__(self, db_session):
        self.db = db_session
    
    async def resolve_customer(
        self,
        tenant_id: int,
        email: Optional[str] = None,
        phone: Optional[str] = None,
        external_id: Optional[str] = None,
        channel: str = "unknown",
    ) -> Tuple[dict, bool]:  # (customer_dict, was_created)
        """
        Resolve customer identity with multi-channel merge.
        
        Priority:
        1. Email → canonical anchor
        2. Phone → secondary anchor
        3. External ID → link to existing
        4. Create if no match
        """
        
        # Normalize email
        if email:
            email = email.lower().strip()
        
        # Normalize phone (E.164)
        if phone:
            phone = normalize_phone(phone)
        
        # Try email lookup first
        if email:
            customer = await self.db.query(
                "SELECT * FROM customers WHERE tenant_id = $1 AND canonical_email = $2",
                tenant_id, email
            ).first()
            if customer:
                return customer, False
        
        # Try phone lookup (if no email)
        if phone and not email:
            customer = await self.db.query(
                "SELECT * FROM customers WHERE tenant_id = $1 AND canonical_phone = $2",
                tenant_id, phone
            ).first()
            if customer:
                return customer, False
        
        # Try external ID lookup
        if external_id:
            identity = await self.db.query(
                "SELECT * FROM customer_identities WHERE tenant_id = $1 AND identity_type = $2 AND identity_value = $3",
                tenant_id, f"{channel}_id", external_id
            ).first()
            if identity:
                customer = await self.db.query(
                    "SELECT * FROM customers WHERE id = $1",
                    identity.customer_id
                ).first()
                return customer, False
        
        # Create new customer (anonymous or email-based)
        customer_id = await self.db.execute(
            """INSERT INTO customers (tenant_id, canonical_email, canonical_phone, ial, created_at)
               VALUES ($1, $2, $3, $4, $5) RETURNING id""",
            tenant_id, email, phone, 0 if not email else 1, datetime.utcnow()
        )
        
        # Link external ID if provided
        if external_id:
            await self.db.execute(
                """INSERT INTO customer_identities (tenant_id, customer_id, identity_type, identity_value, channel, ial, created_at)
                   VALUES ($1, $2, $3, $4, $5, $6, $7)""",
                tenant_id, customer_id, f"{channel}_id", external_id, channel, 1, datetime.utcnow()
            )
        
        # Fetch and return
        customer = await self.db.query(
            "SELECT * FROM customers WHERE id = $1",
            customer_id
        ).first()
        
        return customer, True
```

## Open Questions

1. Should we support phone number verification (SMS OTP)?
   - **Answer:** Yes, deferred to S3 (verification flows)
2. What if customer updates email in Zendesk but old email in system?
   - **Answer:** Store as alias (email_alias identity type); don't overwrite primary
3. Should we deduplicate similar emails (e.g., `john.doe@example.com` vs `johndoe@example.com`)?
   - **Answer:** No (too error-prone); rely on customer verification
4. How do we handle corporate email domains (e.g., multiple people from `@company.com`)?
   - **Answer:** Each email is unique; identity resolution per email, not domain
