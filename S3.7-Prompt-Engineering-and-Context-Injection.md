# S3.7 — Prompt Engineering & Context Injection

**Sprint:** 3 (Enrichment & Context Layers)  
**Deliverable:** Dynamic prompt templates, tone selector, context injection pipeline  
**Effort:** 2.5 days  
**Dependencies:** S3.1 (Customer enrichment), S2.7 (Triage agent graph), S2.2 (Health score)

---

## Overview

**Prompt engineering layer** builds dynamic LLM prompts that inject enriched customer context during triage graph execution—before the first LLM call of each turn, not post-decision.

- **Tone injection:** Empathy for churn risk, urgency for high-value orders, formal for enterprise
- **Context insertion points:** System prompt intro, decision rationale block, escalation justification
- **Token budget:** Enforce max 4096 tokens; truncate few-shot section first, preserve system intro and escalation block

This ensures the triage agent (S2.7) receives contextually aware prompts that make better routing and escalation decisions.

### 2. Context Injection Points

```python
from enum import Enum
from typing import Optional

class InjectionPoint(Enum):
    """Where to inject context into the prompt."""
    INTRO = 'system_intro'
    DECISION_RATIONALE = 'decision_rationale'
    ESCALATION = 'escalation_block'

def inject_context(
    template: str,
    context: dict,
    injection_point: InjectionPoint
) -> str:
    """
    Inject enriched customer context into a template section.
    
    Args:
        template: Jinja2 template string
        context: Dictionary of variables to inject
        injection_point: Which section to target
    
    Returns:
        Rendered template string with variables replaced
    
    Notes:
        - Uses Jinja2 with autoescape=False (internal use only, no user HTML)
        - Raises TemplateError if variables missing or syntax invalid
    """
    from jinja2 import Template, TemplateError
    
    try:
        tmpl = Template(template, autoescape=False, trim_blocks=True)
        rendered = tmpl.render(**context)
        
        # Validate no unrendered placeholders remain
        if '{{' in rendered or '{%' in rendered:
            raise ValueError(f"Unrendered placeholders remain in {injection_point.value}")
        
        return rendered
    
    except TemplateError as e:
        raise ValueError(f"Template rendering failed at {injection_point.value}: {e}")
```

### 3. Tone Selector

```python
from dataclasses import dataclass
from typing import Literal

@dataclass
class BillingContext:
    churn_risk_signal: bool
    dunning_stage: Optional[str]  # 'none', 'warning', 'past_due', 'final'
    subscription_status: str

@dataclass
class OrderContext:
    risk_signals: list[str]  # e.g., ['high_value_order', 'delayed_shipping']
    recent_order_value: float
    high_value_threshold: float = 500.0

@dataclass
class HealthScore:
    label: str  # 'at_risk', 'at_risk_high_value', 'healthy', 'churn_imminent'
    score: float  # 0-1

def select_tone(
    customer_ctx: 'CustomerContext',
    billing_ctx: BillingContext,
    order_ctx: OrderContext,
    health_score: HealthScore
) -> Literal['empathy', 'urgency', 'formal', 'neutral']:
    """
    Select prompt tone based on customer signals.
    
    Priority order:
    1. health_score.label == 'at_risk' OR billing_ctx.churn_risk_signal → 'empathy'
    2. customer_ctx.is_vip AND 'high_value_order' in order_ctx.risk_signals → 'urgency'
    3. customer_ctx.subscription_plan == 'enterprise' → 'formal'
    4. else → 'neutral'
    
    Returns:
        Tone string used to select base template
    """
    # Priority 1: Churn risk
    if health_score.label == 'at_risk' or billing_ctx.churn_risk_signal:
        return 'empathy'
    
    # Priority 2: VIP + high-value order
    if (
        customer_ctx.is_vip and
        'high_value_order' in order_ctx.risk_signals
    ):
        return 'urgency'
    
    # Priority 3: Enterprise
    if customer_ctx.subscription_plan == 'enterprise':
        return 'formal'
    
    # Default
    return 'neutral'
```

### 4. Few-Shot Example Library

```python
import yaml
from pathlib import Path
from typing import Literal

class FewShotLibrary:
    """
    Library of few-shot examples for different (tone, intent) combinations.
    
    Examples stored in YAML at config/few_shot_examples.yaml.
    Each (tone, intent) pair has 2 input/output examples.
    """
    
    def __init__(self, yaml_path: str = "config/few_shot_examples.yaml"):
        """Load examples from YAML file."""
        self.yaml_path = Path(yaml_path)
        self.examples = self._load_yaml()
    
    def _load_yaml(self) -> dict:
        """Load few-shot examples from YAML."""
        try:
            with open(self.yaml_path, 'r') as f:
                return yaml.safe_load(f)
        except FileNotFoundError:
            raise FileNotFoundError(
                f"Few-shot YAML not found at {self.yaml_path}. "
                "Ensure config/few_shot_examples.yaml exists."
            )
    
    def get_examples(
        self,
        tone: Literal['empathy', 'urgency', 'formal', 'neutral'],
        intent: str
    ) -> list[dict]:
        """
        Retrieve 2 input/output examples for a (tone, intent) pair.
        
        Args:
            tone: 'empathy', 'urgency', 'formal', or 'neutral'
            intent: 'billing_dispute', 'technical_issue', 'refund_request', etc.
        
        Returns:
            List of 2 dicts, each with 'input' and 'output' keys
        
        Example:
            >>> lib.get_examples('empathy', 'billing_dispute')
            [
                {
                    'input': 'I was charged twice...',
                    'output': 'Tier 2 - Billing. Escalate to specialist...'
                },
                { ... }
            ]
        """
        key = f"{tone}_{intent}"
        
        if key not in self.examples:
            # Fallback to neutral tone if specific tone not found
            key = f"neutral_{intent}"
            if key not in self.examples:
                raise ValueError(
                    f"No examples found for tone='{tone}', intent='{intent}'"
                )
        
        examples = self.examples[key]
        if not isinstance(examples, list) or len(examples) < 2:
            raise ValueError(
                f"Expected 2+ examples for {key}, got {len(examples) if isinstance(examples, list) else 0}"
            )
        
        return examples[:2]  # Return first 2
```

### 5. Context Injection Pipeline

```python
from typing import Optional
import tiktoken

@dataclass
class EnrichmentBundle:
    """Complete enrichment data for prompt building."""
    customer_ctx: 'CustomerContext'
    billing_ctx: BillingContext
    order_ctx: OrderContext
    sentiment_ctx: dict  # e.g., {'sentiment_label': 'frustrated', 'key_phrases': [...]}
    health_score: HealthScore

def build_prompt(
    customer_id: int,
    tenant_id: int,
    intent: str,
    enrichment_bundle: EnrichmentBundle,
    max_tokens: int = 4096,
    target_max_tokens: int = 3500
) -> str:
    """
    Build complete LLM prompt with injected customer context.
    
    Pipeline:
    1. Select tone based on customer signals
    2. Select base template for tone
    3. Inject context at INTRO + DECISION_RATIONALE
    4. Append few-shot examples
    5. Truncate if over token budget (few-shot first, then context)
    
    Args:
        customer_id: Customer ID
        tenant_id: Tenant ID
        intent: Ticket intent ('billing_dispute', 'technical_issue', etc.)
        enrichment_bundle: Complete enrichment data
        max_tokens: Hard max for prompt (4096)
        target_max_tokens: Try to fit under this (3500); truncate if needed
    
    Returns:
        Assembled prompt string (≤ max_tokens)
    
    Raises:
        ValueError: If tone selection fails or template rendering fails
    """
    from jinja2 import Template
    
    # Step 1: Select tone
    tone = select_tone(
        enrichment_bundle.customer_ctx,
        enrichment_bundle.billing_ctx,
        enrichment_bundle.order_ctx,
        enrichment_bundle.health_score
    )
    
    # Step 2: Get base template
    engine = PromptTemplateEngine()
    base_template = engine.templates.get(tone, engine.templates['default'])
    
    # Step 3: Prepare context variables
    context_vars = {
        'customer_name': enrichment_bundle.customer_ctx.name,
        'account_age_days': enrichment_bundle.customer_ctx.account_age_days,
        'subscription_plan': enrichment_bundle.customer_ctx.subscription_plan,
        'total_spent': enrichment_bundle.customer_ctx.total_spent,
        'nps_segment': enrichment_bundle.customer_ctx.flags[0] if enrichment_bundle.customer_ctx.flags else 'unclassified',
        'churn_signal_reason': 'Inactive for 30+ days' if enrichment_bundle.billing_ctx.churn_risk_signal else None,
        'dunning_stage': enrichment_bundle.billing_ctx.dunning_stage or 'none',
        'top_shap_driver': 'High churn correlation with price sensitivity',
        'intent': intent,
        'health_score_label': enrichment_bundle.health_score.label,
        'order_context_risk_signal': enrichment_bundle.order_ctx.risk_signals[0] if enrichment_bundle.order_ctx.risk_signals else 'none',
        'recent_order_value': enrichment_bundle.order_ctx.recent_order_value,
        'issue_severity': 'high' if enrichment_bundle.order_ctx.risk_signals else 'medium',
        'sla_response_time': '4h' if tone == 'formal' else None,
        'account_manager_name': 'N/A',  # Fetch from DB in production
        'account_manager_email': 'N/A',
        'contract_value_annual': enrichment_bundle.customer_ctx.total_spent * 12,
        'ticket_id': f"{tenant_id}_{customer_id}_{intent}",
        'severity_level': 'HIGH' if enrichment_bundle.health_score.score > 0.7 else 'MEDIUM',
    }
    
    # Render template
    prompt = inject_context(base_template, context_vars, InjectionPoint.INTRO)
    
    # Step 4: Append few-shot examples
    few_shot_lib = FewShotLibrary()
    try:
        examples = few_shot_lib.get_examples(tone, intent)
        examples_text = "\n".join([
            f"Example {i+1}:\nInput: {ex['input']}\nOutput: {ex['output']}"
            for i, ex in enumerate(examples)
        ])
        prompt += f"\n\n[FEW_SHOT_EXAMPLES]\n{examples_text}"
    except ValueError:
        # No examples found for this (tone, intent); skip
        pass
    
    # Step 5: Token budget enforcement
    encoding = tiktoken.get_encoding("cl100k_base")
    tokens = len(encoding.encode(prompt))
    
    if tokens > target_max_tokens:
        # Truncate few-shot section first
        prompt_without_examples = prompt.split('[FEW_SHOT_EXAMPLES]')[0]
        tokens_without_examples = len(encoding.encode(prompt_without_examples))
        
        if tokens_without_examples > target_max_tokens:
            # If still over, truncate context (but preserve system intro and escalation)
            # This is a fallback; in production, consider summarizing context
            import logging
            logger = logging.getLogger(__name__)
            logger.warning(
                f"Prompt exceeds target ({tokens_without_examples} tokens). "
                f"Consider truncating customer context or reducing intent detail."
            )
        
        prompt = prompt_without_examples
        tokens = len(encoding.encode(prompt))
    
    if tokens > max_tokens:
        raise ValueError(
            f"Prompt exceeds hard max ({tokens} > {max_tokens} tokens). "
            "Cannot assemble prompt within token constraints."
        )
    
    return prompt
```

## API / Schema

```python
# Called by S2.7 Triage Graph

# No external API. Internal function build_prompt() called inside triage graph:

# Example usage in S2.7:

async def execute_triage_turn(
    self,
    state: TriageState,
    enrichment_bundle: EnrichmentBundle
) -> str:
    """
    Execute one triage turn with injected context.
    
    1. Build dynamic prompt
    2. Call LLM with prompt
    3. Parse response
    """
    # Build prompt with enriched context
    prompt = build_prompt(
        customer_id=state.customer_id,
        tenant_id=state.tenant_id,
        intent=state.ticket_intent,
        enrichment_bundle=enrichment_bundle,
        max_tokens=4096,
        target_max_tokens=3500
    )
    
    # Call LLM
    response = await self.llm_client.complete(
        prompt=prompt,
        model="gpt-4",
        temperature=0.3,  # Low temp for deterministic routing
        max_tokens=500
    )
    
    return response.text
```

**Returns:** `str` (assembled LLM prompt, ≤ 4096 tokens)

**Token Budget Enforcement:**
- Target: 3500 tokens (system intro + context + escalation + few-shot)
- If exceeded: truncate few-shot section first
- If still exceeded: truncate customer context (preserve system intro + escalation)
- Hard max: 4096 tokens (raise error if exceeded)

## Implementation Notes

- **Templates:** Rendered with Jinja2 >=3.1 (`Environment(autoescape=False)` for internal use only)
- **Token counting:** `tiktoken` (cl100k_base encoding) for OpenAI compatibility
- **Tone selection:** Deterministic (no LLM call); priority-based rules
- **Few-shot examples:** Stored in `config/few_shot_examples.yaml`, versioned in git; changes require review
- **Injection timing:** Happens inside triage graph `execute()` method, before first LLM call of each turn
- **No DB changes:** All data sourced from enrichment (S3.1) and billing context

def test_tone_classification_keyword_match():
    """
    Run 50 assembled prompts through lightweight classifier.
    Assert tone label matches expected (≥90% accuracy).
    """
    keyword_map = {
        'empathy': ['understand', 'appreciate', 'help', 'support', 'concern'],
        'urgency': ['urgent', 'immediate', 'priority', 'quickly', 'expedite'],
        'formal': ['SLA', 'account manager', 'contract', 'engineering', 'technical'],
        'neutral': ['route', 'tier', 'self-service', 'escalate']
    }
    
    test_cases = [
        # (enrichment_bundle, expected_tone)
        (bundle_churn_risk, 'empathy'),
        (bundle_vip_high_value, 'urgency'),
        (bundle_enterprise, 'formal'),
        (bundle_standard, 'neutral'),
    ]
    
    matches = 0
    for bundle, expected_tone in test_cases * 12.5:  # ~50 tests
        prompt = build_prompt(..., enrichment_bundle=bundle)
        keywords = keyword_map[expected_tone]
        prompt_lower = prompt.lower()
        
        if any(kw in prompt_lower for kw in keywords):
            matches += 1
    
    accuracy = matches / 50
    assert accuracy >= 0.90, f"Tone classification accuracy {accuracy:.2%} < 90%"
