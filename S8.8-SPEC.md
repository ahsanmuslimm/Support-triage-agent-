# S8.8: Drift Monitoring

## Overview
Detect model and data drift in production.

## Drift Signals
1. **PSI**: Population Stability Index (intent distribution shift)
   - Alert: PSI >0.2
2. **Centroid Drift**: Embedding space movement per class
   - Per-class drift in embedding space
3. **OOD Rate**: % of predictions marked out-of-distribution
   - Alert: OOD rate >10%
4. **Concept Drift**: F1 on 7-day rolling window
   - Performance degradation detection

## Outputs
- Prometheus metrics export
- Drift monitoring report
- Alert triggers for on-call

## Baseline Fitting
- PSI baseline from initial distribution
- Centroid baselines from initial embeddings
- Concept drift F1 baseline
