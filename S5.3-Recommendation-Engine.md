# S5.3 — Recommendation Engine

**Sprint:** 5 (Proactive Intelligence & Optimization)  
**Deliverable:** Hybrid KB recommendation engine with A/B testing framework  
**Effort:** 2 days  
**Dependencies:** S3.5 (KB pipeline), S5.1 (Lifecycle stage), S4.7 (Feedback loop)

---

## Overview

The Recommendation Engine drives proactive self-service by surfacing the most relevant Knowledge Base articles at the moment a customer needs them. The engine combines three orthogonal recommendation strategies to maximize coverage and conversion:

1. **Content-Based Filtering:** TF-IDF vectorization + cosine similarity to find semantically similar articles
2. **Collaborative Filtering:** Customer-segment × article-popularity matrix (ALS factorization) to recommend "popular with customers like you"
3. **Self-Service Path Routing:** Decision tree that guides users through escalation stages (FAQ → KB search → contact support)

**Business Value:**
- **Resolution Rate:** KB-driven self-service resolves 35–45% of common issues without agent escalation
- **Cost Reduction:** Each self-resolved ticket saves ~$5 in agent handling costs
- **Customer Satisfaction:** Immediate answers improve CSAT by 8–12 percentage points vs. waiting for agent
- **Funnel Transparency:** A/B test framework measures contribution of each recommendation mode

**Fit into Triage Platform:** Recommendations integrate into the **decision matrix (S2.2)** as a pre-triage action; if a strong KB article match is found for an incoming ticket, it is offered to the customer before routing to an agent, with click-through and resolution tracked via **feedback loop (S4.7)**.

## Technical Specification

### Recommendation Strategy Overview

#### Mode 1: Content-Based (TF-IDF + Semantic Re-ranking)

**Vectorization:**
- Tokenize article titles and bodies using scikit-learn TfidfVectorizer
- Config: `max_features=10000`, `ngram_range=(1,2)`, `min_df=2`, `max_df=0.95`
- Store sparse TF-IDF matrix in PostgreSQL (jsonb for dense top-k per article)

**Semantic Re-ranking:**
- Use Sentence-Transformers (`all-MiniLM-L6-v2`) to embed incoming query and top-20 TF-IDF candidates
- Cosine similarity re-rank to select top-5 articles
- Reason: catch synonym and concept-level similarity TF-IDF misses

**Scoring Formula:**
```
content_score = 0.6 * tfidf_cosine_sim + 0.4 * semantic_cosine_sim
```

#### Mode 2: Collaborative Filtering (ALS Matrix Factorization)

**Matrix Structure:**
- Rows: customer_id (binned into 50 segments by account age and plan tier)
- Columns: article_id
- Values: implicit feedback (clicks weighted by dwell time, resolutions weighted 10x)

**Algorithm:** Alternating Least Squares (ALS) from `implicit` library
- `factors=50`, `iterations=10`, `regularization=0.01`, `alpha=40` (click weight)
- Explicit negatives: articles visited but not resolved weighted as -1

**Inference:**
- Compute user latent factor from historical interactions
- Score all articles: `article_score = user_factor · article_factor^T`
- Return top-5 articles not recently clicked

**Segment Mapping:**
```python
def get_segment_id(customer_context):
    """Map customer to collaborative filter segment."""
    days_active = customer_context.account_age_days
    plan = customer_context.subscription_plan
    
    age_bucket = min(days_active // 30, 11)  # 0–11: 0–360 days
    plan_bucket = {"starter": 0, "pro": 1, "enterprise": 2}.get(plan, 0)
    
    return age_bucket * 3 + plan_bucket  # 0–35 segments
```

#### Mode 3: Self-Service Path Routing

**Decision Tree (hardcoded thresholds):**

```
IF intent_confidence >= 0.8 AND topic_type IN ('billing', 'onboarding')
  → Recommend FAQ
ELIF lifecycle_stage IN ('trial_day_1', 'trial_day_7')
  → Recommend onboarding articles
ELIF customer_context.is_at_risk AND topic_type == 'cancellation'
  → Recommend retention articles (high-value path)
ELIF tfidf_best_match_score < 0.3
  → Suggest "Contact Support" directly (skip KB for low-confidence queries)
ELSE
  → Recommend KB search result
```

**Output:** `SelfServicePath` with recommendation type and article list

## Implementation

### TF-IDF Index Build & Update

```python
from sklearn.feature_extraction.text import TfidfVectorizer
import pickle
import psycopg2
from psycopg2.extras import execute_batch

class TFIDFIndexBuilder:
    def __init__(self, db_connection, redis_client):
        self.db = db_connection
        self.redis = redis_client
        self.vectorizer = TfidfVectorizer(
            max_features=10000,
            ngram_range=(1, 2),
            min_df=2,
            max_df=0.95,
            stop_words='english'
        )
    
    def build_index(self, tenant_id: int) -> bool:
        """Build full TF-IDF index for tenant's KB."""
        
        # Fetch all active articles
        cursor = self.db.cursor()
        cursor.execute("""
            SELECT id, title, body FROM kb_articles
            WHERE tenant_id = %s AND is_active = TRUE
            ORDER BY id
        """, (tenant_id,))
        
        articles = cursor.fetchall()
        article_ids = [a[0] for a in articles]
        
        # Concatenate title + body for vectorization
        texts = [f"{a[1]} {a[2]}" for a in articles]
        
        if len(texts) < 10:
            print(f"Tenant {tenant_id}: insufficient articles ({len(texts)} < 10)")
            return False
        
        # Fit vectorizer
        tfidf_matrix = self.vectorizer.fit_transform(texts)
        
        # Store feature names
        feature_names = self.vectorizer.get_feature_names_out()
        
        # Store in Redis as pickle (sparse matrix)
        cache_key = f"tfidf_matrix:{tenant_id}"
        self.redis.set(
            cache_key,
            pickle.dumps({
                'matrix': tfidf_matrix,
                'feature_names': feature_names,
                'article_ids': article_ids,
                'built_at': datetime.utcnow().isoformat()
            }),
            ex=86400 * 7  # 7-day TTL
        )
        
        # Pre-compute top-5 dense representations for each article
        dense_matrix = tfidf_matrix.toarray()
        
        batch_data = []
        for i, article_id in enumerate(article_ids):
            # Get top-10 features for this article
            top_indices = np.argsort(dense_matrix[i])[-10:][::-1]
            top_features = {
                feature_names[j].lower(): float(dense_matrix[i][j])
                for j in top_indices
            }
            
            batch_data.append((
                tenant_id,
                article_id,
                json.dumps(top_features),
                datetime.utcnow()
            ))
        
        # Upsert into PostgreSQL
        upsert_sql = """
            INSERT INTO kb_article_vectors (tenant_id, article_id, top_features, indexed_at)
            VALUES (%s, %s, %s, %s)
            ON CONFLICT (tenant_id, article_id)
            DO UPDATE SET top_features = EXCLUDED.top_features,
                         indexed_at = EXCLUDED.indexed_at
        """
        
        execute_batch(cursor, upsert_sql, batch_data, page_size=100)
        self.db.commit()
        cursor.close()
        
        print(f"Built TF-IDF index for {tenant_id}: {len(article_ids)} articles")
        return True
    
    def update_article(self, tenant_id: int, article_id: int, new_text: str) -> None:
        """Incremental update for single article."""
        
        # Fetch current vectorizer
        cache_key = f"tfidf_matrix:{tenant_id}"
        cached = self.redis.get(cache_key)
        
        if not cached:
            # Rebuild if not in cache
            self.build_index(tenant_id)
            return
        
        data = pickle.loads(cached)
        vectorizer = self.vectorizer
        vectorizer.fit(data['feature_names'])
        
        # Transform new article
        new_vector = vectorizer.transform([new_text]).toarray()[0]
        
        # Update in DB
        cursor = self.db.cursor()
        top_indices = np.argsort(new_vector)[-10:][::-1]
        top_features = {
            vectorizer.get_feature_names_out()[j].lower(): float(new_vector[j])
            for j in top_indices if j < len(vectorizer.get_feature_names_out())
        }
        
        cursor.execute("""
            UPDATE kb_article_vectors SET top_features = %s, indexed_at = %s
            WHERE tenant_id = %s AND article_id = %s
        """, (json.dumps(top_features), datetime.utcnow(), tenant_id, article_id))
        
        self.db.commit()
        cursor.close()
```

### Semantic Re-ranking with Sentence Transformers

```python
from sentence_transformers import SentenceTransformer, util
import torch

class SemanticRanker:
    def __init__(self, model_name="all-MiniLM-L6-v2"):
        self.model = SentenceTransformer(model_name)
        self.device = "cuda" if torch.cuda.is_available() else "cpu"
        self.model.to(self.device)
    
    def rerank_articles(
        self,
        query: str,
        candidates: list[dict],
        top_k: int = 5
    ) -> list[dict]:
        """Re-rank top TF-IDF candidates by semantic similarity."""
        
        if not candidates:
            return []
        
        # Encode query
        query_embedding = self.model.encode(query, convert_to_tensor=True)
        
        # Encode article summaries
        article_texts = [c.get('excerpt', c.get('title', '')) for c in candidates]
        article_embeddings = self.model.encode(
            article_texts,
            convert_to_tensor=True,
            batch_size=32
        )
        
        # Compute cosine similarities
        cos_scores = util.cos_sim(query_embedding, article_embeddings)[0]
        
        # Assign semantic score to each candidate
        for i, candidate in enumerate(candidates):
            candidate['semantic_score'] = float(cos_scores[i])
        
        # Sort by semantic score
        sorted_articles = sorted(
            candidates,
            key=lambda x: x['semantic_score'],
            reverse=True
        )
        
        return sorted_articles[:top_k]
```

### Collaborative Filtering with ALS

```python
from implicit.als import AlternatingLeastSquares
from scipy.sparse import csr_matrix
import numpy as np

class CollaborativeFilteringModel:
    def __init__(self, factors=50, iterations=10, regularization=0.01, alpha=40):
        self.model = AlternatingLeastSquares(
            factors=factors,
            iterations=iterations,
            regularization=regularization,
            alpha=alpha,
            random_state=42,
            calculate_training_loss=False
        )
        self.user_to_idx = {}  # segment_id → row index
        self.article_to_idx = {}  # article_id → col index
        self.is_trained = False
    
    def build_feedback_matrix(self, tenant_id: int, db_connection) -> bool:
        """Build user-article interaction matrix from feedback logs."""
        
        cursor = db_connection.cursor()
        
        # Fetch all feedback events
        cursor.execute("""
            SELECT DISTINCT segment_id, article_id, 
                   SUM(CASE 
                       WHEN event_type = 'resolved' THEN 10
                       WHEN event_type = 'clicked' THEN 1
                       WHEN event_type = 'escalated' THEN -1
                       ELSE 0
                   END) as score
            FROM recommendation_events
            WHERE tenant_id = %s
                AND event_type IN ('clicked', 'resolved', 'escalated')
                AND timestamp > NOW() - INTERVAL '90 days'
            GROUP BY segment_id, article_id
            HAVING SUM(CASE 
                       WHEN event_type = 'resolved' THEN 10
                       WHEN event_type = 'clicked' THEN 1
                       WHEN event_type = 'escalated' THEN -1
                       ELSE 0
                   END) > 0
        """, (tenant_id,))
        
        interactions = cursor.fetchall()
        
        if len(interactions) < 100:
            print(f"Tenant {tenant_id}: insufficient interactions ({len(interactions)} < 100)")
            return False
        
        # Build mappings
        unique_segments = list(set(i[0] for i in interactions))
        unique_articles = list(set(i[1] for i in interactions))
        
        self.user_to_idx = {seg: idx for idx, seg in enumerate(unique_segments)}
        self.article_to_idx = {art: idx for idx, art in enumerate(unique_articles)}
        
        # Build sparse matrix
        rows = [self.user_to_idx[i[0]] for i in interactions]
        cols = [self.article_to_idx[i[1]] for i in interactions]
        data = [i[2] for i in interactions]
        
        feedback_matrix = csr_matrix(
            (data, (rows, cols)),
            shape=(len(unique_segments), len(unique_articles)),
            dtype=np.float32
        )
        
        # Train model
        self.model.fit(feedback_matrix)
        self.is_trained = True
        
        cursor.close()
        return True
    
    def get_recommendations(
        self,
        segment_id: int,
        article_ids_to_exclude: list[int],
        k: int = 5
    ) -> list[tuple[int, float]]:
        """Get top-k recommendations for a customer segment."""
        
        if not self.is_trained or segment_id not in self.user_to_idx:
            return []
        
        user_idx = self.user_to_idx[segment_id]
        
        # Get user latent factors
        user_factors = self.model.user_factors[user_idx]
        
        # Score all articles
        article_scores = self.model.item_factors @ user_factors
        
        # Rank by score
        article_indices = np.argsort(article_scores)[::-1]
        
        # Map back to article_ids, excluding already-recommended
        recommendations = []
        exclude_indices = {
            self.article_to_idx[aid] for aid in article_ids_to_exclude
            if aid in self.article_to_idx
        }
        
        for article_idx in article_indices:
            if article_idx not in exclude_indices:
                # Reverse mapping
                article_id = [
                    aid for aid, idx in self.article_to_idx.items()
                    if idx == article_idx
                ][0]
                score = float(article_scores[article_idx])
                recommendations.append((article_id, score))
            
            if len(recommendations) >= k:
                break
        
        return recommendations
```

### Orchestration & Scoring

```python
import uuid
from dataclasses import dataclass
from enum import Enum

class RecommendationMode(Enum):
    CONTENT = "content"
    COLLABORATIVE = "collaborative"
    PATH = "path"

@dataclass
class Recommendation:
    article_id: int
    title: str
    excerpt: str
    url: str
    score: float
    mode: RecommendationMode
    rank: int
    recommendation_id: str

class RecommendationEngine:
    def __init__(self, db_connection, redis_client, tfidf_builder, semantic_ranker, cf_model):
        self.db = db_connection
        self.redis = redis_client
        self.tfidf = tfidf_builder
        self.semantic = semantic_ranker
        self.collab = cf_model
    
    def get_kb_recommendations(
        self,
        query: str,
        customer_id: int,
        tenant_id: int,
        k: int = 5
    ) -> dict:
        """Main recommendation orchestration."""
        
        # Get customer context and A/B variant assignment
        context = self._get_customer_context(customer_id, tenant_id)
        variant = self._assign_ab_variant(customer_id, tenant_id)
        session_id = str(uuid.uuid4())
        
        recommendations = []
        
        # Mode 1: Content-based (always run)
        content_recs = self._get_content_recommendations(
            query, tenant_id, k, context
        )
        recommendations.extend(content_recs)
        
        # Mode 2: Collaborative (if model trained)
        if variant == "collaborative" or variant == "ensemble":
            collab_recs = self._get_collaborative_recommendations(
                customer_id, tenant_id, k, context
            )
            recommendations.extend(collab_recs)
        
        # Mode 3: Self-service path
        path_recommendation = self._get_selfservice_path(
            query, context, content_recs
        )
        
        # Combine and deduplicate
        seen_articles = set()
        final_recs = []
        for rec in recommendations:
            if rec.article_id not in seen_articles:
                final_recs.append(rec)
                seen_articles.add(rec.article_id)
            if len(final_recs) >= k:
                break
        
        # Re-rank by composite score
        final_recs.sort(key=lambda x: x.score, reverse=True)
        
        # Assign ranks
        for i, rec in enumerate(final_recs):
            rec.rank = i + 1
        
        # Log event for A/B tracking
        for rec in final_recs:
            self._log_recommendation_shown(
                session_id, rec, variant, tenant_id
            )
        
        return {
            "recommendations": [
                {
                    "article_id": r.article_id,
                    "title": r.title,
                    "excerpt": r.excerpt,
                    "url": r.url,
                    "score": r.score,
                    "mode": r.mode.value,
                    "rank": r.rank,
                    "recommendation_id": r.recommendation_id
                }
                for r in final_recs
            ],
            "self_service_path": {
                "stage": path_recommendation["stage"],
                "reason": path_recommendation["reason"],
                "confidence": path_recommendation["confidence"]
            },
            "generated_at": datetime.utcnow().isoformat(),
            "session_id": session_id,
            "variant": variant
        }
    
    def _get_content_recommendations(
        self,
        query: str,
        tenant_id: int,
        k: int,
        context: dict
    ) -> list[Recommendation]:
        """TF-IDF + semantic re-ranking."""
        
        cursor = self.db.cursor()
        
        # Fetch all article vectors
        cursor.execute("""
            SELECT id, title, excerpt, url, top_features
            FROM kb_article_vectors
            WHERE tenant_id = %s
            LIMIT 1000
        """, (tenant_id,))
        
        articles = cursor.fetchall()
        cursor.close()
        
        if not articles:
            return []
        
        # Compute TF-IDF similarity
        tfidf_scores = []
        for article_id, title, excerpt, url, features in articles:
            features_dict = json.loads(features) if isinstance(features, str) else features
            # Simple heuristic: match query terms in top features
            query_terms = set(query.lower().split())
            matching_terms = sum(
                1 for term in features_dict.keys()
                if any(q in term for q in query_terms)
            )
            score = matching_terms / max(len(features_dict), 1)
            tfidf_scores.append({
                'article_id': article_id,
                'title': title,
                'excerpt': excerpt,
                'url': url,
                'tfidf_score': score
            })
        
        # Sort by TF-IDF and take top-20 for semantic re-ranking
        top_20 = sorted(tfidf_scores, key=lambda x: x['tfidf_score'], reverse=True)[:20]
        
        # Re-rank semantically
        reranked = self.semantic.rerank_articles(query, top_20, top_k=k)
        
        # Convert to Recommendation objects
        recommendations = []
        for i, article in enumerate(reranked):
            combined_score = 0.6 * article['tfidf_score'] + 0.4 * article['semantic_score']
            
            rec = Recommendation(
                article_id=article['article_id'],
                title=article['title'],
                excerpt=article['excerpt'],
                url=article['url'],
                score=combined_score,
                mode=RecommendationMode.CONTENT,
                rank=i + 1,
                recommendation_id=str(uuid.uuid4())
            )
            recommendations.append(rec)
        
        return recommendations
    
    def _get_collaborative_recommendations(
        self,
        customer_id: int,
        tenant_id: int,
        k: int,
        context: dict
    ) -> list[Recommendation]:
        """Get recommendations from collaborative filtering."""
        
        segment_id = context['segment_id']
        
        # Get recommendations from model
        collab_recs = self.collab.get_recommendations(
            segment_id,
            article_ids_to_exclude=[],
            k=k
        )
        
        if not collab_recs:
            return []
        
        cursor = self.db.cursor()
        recommendations = []
        
        for article_id, score in collab_recs:
            cursor.execute("""
                SELECT title, excerpt, url
                FROM kb_articles
                WHERE id = %s AND tenant_id = %s
            """, (article_id, tenant_id))
            
            result = cursor.fetchone()
            if result:
                title, excerpt, url = result
                
                rec = Recommendation(
                    article_id=article_id,
                    title=title,
                    excerpt=excerpt,
                    url=url,
                    score=score,
                    mode=RecommendationMode.COLLABORATIVE,
                    rank=0,
                    recommendation_id=str(uuid.uuid4())
                )
                recommendations.append(rec)
        
        cursor.close()
        return recommendations
    
    def _get_selfservice_path(
        self,
        query: str,
        context: dict,
        content_recs: list[Recommendation]
    ) -> dict:
        """Route to FAQ, KB, or contact support."""
        
        best_content_score = content_recs[0].score if content_recs else 0.0
        
        # Decision rules
        if best_content_score < 0.3:
            return {
                "stage": "contact_support",
                "reason": "No strong KB match found",
                "confidence": 0.85
            }
        
        if context['lifecycle_stage'] in ['trial_day_1', 'trial_day_7']:
            return {
                "stage": "kb_search",
                "reason": "Early trial customer - encourage self-service",
                "confidence": 0.80
            }
        
        if context['is_at_risk'] and 'cancel' in query.lower():
            return {
                "stage": "kb_search",
                "reason": "At-risk customer with retention content",
                "confidence": 0.75
            }
        
        return {
            "stage": "kb_search",
            "reason": "Recommend KB article",
            "confidence": 0.90
        }
    
    def _assign_ab_variant(self, customer_id: int, tenant_id: int) -> str:
        """Deterministic A/B assignment based on customer_id hash."""
        
        hash_val = int(hashlib.md5(
            f"{tenant_id}:{customer_id}".encode()
        ).hexdigest(), 16)
        
        variant_map = {
            0: "control",
            1: "personalized",
            2: "collaborative"
        }
        
        return variant_map[hash_val % 3]
    
    def _get_customer_context(self, customer_id: int, tenant_id: int) -> dict:
        """Fetch customer enrichment and lifecycle stage."""
        
        cursor = self.db.cursor()
        cursor.execute("""
            SELECT account_age_days, subscription_plan, is_at_risk
            FROM customer_enrichment_cache
            WHERE customer_id = %s AND tenant_id = %s
        """, (customer_id, tenant_id))
        
        row = cursor.fetchone()
        cursor.close()
        
        if not row:
            return {
                'account_age_days': 0,
                'subscription_plan': 'starter',
                'is_at_risk': False,
                'segment_id': 0,
                'lifecycle_stage': 'unknown'
            }
        
        account_age, plan, is_at_risk = row
        
        # Compute segment
        age_bucket = min(account_age // 30, 11)
        plan_bucket = {"starter": 0, "pro": 1, "enterprise": 2}.get(plan, 0)
        segment_id = age_bucket * 3 + plan_bucket
        
        # Determine lifecycle stage
        lifecycle_stage = "established"
        if account_age < 1:
            lifecycle_stage = "trial_day_1"
        elif account_age < 7:
            lifecycle_stage = "trial_day_7"
        
        return {
            'account_age_days': account_age,
            'subscription_plan': plan,
            'is_at_risk': is_at_risk,
            'segment_id': segment_id,
            'lifecycle_stage': lifecycle_stage
        }
    
    def _log_recommendation_shown(
        self,
        session_id: str,
        recommendation: Recommendation,
        variant: str,
        tenant_id: int
    ) -> None:
        """Log initial recommendation display event."""
        
        cursor = self.db.cursor()
        cursor.execute("""
            INSERT INTO recommendation_events
            (recommendation_id, session_id, event_type, article_id, variant, tenant_id, timestamp)
            VALUES (%s, %s, %s, %s, %s, %s, %s)
        """, (
            recommendation.recommendation_id,
            session_id,
            'shown',
            recommendation.article_id,
            variant,
            tenant_id,
            datetime.utcnow()
        ))
        self.db.commit()
        cursor.close()
```

```python
class RecommendationFeedbackProcessor:
    def __init__(self, db_connection):
        self.db = db_connection
    
    def log_event(self, event: dict) -> bool:
        """Log user interaction and trigger learning updates."""
        
        cursor = self.db.cursor()
        
        cursor.execute("""
            INSERT INTO recommendation_events
            (recommendation_id, session_id, event_type, article_id, customer_id, 
             tenant_id, dwell_time_seconds, a_b_variant, timestamp)
            VALUES (%s, %s, %s, %s, %s, %s, %s, %s, %s)
        """, (
            event['recommendation_id'],
            event.get('session_id'),
            event['event_type'],
            event['article_id'],
            event['customer_id'],
            event['tenant_id'],
            event.get('dwell_time_seconds'),
            event.get('a_b_variant'),
            datetime.utcnow()
        ))
        
        # If resolution event, update article resolution rate
        if event['event_type'] == 'resolved':
            self._update_article_resolution_score(
                event['article_id'],
                event['tenant_id']
            )
        
        self.db.commit()
        cursor.close()
        return True
    
    def _update_article_resolution_score(self, article_id: int, tenant_id: int) -> None:
        """Re-weight article for future recommendations based on resolution rate."""
        
        cursor = self.db.cursor()
        
        # Calculate 24h resolution rate
        cursor.execute("""
            SELECT 
                COUNT(CASE WHEN event_type = 'resolved' THEN 1 END)::float / 
                COUNT(DISTINCT recommendation_id) as resolution_rate
            FROM recommendation_events
            WHERE article_id = %s 
                AND tenant_id = %s
                AND timestamp > NOW() - INTERVAL '24 hours'
        """, (article_id, tenant_id))
        
        result = cursor.fetchone()
        resolution_rate = result[0] if result and result[0] else 0.0
        
        # Update article weight
        cursor.execute("""
            UPDATE kb_articles
            SET resolution_boost = %s
            WHERE id = %s AND tenant_id = %s
        """, (resolution_rate, article_id, tenant_id))
        
        self.db.commit()
        cursor.close()
```

### A/B Testing & Metrics

```python
class ABTestAnalyzer:
    def __init__(self, db_connection):
        self.db = db_connection
    
    def get_test_metrics(
        self,
        test_id: str,
        from_timestamp: datetime,
        to_timestamp: datetime
    ) -> dict:
        """Compute A/B test metrics and statistical significance."""
        
        cursor = self.db.cursor()
        
        # Fetch events by variant
        cursor.execute("""
            SELECT 
                a_b_variant,
                COUNT(DISTINCT CASE WHEN event_type = 'shown' THEN recommendation_id END) as shown,
                COUNT(DISTINCT CASE WHEN event_type = 'clicked' THEN recommendation_id END) as clicked,
                COUNT(DISTINCT CASE WHEN event_type = 'resolved' THEN recommendation_id END) as resolved,
                COUNT(DISTINCT CASE WHEN event_type IN ('shown', 'clicked', 'resolved') 
                    THEN recommendation_id END) as unique_users,
                AVG(CASE WHEN event_type = 'dwell_30s' THEN 30 ELSE 0 END) as avg_dwell
            FROM recommendation_events
            WHERE timestamp BETWEEN %s AND %s
            GROUP BY a_b_variant
        """, (from_timestamp, to_timestamp))
        
        rows = cursor.fetchall()
        cursor.close()
        
        variants = {}
        for variant, shown, clicked, resolved, users, avg_dwell in rows:
            ctr = clicked / shown if shown > 0 else 0.0
            resolution_rate = resolved / shown if shown > 0 else 0.0
            
            variants[variant] = {
                "users_in_variant": users,
                "recommendations_shown": shown,
                "click_through_rate": ctr,
                "resolution_rate": resolution_rate,
                "avg_dwell_seconds": avg_dwell or 0
            }
        
        # Chi-square test for CTR
        control_ctr = variants.get('control', {}).get('click_through_rate', 0)
        personalized_ctr = variants.get('personalized', {}).get('click_through_rate', 0)
        
        ctr_p_value, ctr_significant = self._chi_square_test(
            variants.get('control', {}).get('recommendations_shown', 1),
            int(variants.get('control', {}).get('recommendations_shown', 1) * control_ctr),
            variants.get('personalized', {}).get('recommendations_shown', 1),
            int(variants.get('personalized', {}).get('recommendations_shown', 1) * personalized_ctr)
        )
        
        # Resolution rate lift
        lift_pct = ((personalized_ctr - control_ctr) / control_ctr * 100) if control_ctr > 0 else 0
        
        return {
            "variants": variants,
            "statistical_significance": {
                "personalized_vs_control_ctr": {
                    "p_value": ctr_p_value,
                    "is_significant": ctr_significant,
                    "confidence_level": 0.95
                }
            },
            "lift_vs_control_pct": lift_pct
        }
    
    def _chi_square_test(self, n1, x1, n2, x2) -> tuple[float, bool]:
        """Chi-square test for two proportions."""
        from scipy.stats import chi2_contingency
        
        contingency_table = [[x1, n1 - x1], [x2, n2 - x2]]
        chi2, p_value, dof, expected = chi2_contingency(contingency_table)
        
        is_significant = p_value < 0.05
        return p_value, is_significant
```
