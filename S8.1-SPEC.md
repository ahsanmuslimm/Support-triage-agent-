# S8.1: Dataset Builder & Curation

## Overview
Dagster-based pipeline for preparing high-quality labeled datasets for training.

## Key Components
- **Raw Conversations**: Load from jsonl files
- **Label Precedence**: Override > Correction > Auto-label
- **PII Scrubbing**: Presidio patterns for email, phone, SSN, IP, credit card
- **Deduplication**: Hash(tenant, intent, tokens) - exact duplicate detection
- **Class Balancing**: Drop classes with <20 examples
- **Train/Test Split**: 80/20 stratified by tenant and intent
- **Golden Set**: Tag high-confidence, diverse, edge-case examples

## Outputs
- `labeled_dataset`: Curated examples with dedup + class balance
- `golden_set_curated`: Stratified split + golden tags
- 30+ tests covering label precedence, dedup, PII scrub, class balance
