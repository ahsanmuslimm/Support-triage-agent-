## Overview

### Design Summary

S6.5 integrates Temporal 1.24+ (open-source workflow engine) as the orchestration layer for message triage workflows.

**Key Deliverables** (Sprint 7):
- Temporal Worker node integration
- Activity definitions (classify, enrich, decide, resolve, escalate)
- Workflow definition (ProcessMessageWorkflow)
- Activity retry policies
- Time-skipping tests
- Monitoring via Temporal Web UI + Prometheus metrics

### Placeholder Spec

This is a specification-only deliverable for Sprint 6. Actual implementation deferred to Sprint 7 due to scope constraints.

**What S6.5 Will Provide**:
1. Temporal Server setup (docker-compose)
2. Activity layer (call external services: LLM, KnowledgeBase, Tools)
3. Workflow definition (state machine: CLASSIFY → ENRICH → DECIDE → RESOLVE)
4. Worker pool (local Python worker consuming activities)
5. Deterministic execution (no side effects in workflow code)
6. Activity deduplication via idempotency keys (S6.3 integration)

**Integration Points**:
- **Input**: Message from Kafka topic (S6.2)
- **Activities**: Call existing triage modules (classification, decision, etc.)
- **State**: Temporal History DB stores workflow state
- **Observability**: Workflow metrics + distributed tracing

### Why Temporal?

- **Durability**: Workflow survives application crashes
- **Visibility**: Web UI shows workflow execution history
- **Scalability**: Decoupled activities, horizontal scaling
- **Auditing**: Complete audit trail of all decisions
- **Testing**: Time-skipping tests deterministic

## FAQ

**Q: Why defer to Sprint 7?**  
A: S6.1-S6.4 deliver core distributed infrastructure. S6.5 can build on top. Prioritizes event backbone first.

**Q: How does S6.5 integrate with S6.2-S6.4?**  
A: Message events from Kafka (S6.2) → Idempotency check (S6.3) → Priority queue (S6.4) → Temporal workflow → Activities emit events back to Kafka.

**Q: What's the cutover path?**  
A: LangGraph continues through Sprint 6. S6.5 deployment in Sprint 7 as parallel executor. Feature flag: USE_TEMPORAL_WORKFLOWS.
