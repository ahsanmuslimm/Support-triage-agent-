# S9.3: JavaScript In-App SDK

Tenant-signed ES256 JWT authentication and SSE event streaming.

## Implementation Summary
- JWTValidator: ES256 verification, alg confusion defense (reject HS256), 15min TTL
- IAL2 assertion: JWT contains aud=tenant_id, sub=customer_id
- KeyRotationManager: Automatic key rotation via /.well-known/keys endpoint
- WidgetSession: Manages customer sessions with activity tracking
- SessionManager: Lifecycle management with TTL and cleanup
- Event streaming: SSE from API with JWT Authorization header
- Widget init format: window.TriageWidget.init({jwt: token, tenant: 'acme', target: '#chat-widget'})
- ~350 lines code + 30 tests

## Key Classes
- JWTValidator: Token validation with algorithm enforcement
- KeyRotationManager: Public key management
- WidgetSession: Session state and event queue
- SessionManager: Session registry and expiry
