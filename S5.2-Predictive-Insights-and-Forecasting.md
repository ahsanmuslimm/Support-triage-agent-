## Overview

The Predictive Insights & Forecasting module enables proactive support orchestration through four complementary prediction models, each targeting a specific business outcome:

1. **Next-Issue Prediction (LSTM)** — Predict the category or type of the customer's next support request based on historical query sequence. Enables intelligent routing and knowledge injection before the customer initiates the ticket.

2. **Seasonal Forecasting (Prophet)** — Decompose support volume into trend, weekly, and yearly seasonality. Enables staffing planning, capacity allocation, and early detection of anomalous demand shifts masked within larger seasonal patterns.

3. **72-Hour Churn Prediction** — Binary classifier identifying customers at imminent risk of disengagement within 3 days (high-urgency intervention window). Combines recency signals, escalation history, sentiment trajectory, and resolution timeliness. Target: **85% precision, 80% recall**.

4. **Support Volume Forecasting** — Point and interval forecasts for daily ticket throughput (per tenant, optionally per queue/team). Feeds staffing models, queue prioritization, and SLA planning.

**Business Value:**
- **Proactive Intervention:** Identify churn-risk customers before they go silent; reduce net churn by 8–12%
- **Operational Efficiency:** Forecast demand with 15–20% accuracy improvement over naive baseline; reduce scheduling waste
- **Knowledge Acceleration:** Surface likely-next-issue proactively; reduce MTTR by suggesting relevant KB articles during triage
- **Revenue Protection:** LTV-weighted churn alerts prioritize high-value at-risk customers

**Architecture:** Models are trained offline on historical data (daily cadence), versioned in MLflow, deployed in shadow mode for A/B evaluation, then promoted to production after validation. Predictions are cached in Redis (TTL 1h), reducing latency on repeat queries.

## Technical Specification

### 1. LSTM Next-Issue Prediction

**Objective:** Given a customer's sequence of prior issue categories (last 30 days), predict the next issue type or category.

**Model Architecture:**

```
Input: Sequence of one-hot encoded issue categories [batch_size, seq_len=30, num_categories]
  ↓
Embedding Layer: [batch_size, seq_len, embedding_dim=64]
  ↓
LSTM(units=128, dropout=0.3, recurrent_dropout=0.3)  [batch_size, 128]
  ↓
Dense(256, activation='relu')  [batch_size, 256]
  ↓
Dropout(0.4)
  ↓
Dense(num_categories, activation='softmax')  [batch_size, num_categories]
  ↓
Output: Probability distribution over issue categories
```

**Key Hyperparameters:**
- **seq_len:** 30 days of historical issues (window size)
- **embedding_dim:** 64 (reduces category cardinality)
- **lstm_units:** 128 (captures temporal patterns)
- **dropout:** 0.3 (LSTM), 0.4 (dense) to prevent overfitting
- **batch_size:** 32
- **epochs:** 50 (early stopping on validation loss)
- **learning_rate:** 0.001 (Adam optimizer)

**Training Data Preparation:**

```python
def prepare_lstm_training_data(customer_history_df, lookback=30, test_split=0.2):
    """
    Transform customer issue sequences into supervised format.
    
    Input: customer_history_df with columns [customer_id, issue_category, created_at]
    Output: X [n_samples, seq_len], y [n_samples]
    """
    from sklearn.preprocessing import LabelEncoder
    
    # Encode issue categories
    le = LabelEncoder()
    categories = le.fit_transform(customer_history_df['issue_category'].unique())
    num_categories = len(le.classes_)
    
    X_sequences = []
    y_targets = []
    
    for customer_id in customer_history_df['customer_id'].unique():
        customer_issues = customer_history_df[
            customer_history_df['customer_id'] == customer_id
        ].sort_values('created_at')
        
        encoded_sequence = le.transform(customer_issues['issue_category'].values)
        
        # Create sliding windows
        for i in range(len(encoded_sequence) - lookback):
            window = encoded_sequence[i:i+lookback]
            next_issue = encoded_sequence[i+lookback]
            
            X_sequences.append(window)
            y_targets.append(next_issue)
    
    X_sequences = np.array(X_sequences)
    y_targets = np.array(y_targets)
    
    # One-hot encode targets
    y_targets_onehot = tf.keras.utils.to_categorical(y_targets, num_classes=num_categories)
    
    # Train/test split
    split_idx = int(len(X_sequences) * (1 - test_split))
    X_train, X_test = X_sequences[:split_idx], X_sequences[split_idx:]
    y_train, y_test = y_targets_onehot[:split_idx], y_targets_onehot[split_idx:]
    
    return X_train, X_test, y_train, y_test, le, num_categories
```

**Model Training & Versioning:**

```python
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Embedding, LSTM, Dense, Dropout
import mlflow

class LSTMNextIssuePredictor:
    def __init__(self, num_categories, embedding_dim=64, lstm_units=128):
        self.num_categories = num_categories
        self.embedding_dim = embedding_dim
        self.lstm_units = lstm_units
        self.model = self._build_model()
    
    def _build_model(self):
        model = Sequential([
            Embedding(input_dim=self.num_categories, output_dim=self.embedding_dim, input_length=30),
            LSTM(units=self.lstm_units, dropout=0.3, recurrent_dropout=0.3, return_sequences=False),
            Dense(256, activation='relu'),
            Dropout(0.4),
            Dense(self.num_categories, activation='softmax')
        ])
        model.compile(
            optimizer=tf.keras.optimizers.Adam(learning_rate=0.001),
            loss='categorical_crossentropy',
            metrics=['accuracy', tf.keras.metrics.TopKCategoricalAccuracy(k=3, name='top_3_accuracy')]
        )
        return model
    
    def train(self, X_train, y_train, X_val, y_val, epochs=50, batch_size=32):
        """Train with early stopping."""
        early_stop = tf.keras.callbacks.EarlyStopping(
            monitor='val_loss',
            patience=5,
            restore_best_weights=True
        )
        
        history = self.model.fit(
            X_train, y_train,
            validation_data=(X_val, y_val),
            epochs=epochs,
            batch_size=batch_size,
            callbacks=[early_stop],
            verbose=1
        )
        
        return history
    
    def predict_next_issues(self, sequence):
        """
        Predict top-3 likely next issues.
        
        Args: sequence of shape [1, seq_len]
        Returns: [(category, probability), ...]
        """
        predictions = self.model.predict(sequence, verbose=0)
        top_3_indices = np.argsort(predictions[0])[-3:][::-1]
        
        return [(idx, float(predictions[0][idx])) for idx in top_3_indices]
    
    def save(self, model_dir, version):
        """Save model + metadata to registry."""
        self.model.save(f"{model_dir}/lstm_next_issue_v{version}.h5")
        
        metadata = {
            "version": version,
            "model_type": "lstm_next_issue",
            "embedding_dim": self.embedding_dim,
            "lstm_units": self.lstm_units,
            "num_categories": self.num_categories,
            "created_at": datetime.utcnow().isoformat()
        }
        
        with open(f"{model_dir}/lstm_metadata_v{version}.json", "w") as f:
            json.dump(metadata, f)
```

### 2. Prophet Seasonal Forecasting

**Objective:** Decompose historical support volume into trend, weekly seasonality, yearly seasonality, and holiday effects. Enable multi-horizon forecasts (7-day, 30-day) with confidence intervals.

**Model Configuration:**

```python
from prophet import Prophet
import pandas as pd

class VolumeForecaster:
    def __init__(self, interval_width=0.95, seasonality_mode='additive'):
        """
        Args:
            interval_width: Confidence interval (0.95 = 95% CI)
            seasonality_mode: 'additive' or 'multiplicative'
        """
        self.prophet = Prophet(
            interval_width=interval_width,
            seasonality_mode=seasonality_mode,
            yearly_seasonality=True,
            weekly_seasonality=True,
            daily_seasonality=False,
            changepoint_prior_scale=0.05,  # Flexibility for trend changes
            seasonality_prior_scale=10.0,  # Strength of seasonal patterns
            seasonality_prior_scale_for_yearly=10.0
        )
        self.is_fitted = False
    
    def fit(self, df_train):
        """
        Fit Prophet model on historical volume data.
        
        Args: df_train with columns ['ds' (datetime), 'y' (volume count)]
        """
        self.prophet.fit(df_train)
        self.is_fitted = True
    
    def forecast(self, periods=90, freq='D'):
        """
        Generate forecast for specified periods.
        
        Args:
            periods: Number of future periods (days)
            freq: 'D' for daily, 'W' for weekly
        
        Returns: DataFrame with columns [ds, yhat, yhat_lower, yhat_upper, trend, ...]
        """
        if not self.is_fitted:
            raise ValueError("Model not fitted. Call fit() first.")
        
        future = self.prophet.make_future_dataframe(periods=periods, freq=freq)
        forecast = self.prophet.predict(future)
        
        return forecast[['ds', 'yhat', 'yhat_lower', 'yhat_upper', 'trend']]
    
    def add_holiday_regressors(self, holidays_df):
        """
        Add custom holiday calendar for domain-specific demand changes.
        
        Args: holidays_df with columns ['holiday', 'ds' (date), 'lower_window', 'upper_window']
        
        Example:
            holidays = pd.DataFrame({
                'holiday': ['Black Friday', 'Cyber Monday', 'Christmas'],
                'ds': pd.to_datetime(['2023-11-24', '2023-11-27', '2023-12-25']),
                'lower_window': [0, 0, -7],
                'upper_window': [1, 1, 7]
            })
        """
        for _, row in holidays_df.iterrows():
            self.prophet.add_seasonality(
                name=row['holiday'],
                period=365.25,
                fourier_order=5
            )
    
    def plot_forecast(self, forecast):
        """Visualization for model validation."""
        fig = self.prophet.plot(forecast)
        return fig
    
    def plot_components(self):
        """Show decomposition: trend, yearly, weekly seasonality."""
        return self.prophet.plot_components(self.prophet.history)

# Training pipeline
def train_prophet_volume_forecast(historical_volume_csv, output_dir):
    """
    Train Prophet on daily support volume.
    """
    df = pd.read_csv(historical_volume_csv)
    df.rename(columns={'date': 'ds', 'ticket_count': 'y'}, inplace=True)
    df['ds'] = pd.to_datetime(df['ds'])
    df = df.sort_values('ds')
    
    # Train/test split (90% train, 10% test)
    split_date = df['ds'].quantile(0.9)
    df_train = df[df['ds'] <= split_date].reset_index(drop=True)
    df_test = df[df['ds'] > split_date].reset_index(drop=True)
    
    # Fit Prophet
    forecaster = VolumeForecaster(interval_width=0.95)
    forecaster.fit(df_train)
    
    # Generate 90-day forecast
    forecast = forecaster.forecast(periods=90, freq='D')
    
    # Evaluate on test set
    test_predictions = forecast[forecast['ds'].isin(df_test['ds'].values)].copy()
    test_predictions = test_predictions.merge(df_test[['ds', 'y']], on='ds')
    
    mae = (test_predictions['y'] - test_predictions['yhat']).abs().mean()
    rmse = np.sqrt(((test_predictions['y'] - test_predictions['yhat']) ** 2).mean())
    
    # Save model
    with open(f"{output_dir}/prophet_volume_model.pkl", "wb") as f:
        pickle.dump(forecaster, f)
    
    # Save forecast
    forecast.to_csv(f"{output_dir}/forecast_90d.csv", index=False)
    
    return {
        "mae": mae,
        "rmse": rmse,
        "test_size": len(df_test),
        "forecast_file": f"{output_dir}/forecast_90d.csv"
    }
```

### 3. Churn Prediction (72-Hour Horizon)

**Objective:** Identify customers at high risk of disengaging within 72 hours. Binary classifier (churn=1, active=0) with 85% precision, 80% recall targets.

**Feature Engineering:**

```python
def engineer_churn_features(customer_id, tenant_id, lookback_days=30, db_session=None):
    """
    Extract 72-hour churn prediction features for a customer.
    
    Returns: Dictionary of features for gradient boosting model.
    """
    
    cutoff_date = datetime.utcnow()
    lookback_start = cutoff_date - timedelta(days=lookback_days)
    
    # 1. Recency features
    last_ticket_date = db_session.query(
        func.max(Ticket.created_at)
    ).filter(
        Ticket.customer_id == customer_id,
        Ticket.tenant_id == tenant_id
    ).scalar()
    
    recency_days = (cutoff_date - last_ticket_date).days if last_ticket_date else 999
    
    # 2. Frequency features (last 30 days)
    ticket_count_30d = db_session.query(func.count(Ticket.id)).filter(
        Ticket.customer_id == customer_id,
        Ticket.tenant_id == tenant_id,
        Ticket.created_at >= lookback_start
    ).scalar()
    
    # 3. Sentiment features
    sentiment_records = db_session.query(
        Ticket.sentiment_score
    ).filter(
        Ticket.customer_id == customer_id,
        Ticket.tenant_id == tenant_id,
        Ticket.created_at >= lookback_start
    ).all()
    
    avg_sentiment = np.mean([r[0] for r in sentiment_records]) if sentiment_records else 0.0
    sentiment_velocity = (sentiment_records[-1][0] - sentiment_records[0][0]) if len(sentiment_records) > 1 else 0.0
    
    # 4. Escalation rate
    escalations_30d = db_session.query(func.count(Ticket.id)).filter(
        Ticket.customer_id == customer_id,
        Ticket.tenant_id == tenant_id,
        Ticket.escalation_flag == True,
        Ticket.created_at >= lookback_start
    ).scalar()
    
    escalation_rate_30d = escalations_30d / max(ticket_count_30d, 1)
    
    # 5. Resolution timeliness
    resolved_tickets = db_session.query(
        Ticket.resolved_at - Ticket.created_at
    ).filter(
        Ticket.customer_id == customer_id,
        Ticket.tenant_id == tenant_id,
        Ticket.resolved_at.isnot(None),
        Ticket.created_at >= lookback_start
    ).all()
    
    avg_resolution_hours = np.mean([r[0].total_seconds() / 3600 for r in resolved_tickets]) if resolved_tickets else 0.0
    
    # 6. Subscription LTV context
    ltv_record = db_session.query(CustomerLTV.lifetime_value).filter(
        CustomerLTV.customer_id == customer_id,
        CustomerLTV.tenant_id == tenant_id
    ).first()
    
    customer_ltv = ltv_record[0] if ltv_record else 0.0
    
    # 7. Churn score from S4.3
    churn_score = db_session.query(func.max(ChurnScore.score)).filter(
        ChurnScore.customer_id == customer_id,
        ChurnScore.tenant_id == tenant_id
    ).scalar() or 0.0
    
    return {
        "recency_days": recency_days,
        "frequency_30d": ticket_count_30d,
        "avg_sentiment": avg_sentiment,
        "sentiment_velocity": sentiment_velocity,
        "escalation_rate_30d": escalation_rate_30d,
        "avg_resolution_hours": avg_resolution_hours,
        "customer_ltv": customer_ltv,
        "prior_churn_score": churn_score
    }

# Feature scaling
from sklearn.preprocessing import StandardScaler

def prepare_churn_training_data(labeled_customers_csv, db_session):
    """
    Prepare training dataset for churn model.
    
    Input: CSV with columns [customer_id, tenant_id, churned_within_72h (0/1)]
    """
    df_labels = pd.read_csv(labeled_customers_csv)
    
    features_list = []
    targets = []
    
    for _, row in df_labels.iterrows():
        features = engineer_churn_features(
            row['customer_id'],
            row['tenant_id'],
            db_session=db_session
        )
        features_list.append(features)
        targets.append(row['churned_within_72h'])
    
    X = pd.DataFrame(features_list)
    y = np.array(targets)
    
    # Feature scaling
    scaler = StandardScaler()
    X_scaled = scaler.fit_transform(X)
    
    return X_scaled, y, X.columns.tolist(), scaler
```

**Gradient Boosting Classifier with SHAP Explainability:**

```python
import xgboost as xgb
import shap

class ChurnPredictionModel:
    def __init__(self, random_state=42):
        self.model = xgb.XGBClassifier(
            n_estimators=200,
            max_depth=6,
            learning_rate=0.05,
            subsample=0.8,
            colsample_bytree=0.8,
            objective='binary:logistic',
            random_state=random_state,
            use_label_encoder=False,
            eval_metric='logloss'
        )
        self.scaler = None
        self.feature_names = None
        self.explainer = None
    
    def train(self, X_train, y_train, X_val, y_val, feature_names):
        """Train with validation monitoring."""
        self.feature_names = feature_names
        
        eval_set = [(X_val, y_val)]
        self.model.fit(
            X_train, y_train,
            eval_set=eval_set,
            early_stopping_rounds=10,
            verbose=False
        )
        
        # Initialize SHAP explainer
        self.explainer = shap.TreeExplainer(self.model)
    
    def predict(self, X, return_shap=False):
        """
        Predict churn probability.
        
        Args:
            X: Feature matrix
            return_shap: If True, also return SHAP values for explainability
        
        Returns: Probabilities or (probabilities, shap_values)
        """
        probs = self.model.predict_proba(X)[:, 1]
        
        if return_shap and self.explainer:
            shap_values = self.explainer.shap_values(X)
            return probs, shap_values
        
        return probs
    
    def predict_single(self, customer_features_dict):
        """
        Predict churn for single customer with explanation.
        
        Returns: {probability, top_3_drivers}
        """
        feature_array = np.array([[
            customer_features_dict.get(feat, 0.0)
            for feat in self.feature_names
        ]])
        
        prob, shap_vals = self.predict(feature_array, return_shap=True)
        
        # Top 3 most important drivers
        top_drivers = sorted(
            zip(self.feature_names, shap_vals[0]),
            key=lambda x: abs(x[1]),
            reverse=True
        )[:3]
        
        return {
            "churn_probability": float(prob[0]),
            "risk_level": "critical" if prob[0] > 0.7 else "high" if prob[0] > 0.5 else "medium",
            "top_drivers": [
                {"feature": name, "impact": float(value), "value": customer_features_dict.get(name, 0.0)}
                for name, value in top_drivers
            ]
        }

# Training pipeline with cross-validation

    # Further split train for validation

    # Train model

    # Evaluate on test set
    y_pred_proba = churn_model.predict(X_test)
    y_pred = (y_pred_proba >= 0.5).astype(int)
    
    from sklearn.metrics import precision_score, recall_score, f1_score, roc_auc_score
    precision = precision_score(y_test, y_pred)

    f1 = f1_score(y_test, y_pred)
    auc_roc = roc_auc_score(y_test, y_pred_proba)
    
    metrics = {

        "test_size": len(y_test)
    }
    
    # Save model
    joblib.dump(churn_model, f"{model_output_dir}/churn_model.pkl")
```

```python
import schedule
import time
from datetime import datetime, timedelta

class PredictionModelPipeline:
    def __init__(self, db_session, redis_client, model_registry_path, mlflow_tracking_uri):
        self.db = db_session
        self.redis = redis_client
        self.registry_path = model_registry_path
        self.mlflow_uri = mlflow_tracking_uri
    
    def retrain_all_models(self):
        """Daily retraining orchestrator."""
        
        logger.info("Starting daily model retraining cycle")
        
        # 1. Retrain LSTM next-issue model
        try:
            lstm_version, lstm_accuracy = self.retrain_lstm()
            logger.info(f"LSTM retrained: v{lstm_version}, top-3 accuracy {lstm_accuracy:.3f}")
        except Exception as e:
            logger.error(f"LSTM retraining failed: {e}")
        
        # 2. Retrain Prophet volume forecast
        try:
            prophet_version, prophet_mae = self.retrain_prophet()
            logger.info(f"Prophet retrained: v{prophet_version}, MAE {prophet_mae:.1f}")
        except Exception as e:
            logger.error(f"Prophet retraining failed: {e}")
        
        # 3. Retrain churn model
        try:
            churn_version, churn_metrics = self.retrain_churn()
            logger.info(f"Churn model retrained: v{churn_version}, precision {churn_metrics['precision']:.3f}")
        except Exception as e:
            logger.error(f"Churn retraining failed: {e}")
        
        logger.info("Model retraining cycle complete")
    
    def retrain_lstm(self):
        """Retrain LSTM on last 90 days of ticket history."""
        
        cutoff = datetime.utcnow() - timedelta(days=90)
        query = """
            SELECT customer_id, issue_category, created_at
            FROM tickets
            WHERE created_at >= %s
            ORDER BY customer_id, created_at
        """
        
        df = pd.read_sql(query, self.db.bind, params=[cutoff])
        X_train, X_test, y_train, y_test, le, num_categories = prepare_lstm_training_data(df)
        
        predictor = LSTMNextIssuePredictor(num_categories=num_categories)
        history = predictor.train(X_train, y_train, X_test, y_test, epochs=50)
        
        test_accuracy = predictor.model.evaluate(X_test, y_test, verbose=0)[1]
        test_top3 = predictor.model.evaluate(X_test, y_test, verbose=0)[2]
        
        version = datetime.utcnow().strftime("%Y%m%d_%H%M%S")
        predictor.save(self.registry_path, version)
        
        # Register in MLflow
        with mlflow.start_run(run_name=f"lstm_v{version}"):
            mlflow.log_metrics({
                "test_accuracy": test_accuracy,
                "test_top_3_accuracy": test_top3
            })
            mlflow.log_artifact(f"{self.registry_path}/lstm_metadata_v{version}.json")
        
        return version, test_top3
    
    def retrain_prophet(self):
        """Retrain Prophet on last 180 days of volume data."""
        
        query = """
            SELECT DATE(created_at) as date, COUNT(*) as ticket_count
            FROM tickets
            WHERE created_at >= NOW() - INTERVAL '180 days'
            GROUP BY DATE(created_at)
            ORDER BY date
        """
        
        df = pd.read_sql(query, self.db.bind)
        df.rename(columns={'date': 'ds', 'ticket_count': 'y'}, inplace=True)
        df['ds'] = pd.to_datetime(df['ds'])
        
        forecaster = VolumeForecaster()
        forecaster.fit(df)
        
        # Evaluate on holdout (last 30 days)
        forecast_full = forecaster.forecast(periods=30)
        test_df = df.tail(30).reset_index(drop=True)
        
        mae = (test_df['y'] - forecast_full.head(30)['yhat']).abs().mean()
        
        version = datetime.utcnow().strftime("%Y%m%d_%H%M%S")
        with open(f"{self.registry_path}/prophet_v{version}.pkl", "wb") as f:
            pickle.dump(forecaster, f)
        
        return version, mae
    
    def retrain_churn(self):
        """Retrain churn model on labeled examples from past 60 days."""
        
        # Fetch labeled churn events (ground truth from CRM)
        query = """
            SELECT customer_id, tenant_id, churned_within_72h
            FROM churn_labels
            WHERE labeled_at >= NOW() - INTERVAL '60 days'
        """
        
        labeled_df = pd.read_sql(query, self.db.bind)
        labeled_df.to_csv("/tmp/churn_labels.csv", index=False)
        
        metrics = train_churn_model("/tmp/churn_labels.csv", self.db, self.registry_path)
        
        version = datetime.utcnow().strftime("%Y%m%d_%H%M%S")
        
        return version, metrics

# Scheduler
def schedule_daily_retraining():
    pipeline = PredictionModelPipeline(db, redis_client, registry_path, mlflow_uri)
    
    schedule.every().day.at("02:00").do(pipeline.retrain_all_models)
    
    while True:
        schedule.run_pending()
        time.sleep(60)
```

```python
class ModelDeploymentManager:
    def __init__(self, db_session, redis_client):
        self.db = db_session
        self.redis = redis_client
    
    def deploy_model_shadow(self, model_type, version):
        """
        Deploy new model in shadow mode: predictions generated but not used.
        Enables collection of performance metrics before promotion.
        """
        
        model_record = ModelRegistry(
            model_type=model_type,
            model_version=version,
            status='shadow',
            deployed_at=datetime.utcnow()
        )
        self.db.add(model_record)
        self.db.commit()
        
        # Store in cache for shadow prediction queries
        cache_key = f"model:shadow:{model_type}:{version}"
        self.redis.set(cache_key, "deployed", ex=86400 * 30)  # 30-day TTL
        
        logger.info(f"Model {model_type} v{version} deployed in shadow mode")
    
    def promote_model_to_production(self, model_type, version, promoted_by_user_id):
        """
        Promote shadow model to production. Deprecated previous production version.
        """
        
        # Fetch shadow model record
        shadow_model = self.db.query(ModelRegistry).filter_by(
            model_type=model_type,
            model_version=version,
            status='shadow'
        ).first()
        
        if not shadow_model:
            raise ValueError(f"Shadow model {model_type} v{version} not found")
        
        # Deprecate previous production model
        prev_prod = self.db.query(ModelRegistry).filter_by(
            model_type=model_type,
            status='production'
        ).first()
        
        if prev_prod:
            prev_prod.status = 'deprecated'
        
        # Promote
        shadow_model.status = 'production'
        shadow_model.promoted_at = datetime.utcnow()
        shadow_model.promoted_by_user_id = promoted_by_user_id
        
        self.db.commit()
        
        # Update cache
        self.redis.set(f"model:production:{model_type}", version, ex=86400 * 365)
        
        logger.info(f"Model {model_type} v{version} promoted to production")
        
        return shadow_model

class PredictionService:
    def __init__(self, redis_client, db_session, model_registry_path):
        self.redis = redis_client
        self.db = db_session
        self.registry_path = model_registry_path
        self.models_cache = {}
    
    def predict_next_issue(self, customer_id, tenant_id, history_window=30):
        """
        Predict next issue with caching and model versioning.
        """
        
        # Check cache
        cache_key = f"pred:next_issue:{tenant_id}:{customer_id}"
        cached = self.redis.get(cache_key)
        if cached:
            return json.loads(cached)
        
        # Load customer issue history
        cutoff = datetime.utcnow() - timedelta(days=history_window)
        history = self.db.query(
            Ticket.issue_category
        ).filter(
            Ticket.customer_id == customer_id,
            Ticket.tenant_id == tenant_id,
            Ticket.created_at >= cutoff
        ).order_by(Ticket.created_at.desc()).all()
        
        if not history:
            return {
                "customer_id": customer_id,
                "predictions": [],
                "model_version": None,
                "message": "Insufficient history"
            }
        
        # Get production model
        prod_version = self.redis.get(f"model:production:lstm_next_issue").decode('utf-8')
        model = self._load_lstm_model(prod_version)
        
        # Prepare sequence and predict
        sequence = self._prepare_lstm_sequence(history, history_window)
        top_3 = model.predict_next_issues(sequence)
        
        result = {
            "customer_id": customer_id,
            "predictions": [
                {
                    "rank": i+1,
                    "issue_category": cat,
                    "probability": prob
                }
                for i, (cat, prob) in enumerate(top_3)
            ],
            "model_version": prod_version,
            "predicted_at": datetime.utcnow().isoformat(),
            "cache_hit": False
        }
        
        # Cache result for 1 hour
        self.redis.setex(cache_key, 3600, json.dumps(result, default=str))
        
        return result
    
    def predict_churn(self, customer_id, tenant_id, include_drivers=True):
        """Predict 72-hour churn with SHAP drivers."""
        
        cache_key = f"pred:churn:{tenant_id}:{customer_id}"
        cached = self.redis.get(cache_key)
        if cached:
            return json.loads(cached)
        
        # Engineer features
        features = engineer_churn_features(customer_id, tenant_id, db_session=self.db)
        
        # Load production churn model
        prod_version = self.redis.get(f"model:production:xgboost_churn").decode('utf-8')
        churn_model = joblib.load(f"{self.registry_path}/churn_model.pkl")
        
        # Predict with SHAP
        prediction = churn_model.predict_single(features)
        
        result = {
            "customer_id": customer_id,
            "churn_probability": prediction["churn_probability"],
            "risk_level": prediction["risk_level"],
            "top_drivers": prediction["top_drivers"] if include_drivers else [],
            "model_version": prod_version,
            "predicted_at": datetime.utcnow().isoformat()
        }
        
        # Cache for 30 minutes (churned customers checked frequently)
        self.redis.setex(cache_key, 1800, json.dumps(result, default=str))
        
        return result
    
    def forecast_volume(self, tenant_id, start_date, end_date, granularity='daily'):
        """Forecast support volume with confidence intervals."""
        
        # Get production Prophet model
        prod_version = self.redis.get(f"model:production:prophet_volume").decode('utf-8')
        with open(f"{self.registry_path}/prophet_v{prod_version}.pkl", "rb") as f:
            forecaster = pickle.load(f)
        
        # Generate forecast
        days_ahead = (end_date - start_date).days
        forecast = forecaster.forecast(periods=days_ahead)
        
        # Filter to requested range
        forecast_filtered = forecast[
            (forecast['ds'] >= start_date) & (forecast['ds'] <= end_date)
        ]
        
        return {
            "tenant_id": tenant_id,
            "granularity": granularity,
            "forecast": [
                {
                    "date": row['ds'].isoformat(),
                    "forecast_volume": int(row['yhat']),
                    "lower_bound": int(row['yhat_lower']),
                    "upper_bound": int(row['yhat_upper']),
                    "trend_component": int(row['trend'])
                }
                for _, row in forecast_filtered.iterrows()
            ],
            "model_version": prod_version,
            "generated_at": datetime.utcnow().isoformat()
        }
    
    def _load_lstm_model(self, version):
        """Load LSTM model from registry."""
        if version not in self.models_cache:
            model = tf.keras.models.load_model(f"{self.registry_path}/lstm_next_issue_v{version}.h5")
            self.models_cache[version] = model
        return self.models_cache[version]
```
