# S3.9 — Business Intelligence & Analytics Dashboards

**Sprint:** 3 (Enrichment & Context Layers)  
**Deliverable:** Real-time/historical analytics dashboards, materialized views, API metrics endpoints  
**Effort:** 3 days  
**Dependencies:** S2.7 (Triage agent graph), S3.1 (Customer enrichment), Database (PostgreSQL with pg_cron)

---

## Overview

**Analytics layer** provides real-time and historical visibility into triage performance, agent effectiveness, customer outcomes, and system anomalies:
- Triage automation rate, escalation patterns, resolution times
- Agent accuracy by intent, tool usage, cost per ticket
- Customer satisfaction, retention, churn prevention
- Anomaly detection (EWMA-based control limits)

**Dashboard consumers:** support managers, product team, customer success  
**Stack:** SQL materialized views + FastAPI metrics endpoints + Grafana/Metabase frontend

### 2. Materialized Views

**View: v_triage_daily**  
Aggregates daily triage performance (refreshed every 15 min):

```sql
CREATE MATERIALIZED VIEW v_triage_daily AS
SELECT
    DATE(c.created_at) AS date,
    COUNT(c.id) AS ticket_count,
    SUM(CASE WHEN c.escalated_at IS NULL THEN 1 ELSE 0 END)::FLOAT / COUNT(c.id) AS triage_rate,
    SUM(CASE WHEN c.escalated_at IS NOT NULL THEN 1 ELSE 0 END)::FLOAT / COUNT(c.id) AS escalation_rate,
    AVG(EXTRACT(EPOCH FROM (COALESCE(c.resolved_at, c.updated_at) - c.created_at))) AS avg_resolution_sec,
    PERCENTILE_CONT(0.95) WITHIN GROUP (ORDER BY EXTRACT(EPOCH FROM (COALESCE(c.resolved_at, c.updated_at) - c.created_at))) AS p95_resolution_sec
FROM
    conversations c
WHERE
    c.created_at >= CURRENT_DATE - INTERVAL '90 days'
GROUP BY
    DATE(c.created_at)
ORDER BY
    date DESC;

CREATE INDEX idx_v_triage_daily_date ON v_triage_daily(date);
```

**View: v_intent_accuracy**  
Tracks decision accuracy by intent type:

```sql
CREATE MATERIALIZED VIEW v_intent_accuracy AS
SELECT
    il.intent_label AS intent,
    COUNT(il.id) AS total,
    SUM(CASE WHEN il.is_correct = TRUE THEN 1 ELSE 0 END) AS correct,
    ROUND(100.0 * SUM(CASE WHEN il.is_correct = TRUE THEN 1 ELSE 0 END) / COUNT(il.id), 2) AS accuracy_pct
FROM
    intent_labels il
WHERE
    il.created_at >= CURRENT_DATE - INTERVAL '30 days'
GROUP BY
    il.intent_label
ORDER BY
    total DESC;

CREATE INDEX idx_v_intent_accuracy_intent ON v_intent_accuracy(intent);
```

**View: v_agent_tool_usage**  
Agent tool invocation patterns and performance:

```sql
CREATE MATERIALIZED VIEW v_agent_tool_usage AS
SELECT
    tc.tool_name,
    COUNT(tc.id) AS call_count,
    AVG(tc.latency_ms) AS avg_latency_ms,
    ROUND(100.0 * SUM(CASE WHEN tc.error_code IS NOT NULL THEN 1 ELSE 0 END) / COUNT(tc.id), 2) AS error_rate_pct
FROM
    tool_calls tc
WHERE
    tc.created_at >= CURRENT_DATE - INTERVAL '30 days'
GROUP BY
    tc.tool_name
ORDER BY
    call_count DESC;

CREATE INDEX idx_v_agent_tool_usage_tool ON v_agent_tool_usage(tool_name);
```

**View: v_customer_outcomes**  
Cohort-based customer satisfaction, retention, LTV delta:

```sql
CREATE MATERIALIZED VIEW v_customer_outcomes AS
SELECT
    DATE(c.created_at) AS cohort_date,
    AVG(cs.satisfaction_score) AS satisfaction_avg,
    ROUND(100.0 * SUM(CASE WHEN cu.churned_at IS NULL THEN 1 ELSE 0 END)::FLOAT / COUNT(DISTINCT c.customer_id), 2) AS retention_rate_pct,
    AVG(CASE WHEN cu.ltv_current_usd IS NOT NULL THEN cu.ltv_current_usd - COALESCE(cu.ltv_prior_usd, 0) ELSE 0 END) AS ltv_delta_usd
FROM
    conversations c
LEFT JOIN csat_ratings cs ON cs.conversation_id = c.id
LEFT JOIN customer_outcomes cu ON cu.customer_id = c.customer_id
WHERE
    c.created_at >= CURRENT_DATE - INTERVAL '90 days'
GROUP BY
    cohort_date
ORDER BY
    cohort_date DESC;

CREATE INDEX idx_v_customer_outcomes_cohort ON v_customer_outcomes(cohort_date);
```

### 3. Agent Performance Metrics Endpoint

```python
from fastapi import APIRouter, Depends, Header, Query
from datetime import datetime, timedelta
from typing import List, Dict

router = APIRouter(prefix="/api/v1/analytics", tags=["analytics"])

@dataclass
class IntentPerformance:
    intent: str
    total_queries: int
    correct_decisions: int
    accuracy: float
    top_tools_used: List[str]

@dataclass
class AgentPerformanceResponse:
    window: str
    by_intent: List[IntentPerformance]
    overall_accuracy: float
    avg_tools_per_ticket: float
    model_cost_usd_total: float

@router.get("/agent-performance", response_model=AgentPerformanceResponse)
async def get_agent_performance(
    window: str = Query("7d", regex="^(1d|7d|30d)$"),
    db = Depends(get_db),
    x_tenant_id: int = Header(...)
) -> AgentPerformanceResponse:
    """
    Get agent decision accuracy and tool usage by intent.
    
    Query intent_labels (grouped by intent) + tool_calls (aggregated).
    """
    
    days = {"1d": 1, "7d": 7, "30d": 30}[window]
    since = datetime.utcnow() - timedelta(days=days)
    
    # Intent accuracy
    intent_rows = await db.fetch("""
        SELECT
            intent_label,
            COUNT(*) AS total,
            SUM(CASE WHEN is_correct = TRUE THEN 1 ELSE 0 END) AS correct,
            ROUND(100.0 * SUM(CASE WHEN is_correct = TRUE THEN 1 ELSE 0 END) / COUNT(*), 2) AS accuracy
        FROM intent_labels
        WHERE tenant_id = $1 AND created_at >= $2
        GROUP BY intent_label
        ORDER BY total DESC
    """, x_tenant_id, since)
    
    # Tool usage per intent
    tool_rows = await db.fetch("""
        SELECT
            il.intent_label,
            tc.tool_name,
            COUNT(tc.id) AS call_count
        FROM tool_calls tc
        JOIN intent_labels il ON il.conversation_id = tc.conversation_id
        WHERE tc.tenant_id = $1 AND tc.created_at >= $2
        GROUP BY il.intent_label, tc.tool_name
    """, x_tenant_id, since)
    
    # Build top tools per intent
    tools_by_intent = {}
    for row in tool_rows:
        intent = row["intent_label"]
        if intent not in tools_by_intent:
            tools_by_intent[intent] = []
        tools_by_intent[intent].append((row["tool_name"], row["call_count"]))
    
    for intent in tools_by_intent:
        tools_by_intent[intent] = sorted(
            tools_by_intent[intent],
            key=lambda x: x[1],
            reverse=True
        )[:3]  # Top 3 tools
    
    by_intent = [
        IntentPerformance(
            intent=row["intent_label"],
            total_queries=row["total"],
            correct_decisions=row["correct"],
            accuracy=row["accuracy"] / 100.0,
            top_tools_used=[t[0] for t in tools_by_intent.get(row["intent_label"], [])]
        )
        for row in intent_rows
    ]
    
    overall_accuracy = sum(r.correct_decisions for r in by_intent) / max(sum(r.total_queries for r in by_intent), 1)
    
    # Tool usage and cost
    tool_stats = await db.fetch("""
        SELECT
            COUNT(*) AS tool_calls,
            AVG(tokens_used) AS avg_tokens_per_call
        FROM tool_calls
        WHERE tenant_id = $1 AND created_at >= $2
    """, x_tenant_id, since)
    
    avg_tokens = tool_stats[0]["avg_tokens_per_call"] or 0
    avg_tools_per_ticket = (tool_stats[0]["tool_calls"] or 0) / max(len(by_intent), 1)
    model_cost_usd = (avg_tokens * len(by_intent)) / 1000 * 0.002  # GPT-4 approximate
    
    return AgentPerformanceResponse(
        window=window,
        by_intent=by_intent,
        overall_accuracy=overall_accuracy,
        avg_tools_per_ticket=avg_tools_per_ticket,
        model_cost_usd_total=model_cost_usd
    )
```

### 4. Customer Outcomes Endpoint

```python
from datetime import datetime, timedelta

@dataclass
class CustomerOutcomesResponse:
    window: str
    avg_satisfaction: float
    retention_rate: float
    promoter_delta: float  # NPS promoters this period vs. last
    ltv_impact_usd: float
    churn_prevented_count: int

@router.get("/customer-outcomes", response_model=CustomerOutcomesResponse)
async def get_customer_outcomes(
    window: str = Query("30d", regex="^(1d|7d|30d)$"),
    db = Depends(get_db),
    x_tenant_id: int = Header(...)
) -> CustomerOutcomesResponse:
    """
    Get customer satisfaction, retention, NPS, and LTV impact.
    
    churn_prevented_count: tickets where health_score='at_risk' and customer
    did not churn within 30 days post-interaction.
    """
    
    days = {"1d": 1, "7d": 7, "30d": 30}[window]
    since = datetime.utcnow() - timedelta(days=days)
    prior_since = since - timedelta(days=days)
    
    # Satisfaction
    csat = await db.fetchval("""
        SELECT AVG(cs.satisfaction_score)
        FROM csat_ratings cs
        JOIN conversations c ON c.id = cs.conversation_id
        WHERE c.tenant_id = $1 AND c.created_at >= $2
    """, x_tenant_id, since)
    
    # Retention
    retention = await db.fetchval("""
        SELECT
            ROUND(100.0 * SUM(CASE WHEN cu.churned_at IS NULL THEN 1 ELSE 0 END)::FLOAT / COUNT(DISTINCT c.customer_id), 2)
        FROM conversations c
        LEFT JOIN customer_outcomes cu ON cu.customer_id = c.customer_id
        WHERE c.tenant_id = $1 AND c.created_at >= $2
    """, x_tenant_id, since)
    
    # NPS promoters (current vs. prior period)
    current_promoters = await db.fetchval("""
        SELECT COUNT(DISTINCT cs.respondent_id)
        FROM csat_ratings cs
        JOIN conversations c ON c.id = cs.conversation_id
        WHERE c.tenant_id = $1 AND c.created_at >= $2 AND cs.satisfaction_score >= 5
    """, x_tenant_id, since)
    
    prior_promoters = await db.fetchval("""
        SELECT COUNT(DISTINCT cs.respondent_id)
        FROM csat_ratings cs
        JOIN conversations c ON c.id = cs.conversation_id
        WHERE c.tenant_id = $1 AND c.created_at >= $2 AND c.created_at < $3 AND cs.satisfaction_score >= 5
    """, x_tenant_id, prior_since, since)
    
    promoter_delta = (current_promoters or 0) - (prior_promoters or 0)
    
    # LTV impact
    ltv_impact = await db.fetchval("""
        SELECT AVG(cu.ltv_current_usd - COALESCE(cu.ltv_prior_usd, 0))
        FROM conversations c
        JOIN customer_outcomes cu ON cu.customer_id = c.customer_id
        WHERE c.tenant_id = $1 AND c.created_at >= $2
    """, x_tenant_id, since)
    
    # Churn prevented: at_risk tickets where customer didn't churn 30d later
    churn_prevented = await db.fetchval("""
        SELECT COUNT(DISTINCT c.id)
        FROM conversations c
        JOIN customer_enrichment_cache cec ON cec.customer_id = c.customer_id
        LEFT JOIN customer_outcomes cu ON cu.customer_id = c.customer_id
        WHERE c.tenant_id = $1
          AND c.created_at >= $2
          AND cec.is_at_risk = TRUE
          AND (cu.churned_at IS NULL OR cu.churned_at > c.created_at + INTERVAL '30 days')
    """, x_tenant_id, since)
    
    return CustomerOutcomesResponse(
        window=window,
        avg_satisfaction=csat or 0.0,
        retention_rate=(retention or 0) / 100.0,
        promoter_delta=promoter_delta,
        ltv_impact_usd=ltv_impact or 0.0,
        churn_prevented_count=churn_prevented or 0
    )
```

### 5. Anomaly Detection

```python
from typing import Optional
from dataclasses import dataclass
from datetime import datetime
import math

@dataclass
class AnomalyEvent:
    metric_name: str
    value: float
    expected_range: tuple  # (low, high)
    severity: str  # 'warning' | 'critical'
    detected_at: datetime
    description: str

class AnomalyDetector:
    """EWMA-based anomaly detection with control limits."""
    
    def __init__(self, db, redis_cache, slack_webhook_url: str = None):
        self.db = db
        self.cache = redis_cache
        self.slack_webhook = slack_webhook_url
    
    async def detect(
        self,
        metric_name: str,
        value: float,
        timestamp: datetime = None
    ) -> Optional[AnomalyEvent]:
        """
        Detect anomalies using EWMA baseline with ±3σ control limits.
        Returns AnomalyEvent if anomaly detected, None otherwise.
        """
        
        if timestamp is None:
            timestamp = datetime.utcnow()
        
        # Get EWMA baseline from cache or compute
        cache_key = f"anomaly:baseline:{metric_name}"
        baseline_data = await self.cache.get(cache_key)
        
        if not baseline_data:
            baseline_data = await self._compute_baseline(metric_name)
            await self.cache.set(cache_key, baseline_data, ex=3600)
        else:
            baseline_data = json.loads(baseline_data)
        
        ewma_mean = baseline_data.get("ewma_mean", value)
        ewma_std = baseline_data.get("ewma_std", 0.1 * ewma_mean)  # 10% default
        
        # Control limits: mean ± 3σ
        lower_limit = ewma_mean - 3 * ewma_std
        upper_limit = ewma_mean + 3 * ewma_std
        
        # Detect anomaly
        if not (lower_limit <= value <= upper_limit):
            severity = "critical" if abs(value - ewma_mean) > 4 * ewma_std else "warning"
            
            anomaly = AnomalyEvent(
                metric_name=metric_name,
                value=value,
                expected_range=(lower_limit, upper_limit),
                severity=severity,
                detected_at=timestamp,
                description=f"{metric_name} = {value:.2f} (expected {ewma_mean:.2f} ± {3 * ewma_std:.2f})"
            )
            
            # Store in DB
            await self.db.execute("""
                INSERT INTO anomaly_events (metric_name, value, expected_low, expected_high, severity, detected_at)
                VALUES ($1, $2, $3, $4, $5, $6)
            """, metric_name, value, lower_limit, upper_limit, severity, timestamp)
            
            # Alert on critical
            if severity == "critical" and self.slack_webhook:
                await self._alert_slack(anomaly)
            
            return anomaly
        
        return None
    
    async def _compute_baseline(self, metric_name: str) -> dict:
        """Compute EWMA baseline from last 30 days of metric history."""
        
        rows = await self.db.fetch("""
            SELECT value, recorded_at
            FROM metric_history
            WHERE metric_name = $1 AND recorded_at >= CURRENT_TIMESTAMP - INTERVAL '30 days'
            ORDER BY recorded_at ASC
        """, metric_name)
        
        if not rows:
            return {"ewma_mean": 0, "ewma_std": 0}
        
        values = [float(r["value"]) for r in rows]
        
        # Simple EWMA (α = 0.3)
        ewma = values[0]
        alpha = 0.3
        for v in values[1:]:
            ewma = alpha * v + (1 - alpha) * ewma
        
        # Standard deviation
        mean = sum(values) / len(values)
        variance = sum((v - mean) ** 2 for v in values) / len(values)
        std = math.sqrt(variance)
        
        return {"ewma_mean": ewma, "ewma_std": std}
    
    async def _alert_slack(self, anomaly: AnomalyEvent):
        """Send critical anomaly alert to Slack."""
        
        import aiohttp
        
        payload = {
            "text": f"🚨 CRITICAL ANOMALY: {anomaly.metric_name}",
            "attachments": [
                {
                    "color": "danger",
                    "fields": [
                        {"title": "Metric", "value": anomaly.metric_name, "short": True},
                        {"title": "Value", "value": f"{anomaly.value:.2f}", "short": True},
                        {"title": "Expected Range", "value": f"[{anomaly.expected_range[0]:.2f}, {anomaly.expected_range[1]:.2f}]", "short": True},
                        {"title": "Detected", "value": anomaly.detected_at.isoformat(), "short": True},
                    ]
                }
            ]
        }
        
        async with aiohttp.ClientSession() as session:
            async with session.post(self.slack_webhook, json=payload) as resp:
                return resp.status == 200
```

## Database Schema

```sql
-- Anomaly events table
CREATE TABLE anomaly_events (
    id BIGSERIAL PRIMARY KEY,
    tenant_id BIGINT NOT NULL REFERENCES tenants(id),
    metric_name VARCHAR(100) NOT NULL,
    value NUMERIC(15, 6) NOT NULL,
    expected_low NUMERIC(15, 6) NOT NULL,
    expected_high NUMERIC(15, 6) NOT NULL,
    severity VARCHAR(20) NOT NULL CHECK (severity IN ('warning', 'critical')),
    detected_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    acknowledged_at TIMESTAMPTZ,
    acknowledged_by_user_id BIGINT REFERENCES users(id),
    
    FOREIGN KEY (tenant_id) REFERENCES tenants(id)
);

CREATE INDEX idx_anomaly_events_tenant_time ON anomaly_events(tenant_id, detected_at DESC);
CREATE INDEX idx_anomaly_events_severity ON anomaly_events(severity) WHERE acknowledged_at IS NULL;

-- Metric history (for baselines)
CREATE TABLE metric_history (
    id BIGSERIAL PRIMARY KEY,
    tenant_id BIGINT NOT NULL REFERENCES tenants(id),
    metric_name VARCHAR(100) NOT NULL,
    value NUMERIC(15, 6) NOT NULL,
    recorded_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (tenant_id) REFERENCES tenants(id)
);

CREATE INDEX idx_metric_history_lookup ON metric_history(tenant_id, metric_name, recorded_at DESC);
```

## Implementation Notes

- **pg_cron extension:** Must be enabled in PostgreSQL via `shared_preload_libraries = 'pg_cron'`
- **EWMA algorithm:** Exponential Weighted Moving Average (α = 0.3) provides responsiveness to recent trends
- **Model cost:** `(total_LLM_tokens / 1000) * 0.002` approximates GPT-4 pricing; configurable per tenant
- **Read replica:** Grafana queries PostgreSQL read-replica to avoid impacting write performance
- **Cache metrics:** Redis stats fetched via INFO STATS command (connected_clients, keyspace_hits, keyspace_misses)
- **Multi-tenancy:** All queries filtered by X-Tenant-ID header; materialized views include tenant isolation
