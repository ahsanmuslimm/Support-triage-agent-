# S4.5 — Escalation Queue & SLA Management

## Overview
Managed queue for human-agent escalations with SLA tracking, auto-escalation, and full audit trail. Ensures every escalated conversation receives attention within the committed SLA window. This system provides visibility into escalation bottlenecks, proactive breach notifications, and historical accountability for all customer interactions requiring manual intervention.

---

## Technical Specification

### Queue Model
The escalation queue operates on a priority-based model with four tiers and multiple assignment strategies:

**Priority Tiers:**
- **P0** (Critical): System failures, security incidents, VIP customer emergency. Max 1-hour resolution SLA.
- **P1** (High): Product defects affecting multiple customers, urgent customer requests. Max 4-hour SLA.
- **P2** (Medium): Non-urgent issues, feature requests, standard support. Max 24-hour SLA.
- **P3** (Low): Informational, feedback collection, non-blocking concerns. Max 72-hour SLA.

**Assignment Rules:**
- **Round-Robin**: Cycles through available agents; prevents overload clustering.
- **Skill-Match**: Routes to agents with prior interaction or certification in the relevant product/domain.
- **Load-Based**: Assigns to agent with lowest current queue depth, rebalanced on login/logout.
- **Hybrid**: Skill-match as primary; fall back to load-based if no skilled agent available.

### SLA Tracking
Every escalated ticket has a computed SLA deadline based on priority tier and escalation timestamp. The system continuously monitors progress and triggers notifications at critical thresholds:

- **50% of SLA elapsed** → Supervisor notification (escalation to queue manager for awareness)
- **80% of SLA elapsed** → Manager escalation (escalation to department head for action)
- **100% of SLA elapsed** → Breach recorded and incident marked (affects team metrics)

SLA timers account for business hours only (configurable per tenant; defaults to 09:00–17:00 Mon–Fri).

### Auto-Escalation
A scheduled worker runs every minute to inspect active queue items:
1. For each item, calculate `time_remaining = sla_deadline - now`
2. Check against configured notification thresholds (50%, 80%, 100%)
3. If threshold crossed and not yet notified, emit notification and record breach event
4. Persist state change in audit trail with timestamp and actor = "system:sla-monitor"

### Escalation History
Immutable, append-only audit trail capturing every state transition, assignment change, and system action:
- Creation (system auto-escalates after AI triage timeout)
- Assignment (agent accepts or is assigned by rule)
- Resolution (agent marks complete with reason)
- Reassignment (moved between agents)
- SLA breach events (notification thresholds hit)
- Manual overrides (manager adjusts priority, bypasses assignment queue)

Each entry includes: actor type (agent/manager/system), actor ID, action type, previous state, new state, and ISO 8601 timestamp.

### Per-Tenant SLA Configuration
Tenants can customize SLA targets and notification timing. Defaults provided, but each tier and threshold is overridable per tenant_id:

```json
{
  "tenant_id": "acme_corp",
  "sla_tiers": {
    "P0": {"target_minutes": 60, "business_hours_only": true},
    "P1": {"target_minutes": 240, "business_hours_only": true},
    "P2": {"target_minutes": 1440, "business_hours_only": false},
    "P3": {"target_minutes": 4320, "business_hours_only": false}
  },
  "notification_thresholds": [50, 80, 100],
  "business_hours": {"start": "09:00", "end": "17:00", "tz": "America/New_York"}
}
```

## Data Model

### EscalationQueueItem

```sql
CREATE TABLE escalation_queue_items (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  escalation_id UUID NOT NULL UNIQUE REFERENCES escalations(id),
  tenant_id UUID NOT NULL REFERENCES tenants(id),
  priority VARCHAR(2) NOT NULL CHECK (priority IN ('P0', 'P1', 'P2', 'P3')),
  assigned_agent_id UUID REFERENCES agents(id),
  enqueued_at TIMESTAMP NOT NULL DEFAULT NOW(),
  sla_deadline TIMESTAMP NOT NULL,
  status VARCHAR(20) NOT NULL DEFAULT 'pending' CHECK (status IN ('pending', 'assigned', 'in_progress', 'resolved', 'escalated')),
  resolution_reason VARCHAR(500),
  updated_at TIMESTAMP NOT NULL DEFAULT NOW(),
  created_at TIMESTAMP NOT NULL DEFAULT NOW(),
  
  CONSTRAINT assigned_agent_not_null_if_assigned CHECK (
    (status IN ('assigned', 'in_progress') AND assigned_agent_id IS NOT NULL) OR
    (status NOT IN ('assigned', 'in_progress'))
  )
);

CREATE INDEX idx_queue_fetch ON escalation_queue_items(tenant_id, status, priority, sla_deadline);
CREATE INDEX idx_queue_agent ON escalation_queue_items(assigned_agent_id, status);
CREATE INDEX idx_queue_deadline ON escalation_queue_items(sla_deadline) WHERE status != 'resolved';
```

### SLAConfig


## Implementation

### Priority Scoring Algorithm

```python
def compute_priority_score(escalation):
    """
    Compute numeric priority for queue ordering.
    Higher score = higher priority.
    """
    priority_base = {
        'P0': 10000,
        'P1': 7500,
        'P2': 5000,
        'P3': 2500
    }
    
    score = priority_base.get(escalation['priority'], 0)
    
    # Urgency boosts
    if escalation.get('is_vip_customer'):
        score += 2000
    
    if escalation.get('repeat_contact_count', 0) > 2:
        score += 1000
    
    # Sentiment boost (negative sentiment = higher priority)
    sentiment = escalation.get('sentiment_score', 0.0)
    if sentiment < -0.5:  # Very negative
        score += 1500
    elif sentiment < -0.2:  # Somewhat negative
        score += 500
    
    # Age boost (longer in queue = boosted priority)
    age_hours = (now() - escalation['created_at']).total_seconds() / 3600
    age_boost = min(age_hours * 50, 2000)  # Cap at +2000
    score += age_boost
    
    return score
```

### SLA Deadline Computation

```python
def compute_sla_deadline(escalation_id, sla_config):
    """
    Compute SLA deadline accounting for business hours.
    """
    escalation = get_escalation(escalation_id)
    priority = escalation['priority']
    start_time = escalation['created_at']
    
    target_minutes = sla_config['sla_tiers'][priority]['target_minutes']
    business_hours_only = sla_config['sla_tiers'][priority]['business_hours_only']
    
    if not business_hours_only:
        return start_time + timedelta(minutes=target_minutes)
    
    # Business hours only: accumulate calendar time
    tz = pytz.timezone(sla_config['business_hours']['tz'])
    business_start = time.fromisoformat(sla_config['business_hours']['start'])
    business_end = time.fromisoformat(sla_config['business_hours']['end'])
    
    current = start_time.astimezone(tz)
    minutes_remaining = target_minutes
    
    while minutes_remaining > 0:
        # Check if current time is within business hours
        if current.weekday() not in sla_config['business_hours']['days']:
            # Not a business day; skip to next business day 09:00
            current = current.replace(hour=business_start.hour, minute=0, second=0) + timedelta(days=1)
            continue
        
        if current.time() < business_start:
            current = current.replace(hour=business_start.hour, minute=0, second=0)
        elif current.time() >= business_end:
            current = current.replace(hour=business_start.hour, minute=0, second=0) + timedelta(days=1)
            continue
        
        # Consume available business minutes
        end_of_day = current.replace(hour=business_end.hour, minute=0, second=0)
        available_minutes = int((end_of_day - current).total_seconds() / 60)
        
        if available_minutes >= minutes_remaining:
            return current + timedelta(minutes=minutes_remaining)
        
        minutes_remaining -= available_minutes
        current = current.replace(hour=business_start.hour, minute=0, second=0) + timedelta(days=1)
    
    return current
```

### Auto-Escalation Scheduler (Celery Beat)

```python
from celery import shared_task
from celery.beat import ScheduleEntry

@shared_task
def check_sla_thresholds():
    """
    Celery task: run every minute to check for SLA milestone breaches.
    """
    now = datetime.utcnow()
    
    # Find all active queue items
    items = EscalationQueueItem.objects.filter(
        status__in=['pending', 'assigned', 'in_progress']
    ).select_related('escalation', 'tenant')
    
    for item in items:
        sla_config = get_sla_config(item.tenant_id)
        time_remaining = (item.sla_deadline - now).total_seconds()
        total_sla_seconds = (item.sla_deadline - item.enqueued_at).total_seconds()
        
        if time_remaining <= 0:
            pct_elapsed = 100
        else:
            pct_elapsed = int(100 * (1 - time_remaining / total_sla_seconds))
        
        thresholds = sla_config['notification_thresholds']
        
        for threshold in thresholds:
            if pct_elapsed >= threshold:
                # Check if breach already recorded
                breach_exists = SLABreach.objects.filter(
                    queue_item_id=item.id,
                    breach_type=threshold
                ).exists()
                
                if not breach_exists:
                    # Record breach
                    breach = SLABreach.objects.create(
                        queue_item_id=item.id,
                        tenant_id=item.tenant_id,
                        breach_type=threshold,
                        breached_at=now,
                        notification_channel='slack'  # or email, etc.
                    )
                    
                    # Send notification
                    send_sla_breach_notification(item, threshold)
                    
                    # Record in audit trail
                    EscalationHistoryEntry.objects.create(
                        queue_item_id=item.id,
                        tenant_id=item.tenant_id,
                        actor_type='system',
                        action=f'sla_threshold_{threshold}_pct',
                        previous_state={},
                        new_state={'breach_recorded': True},
                        ts=now
                    )
    
    return {'checked': items.count()}

# Register with Celery Beat
CELERY_BEAT_SCHEDULE = {
    'check-sla-thresholds': {
        'task': 'support_triage.tasks.check_sla_thresholds',
        'schedule': crontab(minute='*'),  # Every minute
        'options': {'queue': 'high_priority'}
    }
}
```

### Assignment Algorithm

```python
def assign_queue_item(queue_item_id, assignment_strategy='hybrid', skill_tags=None):
    """
    Assign a queue item to an available agent using the specified strategy.
    """
    item = EscalationQueueItem.objects.get(id=queue_item_id)
    
    if assignment_strategy == 'skill-match' and skill_tags:
        # Find agents with matching skills and capacity
        candidates = Agent.objects.filter(
            tenant_id=item.tenant_id,
            status='available',
            skills__tag__in=skill_tags
        ).annotate(
            queue_depth=Count('escalation_queue_items__id', 
                             filter=Q(escalation_queue_items__status__in=['assigned', 'in_progress']))
        ).order_by('queue_depth')[:5]
        
        if candidates:
            agent = candidates[0]
        else:
            # Fall back to load-based
            agent = assign_queue_item(queue_item_id, 'load-based')
    
    elif assignment_strategy == 'load-based':
        agent = Agent.objects.filter(
            tenant_id=item.tenant_id,
            status='available'
        ).annotate(
            queue_depth=Count('escalation_queue_items__id',
                             filter=Q(escalation_queue_items__status__in=['assigned', 'in_progress']))
        ).order_by('queue_depth').first()
    
    elif assignment_strategy == 'round-robin':
        last_assigned = Agent.objects.filter(
            tenant_id=item.tenant_id,
            escalation_queue_items__isnull=False
        ).order_by('-escalation_queue_items__updated_at').first()
        
        agents = list(Agent.objects.filter(
            tenant_id=item.tenant_id,
            status='available'
        ).order_by('id'))
        
        if last_assigned and last_assigned in agents:
            idx = agents.index(last_assigned)
            agent = agents[(idx + 1) % len(agents)]
        else:
            agent = agents[0] if agents else None
    
    if agent:
        item.assigned_agent_id = agent.id
        item.status = 'assigned'
        item.save()
        
        EscalationHistoryEntry.objects.create(
            queue_item_id=item.id,
            tenant_id=item.tenant_id,
            actor_type='system',
            action='assigned',
            previous_state={'assigned_agent_id': None, 'status': 'pending'},
            new_state={'assigned_agent_id': str(agent.id), 'status': 'assigned'},
            notes=f'Assignment strategy: {assignment_strategy}'
        )
        
        return agent
    
    return None
```

### Breach Idempotency

Breach recording is keyed on `(queue_item_id, breach_type)` with a UNIQUE constraint. The Celery task checks for existence before creating, preventing duplicate notifications:

```python
breach, created = SLABreach.objects.get_or_create(

    breach_type=threshold,

        'notification_channel': 'slack'
    }
```

```python
    EscalationHistoryEntry.objects.create(
        queue_item_id=item.id,
        tenant_id=tenant.id,
        actor_type='agent',
        actor_id=agent.id,
        action='self_assigned',
        previous_state={'status': 'pending'},
        new_state={'status': 'assigned'}
    )
    
    history = EscalationHistoryEntry.objects.filter(queue_item_id=item.id).order_by('ts')
    assert history.count() == 2
    assert history[0].action == 'created'
    assert history[1].action == 'self_assigned'
```

### Database Indexing for Performance

The following indices ensure queue fetch queries (the primary operational load) complete in < 100ms even with millions of rows:

```sql
-- Primary queue fetch index
CREATE INDEX idx_queue_fetch 
ON escalation_queue_items(tenant_id, status, priority DESC, sla_deadline ASC);

-- Agent queue depth queries
CREATE INDEX idx_queue_agent 
ON escalation_queue_items(assigned_agent_id, status) 
WHERE status IN ('assigned', 'in_progress');

-- SLA deadline monitoring (for auto-escalation scheduler)
CREATE INDEX idx_sla_deadline 
ON escalation_queue_items(sla_deadline) 
WHERE status != 'resolved';

-- Audit trail queries
CREATE INDEX idx_history_queue_ts 
ON escalation_history(queue_item_id, ts DESC);

-- Breach trend analysis
CREATE INDEX idx_breaches_tenant_date 
ON sla_breaches(tenant_id, created_at DESC) 
WHERE notification_sent = true;
```
