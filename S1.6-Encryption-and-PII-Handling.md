## Overview

Implement multi-layered encryption and PII protection:

1. **Envelope encryption** — Data encryption keys (DEK) encrypted by key encryption keys (KEK)
2. **At-rest encryption** — PostgreSQL column-level or database-level
3. **PII redaction** — Pseudonymization vault for email, phone, names
4. **Audit logging** — Track who accesses PII, when, and why
5. **Privacy controls** — Opt-out for data collection, pseudonymization on request

## Technical Specification

### 1. Encryption Architecture

**Envelope Encryption Model:**

```
┌─────────────────────────────────────────┐
│ Customer Message (plaintext)            │
│ "Hi, my order #12345 is delayed"        │
└──────────────┬──────────────────────────┘
               ▼
┌─────────────────────────────────────────┐
│ Generate DEK (random 32-byte key)       │
│ Encrypt plaintext with AES-256-GCM      │
└──────────────┬──────────────────────────┘
               ▼
┌─────────────────────────────────────────┐
│ Encrypted message + IV + Auth tag       │
│ (DEK remains in memory)                 │
└──────────────┬──────────────────────────┘
               ▼
┌─────────────────────────────────────────┐
│ Encrypt DEK with KEK (stored in KeyVault)
│ DEK(encrypted) stored in database       │
└──────────────┬──────────────────────────┘
               ▼
┌─────────────────────────────────────────┐
│ Store in PostgreSQL:                    │
│ - ciphertext (blob)                     │
│ - iv (16-byte, prepended)               │
│ - auth_tag (16-byte, prepended)         │
│ - encrypted_dek (blob)                  │
└─────────────────────────────────────────┘
```

**KEK Storage:**

- Store Master KEK in **Azure KeyVault** or **AWS KMS** (external, highly available)
- Rotate KEK yearly
- DEK encrypted with current KEK version
- Support old KEK versions for decryption (backward compatibility)

### 2. PostgreSQL Schema

```sql

-- Encrypted message body

    is_pii_redacted BOOLEAN DEFAULT FALSE,
    pii_pseudonym_ids TEXT[],                  -- Array of vault token IDs

        (body IS NOT NULL AND body_encrypted IS NULL) OR
        (body IS NULL AND body_encrypted IS NOT NULL)
    )
);

    id BIGSERIAL PRIMARY KEY,

    id BIGSERIAL PRIMARY KEY,

    reason VARCHAR(255),                       -- Why PII was accessed
    accessed_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (tenant_id) REFERENCES tenants(id)
);
```

### 3. Encryption Manager

```python
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.kdf.pbkdf2 import PBKDF2
import os
import secrets

class EncryptionManager:
    def __init__(self, kek_provider):
        """
        kek_provider: Service that retrieves KEK from KeyVault
        """
        self.kek_provider = kek_provider
    
    def encrypt_message(self, plaintext: str, tenant_id: int) -> dict:
        """
        Encrypt message with AES-256-GCM.
        
        Returns:
        {
            "ciphertext": bytes (IV + auth_tag + ciphertext),
            "encrypted_dek": bytes (DEK encrypted with KEK),
            "kek_version": int
        }
        """
        
        # Generate DEK (Data Encryption Key)
        dek = secrets.token_bytes(32)  # 256-bit key
        
        # Get current KEK (Key Encryption Key) from KeyVault
        kek_version, kek = self.kek_provider.get_current_kek(tenant_id)
        
        # Generate IV
        iv = secrets.token_bytes(12)  # 96-bit IV (standard for GCM)
        
        # Encrypt plaintext with DEK
        cipher = AESGCM(dek)
        ciphertext = cipher.encrypt(iv, plaintext.encode(), None)
        
        # Ciphertext includes auth tag; prepend IV
        encrypted_message = iv + ciphertext
        
        # Encrypt DEK with KEK
        kek_cipher = AESGCM(kek)
        dek_iv = secrets.token_bytes(12)
        encrypted_dek = dek_iv + kek_cipher.encrypt(dek_iv, dek, None)
        
        return {
            "ciphertext": encrypted_message,
            "encrypted_dek": encrypted_dek,
            "kek_version": kek_version,
        }
    
    def decrypt_message(self, ciphertext: bytes, encrypted_dek: bytes, kek_version: int, tenant_id: int) -> str:
        """Decrypt message (requires KeyVault access)."""
        
        # Get KEK by version (supports old versions for backward compatibility)
        kek = self.kek_provider.get_kek_by_version(tenant_id, kek_version)
        
        # Extract IV and ciphertext
        iv = ciphertext[:12]
        ct = ciphertext[12:]
        
        # Decrypt DEK
        dek_iv = encrypted_dek[:12]
        encrypted_dek_ct = encrypted_dek[12:]
        kek_cipher = AESGCM(kek)
        dek = kek_cipher.decrypt(dek_iv, encrypted_dek_ct, None)
        
        # Decrypt message
        cipher = AESGCM(dek)
        plaintext = cipher.decrypt(iv, ct, None)
        
        return plaintext.decode()
```

### 4. PII Redaction Strategy

Use **Microsoft Presidio** for PII detection + pseudonymization vault.

```python
from presidio_analyzer import AnalyzerEngine
from presidio_anonymizer import AnonymizerEngine

class PIIRedactor:
    def __init__(self, vault_manager):
        self.analyzer = AnalyzerEngine()  # Detects PII
        self.anonymizer = AnonymizerEngine()  # Replaces PII
        self.vault = vault_manager  # Stores tokens
    
    async def redact_message(self, text: str, tenant_id: int, mode: str = "vault") -> tuple[str, list]:
        """
        Redact PII from message.
        
        Modes:
        - "vault": Replace with {{VAULT_abc123}} tokens
        - "mask": Replace with {{CREDIT_CARD}}, {{EMAIL}}, etc.
        - "none": Return as-is
        
        Returns:
        (redacted_text, vault_tokens)
        """
        
        if mode == "none":
            return text, []
        
        # Analyze text for PII
        results = self.analyzer.analyze(text, language="en")
        
        if not results:
            return text, []
        
        vault_tokens = []
        anonymized_text = text
        
        # Sort results by offset (reverse) to preserve offsets during replacement
        for result in sorted(results, key=lambda x: x.start, reverse=True):
            entity_type = result.entity_type  # EMAIL, PHONE_NUMBER, etc.
            value = text[result.start:result.end]
            
            if mode == "vault":
                # Create vault entry
                token = await self.vault.store_pii(
                    tenant_id=tenant_id,
                    pii_type=entity_type.lower(),
                    original_value=value
                )
                vault_tokens.append(token)
                
                # Replace with token reference
                placeholder = f"{{{{VAULT_{token}}}}}"
            else:  # mask
                placeholder = f"{{{{{entity_type}}}}}"
            
            # Replace in text
            anonymized_text = (
                anonymized_text[:result.start] +
                placeholder +
                anonymized_text[result.end:]
            )
        
        return anonymized_text, vault_tokens
```

### 7. Multi-Tenancy & Key Isolation

- One Master KEK per tenant (rotated annually)
- DEK per message (unique, random)
- Encryption/decryption scoped to tenant_id
- RLS on all encryption tables
