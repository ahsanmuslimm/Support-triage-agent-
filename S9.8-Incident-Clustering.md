# S9.8: Incident Clustering

Embedding-based similarity, 30-min lookback, and urgency boost.

## Implementation Summary
- Embedding-based similarity: Embed ticket summaries using multilingual-e5, compute cosine similarity
- Clustering threshold: 0.7 similarity trigger
- 30-min lookback: Only consider recent tickets (30-minute window)
- Linkage: Related tickets shown in timeline ("3 other customers reporting similar issue")
- Urgency boost: If 5+ tickets in cluster within 10min, boost urgency to P1
- Auto-runbook: Link known incident runbooks to clusters for faster resolution
- Cluster timeline: Display related tickets chronologically with similarity score
- Embedding model: Optional model injection; mock for testing
- ~350 lines code + 20 tests

## Key Classes
- IncidentClusterer: Main clustering engine
- TicketCluster: Cluster representation with metadata
- Cluster stats: Retrieval of clustering metrics
