# S8.4: Out-of-Distribution Detector

## Overview
Detect OOD examples using energy-based and centroid distance ensemble.

## Key Components
- **EnergyDetector**: E = -log(sum(exp(logits)))
- **CentroidDetector**: Distance to nearest training class centroid
- **OODEnsemble**: max(norm_energy, norm_distance)
- **ThresholdCalibrator**: Calibrate for 80% recall on novel intents
- **OODAnalyzer**: ROC-AUC, PR curves, full analysis

## Validation
- Threshold calibration: 80% recall on held-out novel intents
- Energy-based scoring and normalization
- Centroid distance in embedding space
- ROC AUC computation
