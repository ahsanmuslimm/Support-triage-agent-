# S3.5 — Knowledge Gap Analysis

**Sprint:** 3 (Enrichment & Context Layers)  
**Deliverable:** Coverage score per category, top-10 missing knowledge areas, expansion recommendations  
**Effort:** 2 days  
**Dependencies:** S2.4 (FAQ/KB schema), S2.7 (Triage agent graph), S3.8 (Continuous learning loop)

---

## Overview

**Knowledge Gap Analysis** identifies and quantifies holes in the knowledge base by analyzing queries that required escalation. Instead of assuming the KB is complete, this component listens to escalations and builds a data-driven map of what customers are asking about but the system cannot resolve.

**Outputs:**
- Coverage score per category (0–1, where 1.0 = all queries resolved by KB)
- Top-10 ranked missing knowledge areas with sample queries
- Actionable expansion recommendations (e.g., "Add FAQ: how to reset password")

**Feeds into:**
- Knowledge base maintenance workflow (prioritize which articles to write/update)
- S3.8 continuous learning loop (auto-suggest new KB articles)
- Analytics dashboards (coverage trends over time)

### 2. Query Categorizer

**Zero-shot classification** using a pretrained sentence transformer, with keyword fallback.

```python
from sentence_transformers import SentenceTransformer
import numpy as np
from typing import Dict, List
import logging

logger = logging.getLogger(__name__)


class QueryCategorizer:
    """Classify customer queries into predefined categories."""
    
    CATEGORIES = [
        "billing",
        "shipping",
        "returns",
        "product_info",
        "account_access",
        "technical_support",
        "subscription_management",
        "fraud_dispute",
        "feature_request",
        "other",
    ]
    
    # Fallback keyword mapping if transformer unavailable
    KEYWORD_MAPPING = {
        "billing": ["invoice", "charge", "payment", "refund", "price", "cost"],
        "shipping": ["delivery", "tracking", "ship", "carrier", "address"],
        "returns": ["return", "exchange", "replace", "defective", "broken"],
        "product_info": ["specs", "features", "dimensions", "color", "availability"],
        "account_access": ["password", "login", "reset", "email", "mfa", "2fa"],
        "technical_support": ["error", "bug", "crash", "not working", "issue"],
        "subscription_management": ["cancel", "downgrade", "upgrade", "plan", "billing cycle"],
        "fraud_dispute": ["fraud", "unauthorized", "dispute", "chargeback"],
        "feature_request": ["request", "wish", "want", "add", "implement"],
    }
    
    def __init__(self, model_name: str = "sentence-transformers/all-MiniLM-L6-v2"):
        """
        Initialize categorizer with transformer.
        
        Args:
            model_name: HuggingFace model identifier
        """
        self.transformer = None
        self.use_transformer = False
        
        try:
            self.transformer = SentenceTransformer(model_name)
            self.use_transformer = True
            logger.info(f"Loaded transformer model: {model_name}")
        except Exception as e:
            logger.warning(f"Transformer load failed: {e}. Falling back to keyword matching.")
    
    def categorize(self, query_text: str) -> str:
        """
        Classify a query into a category.
        
        Args:
            query_text: Customer query
            
        Returns:
            Category name
        """
        query_lower = query_text.lower()
        
        if self.use_transformer:
            return self._categorize_transformer(query_text)
        else:
            return self._categorize_keywords(query_lower)
    
    def _categorize_transformer(self, query_text: str) -> str:
        """Zero-shot classification using embeddings."""
        try:
            query_embedding = self.transformer.encode(query_text, convert_to_tensor=True)
            category_embeddings = self.transformer.encode(self.CATEGORIES, convert_to_tensor=True)
            
            # Compute cosine similarities
            similarities = np.dot(query_embedding, category_embeddings.T)
            best_idx = np.argmax(similarities)
            
            return self.CATEGORIES[best_idx]
        except Exception as e:
            logger.error(f"Transformer categorization failed: {e}")
            return self._categorize_keywords(query_text.lower())
    
    def _categorize_keywords(self, query_lower: str) -> str:
        """Fallback keyword matching."""
        scores: Dict[str, int] = {cat: 0 for cat in self.CATEGORIES}
        
        for category, keywords in self.KEYWORD_MAPPING.items():
            for keyword in keywords:
                if keyword in query_lower:
                    scores[category] += 1
        
        best_category = max(scores, key=scores.get)
        
        # If no keywords matched, return 'other'
        if scores[best_category] == 0:
            return "other"
        
        return best_category
```

### 3. Coverage Scorer

```python
from dataclasses import dataclass
from typing import List, Dict
from datetime import datetime


@dataclass
class QueryRecord:
    """A single customer query with resolution metadata."""
    query_id: str
    query_text: str
    category: str
    was_escalated: bool
    resolution_source: str  # 'kb' | 'agent' | 'escalated'
    created_at: datetime
    
    @staticmethod
    def from_db_row(row) -> "QueryRecord":
        """Convert DB row to QueryRecord."""
        return QueryRecord(
            query_id=row["id"],
            query_text=row["query_text"],
            category=row["category"],
            was_escalated=row["was_escalated"],
            resolution_source=row["resolution_source"],
            created_at=row["created_at"],
        )


def compute_coverage(queries: List[QueryRecord]) -> Dict[str, float]:
    """
    Compute coverage score per category and overall.
    
    Coverage = (queries resolved by KB) / (total queries in category)
    
    Args:
        queries: List of QueryRecord objects
        
    Returns:
        Dict with keys: 'billing', 'shipping', ..., 'overall'
    """
    coverage_by_category: Dict[str, Dict[str, int]] = {}
    
    # Initialize counters
    for query in queries:
        if query.category not in coverage_by_category:
            coverage_by_category[query.category] = {
                "total": 0,
                "resolved_by_kb": 0,
            }
    
    # Count
    for query in queries:
        coverage_by_category[query.category]["total"] += 1
        
        if query.resolution_source == "kb" and not query.was_escalated:
            coverage_by_category[query.category]["resolved_by_kb"] += 1
    
    # Calculate scores
    coverage_scores: Dict[str, float] = {}
    total_all = 0
    resolved_all = 0
    
    for category, counts in coverage_by_category.items():
        total = counts["total"]
        resolved = counts["resolved_by_kb"]
        
        coverage_scores[category] = resolved / total if total > 0 else 0.0
        total_all += total
        resolved_all += resolved
    
    # Overall coverage
    coverage_scores["overall"] = resolved_all / total_all if total_all > 0 else 0.0
    
    return coverage_scores
```

### 4. Gap Identifier

```python
from collections import defaultdict
from typing import Dict, Tuple
import math


def identify_gaps(
    coverage_by_category: Dict[str, float],
    escalated_queries: List[QueryRecord],
    top_n: int = 10,
) -> List[MissingAreaItem]:
    """
    Identify top gaps in knowledge base.
    
    Algorithm:
    1. Cluster escalated queries by category
    2. Rank by escalation_count descending
    3. Assign priority (high: >50/week, medium: 20–50, low: <20)
    4. Extract 3 representative sample queries per cluster
    
    Args:
        coverage_by_category: Output from compute_coverage()
        escalated_queries: List of queries with was_escalated=True
        top_n: Return top N gaps (default 10)
        
    Returns:
        List of MissingAreaItem sorted by escalation_count desc
    """
    
    # Cluster by category
    clusters: Dict[str, List[QueryRecord]] = defaultdict(list)
    
    for query in escalated_queries:
        clusters[query.category].append(query)
    
    # Build gap items
    gaps: List[MissingAreaItem] = []
    
    for category, queries in clusters.items():
        count = len(queries)
        
        # Estimate weekly rate (assume 7-day window in data)
        weekly_rate = count / 1  # Simple: treat input as 1-week data
        
        # Assign priority
        if weekly_rate > 50:
            priority = "high"
        elif weekly_rate >= 20:
            priority = "medium"
        else:
            priority = "low"
        
        # Extract 3 representative samples
        sample_size = min(3, len(queries))
        sample_queries = [q.query_text for q in queries[:sample_size]]
        
        gap = MissingAreaItem(
            topic=category,
            escalation_count=count,
            sample_queries=sample_queries,
            priority=priority,
        )
        
        gaps.append(gap)
    
    # Sort by escalation count descending, then by priority
    priority_order = {"high": 0, "medium": 1, "low": 2}
    gaps.sort(key=lambda g: (-g.escalation_count, priority_order[g.priority]))
    
    return gaps[:top_n]
```

### 5. Recommendation Generator

```python
def generate_recommendations(missing_areas: List[MissingAreaItem]) -> List[str]:
    """
    Generate actionable KB expansion recommendations.
    
    Template types:
    - "Add FAQ article for {topic}: covers {sample_query}"
    - "Create troubleshooting guide for {topic} (est. {count} queries/week)"
    - "Review and update existing {topic} articles (coverage {score:.0%})"
    
    Args:
        missing_areas: List of gaps from identify_gaps()
        
    Returns:
        List of recommendation strings, sorted by priority
    """
    
    recommendations: List[str] = []
    
    for gap in missing_areas:
        topic = gap.topic
        count = gap.escalation_count
        priority = gap.priority
        
        # Build recommendation based on priority
        if priority == "high":
            if count > 100:
                recommendation = (
                    f"🔴 URGENT: Create comprehensive guide for '{topic}' "
                    f"(~{count} escalations). Sample queries: {gap.sample_queries[0]}"
                )
            else:
                recommendation = (
                    f"🔴 Add FAQ article for '{topic}': covers {gap.sample_queries[0]}"
                )
        
        elif priority == "medium":
            recommendation = (
                f"🟡 Create troubleshooting guide for '{topic}' "
                f"(est. {count} queries). Key issue: {gap.sample_queries[0]}"
            )
        
        else:  # low
            recommendation = (
                f"🟢 Review and expand '{topic}' articles "
                f"({count} additional queries). Example: {gap.sample_queries[0]}"
            )
        
        recommendations.append(recommendation)
    
    return recommendations
```

## Implementation Notes

- **Nightly Schedule:** Cron job runs at 02:00 UTC. Configured via APScheduler or Celery Beat.
- **Query Source:** `QueryRecord` objects built from `conversations` table joined with `escalation_events`.
- **Transformer Model:** Loaded once at startup, cached in memory. Fallback to keyword matching if unavailable.
- **Results Caching:** Redis key format: `knowledge_gaps:{tenant_id}:{date}`, TTL = 24 hours.
- **Category Configuration:** Category list is configurable per tenant via `tenant_config` table.
- **No New DB Tables:** Reads from existing `conversations`, `escalation_events`, and `faq_articles` tables.

### Pseudo-code: Nightly Analysis Job

```python
async def run_gap_analysis_job():
    """
    Nightly job: analyze queries from past 7 days, compute coverage,
    identify gaps, generate recommendations, cache results.
    """
    
    logger.info("Starting gap analysis job...")
    
    # Fetch all tenants
    tenants = await db.query("SELECT id FROM tenants WHERE is_active = TRUE")
    
    for tenant in tenants:
        tenant_id = tenant.id
        
        # Fetch queries from past 7 days
        cutoff_date = datetime.utcnow() - timedelta(days=7)
        queries_raw = await db.query("""
            SELECT
                c.id, c.query_text, c.category,
                e.escalated_at IS NOT NULL as was_escalated,
                CASE
                    WHEN e.escalated_at IS NOT NULL THEN 'escalated'
                    WHEN c.kb_article_id IS NOT NULL THEN 'kb'
                    ELSE 'agent'
                END as resolution_source,
                c.created_at
            FROM conversations c
            LEFT JOIN escalation_events e ON c.id = e.conversation_id
            WHERE c.tenant_id = $1 AND c.created_at >= $2
        """, tenant_id, cutoff_date)
        
        # Categorize uncategorized queries
        categorizer = QueryCategorizer()
        queries = []
        for row in queries_raw:
            if not row["category"]:
                row["category"] = categorizer.categorize(row["query_text"])
            queries.append(QueryRecord.from_db_row(row))
        
        # Compute coverage
        coverage_scores = compute_coverage(queries)
        escalated = [q for q in queries if q.was_escalated]
        
        # Identify gaps
        gaps = identify_gaps(coverage_scores, escalated, top_n=10)
        
        # Generate recommendations
        recommendations = generate_recommendations(gaps)
        
        # Build report
        category_stats = [
            CategoryStats(
                category=cat,
                query_count=sum(1 for q in queries if q.category == cat),
                resolved_without_escalation=sum(
                    1 for q in queries
                    if q.category == cat and q.resolution_source == "kb"
                ),
                coverage_score=coverage_scores.get(cat, 0.0),
                example_queries=[q.query_text for q in queries if q.category == cat][:3],
            )
            for cat in categorizer.CATEGORIES
        ]
        
        report = KnowledgeGapReport(
            analysis_date=datetime.utcnow().date(),
            total_queries_analyzed=len(queries),
            categories=category_stats,
            coverage_score_overall=coverage_scores.get("overall", 0.0),
            top_missing_areas=gaps,
            recommendations=recommendations,
        )
        
        # Cache
        cache_key = f"knowledge_gaps:{tenant_id}:{report.analysis_date.isoformat()}"
        await redis.set(cache_key, json.dumps(report.to_dict()), ex=86400)
        
        logger.info(f"Gap analysis complete for tenant {tenant_id}: "
                    f"{report.coverage_score_overall:.1%} coverage")
```

## Deployment

- **Scheduler:** APScheduler cron job at `0 2 * * *` (02:00 UTC daily)
- **Environment Variables:**
  - `SENTENCE_TRANSFORMER_MODEL` (default: `sentence-transformers/all-MiniLM-L6-v2`)
  - `KB_COVERAGE_CACHE_TTL` (default: `86400` seconds = 24 hours)
  - `GAP_ANALYSIS_LOOKBACK_DAYS` (default: `7`)
- **Redis:** Keys prefixed `knowledge_gaps:` expire after 24 hours
- **No Schema Changes:** Uses existing `conversations`, `escalation_events`, `faq_articles` tables

## Acceptance Criteria

- ✓ Coverage score computed correctly (resolved / total per category)

- ✓ Priorities assigned (high > 50/week, medium 20–50, low < 20)
- ✓ Recommendations generated with actionable text
- ✓ API endpoints return valid JSON with expected fields
- ✓ Nightly job runs without errors
- ✓ Results cached in Redis (24h TTL)
- ✓ Fallback to keyword matching if transformer unavailable
