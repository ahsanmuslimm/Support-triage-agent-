# S8.2: SetFit Fine-Tuning

## Overview
Multi-label intent classification using SetFit with efficient per-tenant LoRA adapters.

## Key Components
- **SetFit Trainer**: Multilingual-e5 embeddings → mDeBERTa-v3 head
- **MultiLabelHead**: Sigmoid per label (not softmax)
- **FocalLoss**: Class-balanced focal loss α=0.25, γ=2.0
- **ContrastiveLoss**: Triplet loss with positive/negative sampling
- **LoRA Adapters**: Per-tenant low-rank adaptation for efficiency
- **Training Metrics**: Macro-F1, per-class F1, F1 variance
- **Validation Gates**: F1 ≥0.92, variance <0.15
- **Hyperparameter Tuning**: Grid search over LR, batch size, epochs

## Outputs
- Trained multi-label head with per-tenant LoRA adapters
- Training history with per-epoch metrics
- 45+ tests for trainer, loss functions, adapters, metrics
