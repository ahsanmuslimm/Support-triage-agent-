# S8.3: Temperature Scaling & ONNX Export

## Overview
Confidence calibration and model serving with ONNX quantization.

## Key Components
- **PlattScaling**: Temperature T calibration on validation set
- **ECE Computation**: 
  - Binned ECE (10 bins)
  - Adaptive ECE (auto bin count)
  - MCE (max calibration error)
  - Brier score
- **ONNX Export**: FP32 + INT8 quantization
- **ONNXInference**: Runtime inference with top_k predictions
- **HotReloader**: Reload ONNX models without restart
- **CalibrationPipeline**: End-to-end calibration → ECE <0.05

## Outputs
- Calibrated model with temperature parameter
- FP32 and INT8 ONNX models
- Calibration metadata (temperature, ECE metrics)
- 35+ tests for calibration, ECE, ONNX
