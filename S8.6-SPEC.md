# S8.6: Taxonomy Bootstrap

## Overview
Auto-discover intent taxonomy from historical embeddings.

## Key Components
- **K-Means Clustering**: k tuned via silhouette score (10-30)
- **Opus Labeling**: Claude labels each cluster
- **Admin Review**: Approve/reject cluster labels
- **Intent Merge**: Combine clusters → reclassify tickets
- **Intent Split**: Divide cluster → new intents + validation
- **Label Migration**: Update historical tickets on merge/split

## Outputs
- Discovered intent taxonomy
- Cluster labels with confidence scores
- Merge/split history with audit trails

## Validation
- Silhouette score for cluster quality
- Separation quality on splits (>0.6 preferred)
- Admin review workflow
